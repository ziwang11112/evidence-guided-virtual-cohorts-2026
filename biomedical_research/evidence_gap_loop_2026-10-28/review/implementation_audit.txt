Independent implementation audit — 2026-10-28

Disposition: No blocking implementation issue remained in the tested synthetic
paths. All 18 independent synthetic test methods passed. This is a procedural
and numerical implementation assessment, not a scientific result.

Scope: protocol.json, loop_control.py, tools/literature_gateway.py and its config,
custodian/evaluate.py, custodian/analysis_spec.json, eligibility metadata, and
shared schema/description. Test inputs were fabricated under review/ and cleaned
after each case. No real observed/reference/participant CSV, raw source data,
builder construction, target analysis or outcome result was read. No old
experiment was rerun. No expected biological coefficient or sign was supplied.

Issues found and corrected before release:
1. Arbitrary nonempty parameter provenance and empty evidence were accepted.
   Typed parameter links now resolve against evidence and declared assumptions.
2. A matching hash under a directory named approved was enough to claim approval.
   Evidence now requires the assigned gateway's accepted-artifact registry.
3. Reviews did not bind candidate artifacts/freeze receipts. Initial and final
   reviews and execution records now bind the candidate and run hashes.
4. Forty labeled files could unlock evaluation without frozen constructions.
   The release gate now validates four runs, 40 distinct output paths, all
   scheduled seeds, freezes, reviews, execution receipts and artifact hashes.
5. Gateway page size allowed 20 results while the protocol capped it at 10.
   Search, download and result caps now agree with the common protocol.
6. Final gap records could lack a linked action. Every applicable final gap now
   needs an action or an explicit retain/stop disposition in the action history.

Independent verification:
- Full positive synthetic release: four runs, two stages, five draws each.
- Premature execution/final submission and premature evaluation blocked; no CSV
  reader called before an invalid release is rejected.
- Changed code, review/freeze/execution bytes, seed, output path and missing
  artifact bindings rejected. Appended gateway audit history is allowed while
  modification of its frozen prefix is rejected.
- Same generator and seeds produce byte-identical ordinary/gap-policy outputs.
  A declared final no-op retains the initial same-seed outputs. Changed observed
  cells, extra columns, nonfinite/nonpositive values and global RNG mutation are
  rejected; exact high-precision observed values survive CSV roundtrip.
- Synthetic group-mean and marginal-SD evidence remains byte-identical through
  freeze/execution; the controller does not convert it into conditional effects.
- Gateway screens complete returned metadata and encoded excluded aliases;
  failed network attempts consume budget; supplements require parent-manifest
  linkage and correct parent identity.
- Weighted coefficients agree with independent least squares. Taylor covariance
  agrees with manual stratum/PSU score sums including entirely empty domain PSUs.
  Results are invariant to uniform weight scaling; documented domain degrees of
  freedom are reproduced. Both arms use the same eight locked endpoints.

Limits: A source link and a structural provenance schema do not prove correct
extraction, scientific transport or an adequate individual-level model; the
independent scientific review remains necessary. Alias screening is conservative
and incomplete. Hash receipts and role scopes provide procedural integrity on a
shared filesystem, not an OS sandbox or protection against a fully malicious
local actor. Equal caps/schedules do not establish matched reasoning-token
consumption. The evaluator validation-only amendment requires the custodian's
explicit chronology/re-freeze record; no endpoint/statistical change was requested.
