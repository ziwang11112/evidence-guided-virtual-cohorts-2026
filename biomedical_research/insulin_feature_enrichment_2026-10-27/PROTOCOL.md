# Whole-variable insulin enrichment: prospective pilot protocol

27 October 2026. This protocol is committed before analysis of any true insulin relationships. Frozen source, input, model and evaluation manifests supply exact hashes. No claim of preregistration in an external registry or pristine pretrained knowledge is made.

## Question and population

Can an Agent independently find applicable external research, generate a previously unobserved fasting-insulin column for observed BMI/age/sex rows, and support scientific interpretations compatible with reserved real-data analyses? The user prioritizes analytical utility and relationships over exact value reconstruction. No per-person RMSE objective or numerical-equivalence pass threshold is imposed.

Official NHANES 2017–2018 sources and inclusion criteria are recorded in the custodian manifest. The complete-case target has 1,700 adults aged20–79, while the positive fasting-weight design spine retains2,711 records. The reference is held separately. Exclusion rules were fixed from study design/metadata, not correlation results. Remaining missing-outcome selection is not automatically corrected by the original survey weights.

Visible input contains only pseudonymous row_id, BMI, age, and sex. No glucose/HOMA or insulin-derived fields, outcome marginals, original record IDs, or target analysis results are supplied. Insulin is wholly absent, not merely selectively masked within each row. Whole-cohort synthesis and other completion tasks remain broader project uses; this pilot isolates feature enrichment.

## Agent and integrity design

The construction Agent chooses literature queries, evidence, model structure, quantitative parameters and uncertainty assumptions. The fixed controller handles interfaces, preservation, seeds and provenance only. Program and direct-record routes are eligible; actual executed route must be reported. One independent source/code review and a versioned revision may occur before evaluation. Defects may justify interface repair in a new attempt, never unrecorded rewriting or result-driven tuning.

The first search context encountered prohibited NHANES snippets despite negative search terms and was halted before creating a model or accessing the observed rows. Its log is retained under agent/. It is excluded from the clean construction. A new context under agent_clean/ uses an automatic bibliographic screening gateway that removes prohibited metadata/abstract/fulltext before display. Conservative screening can exclude otherwise useful sources and does not prove absence of all source overlap or model pretraining knowledge. No exposed parameter is carried into the fresh prompt.

All NHANES-derived relationship evidence is excluded from construction. External source populations, assay/fasting definitions and overlap are audited. Unreported quantities are labeled assumptions, not fabricated extracted evidence. Random seeds270101–270120 are fixed before generation; all20 outputs per scheduled model version are evaluated. No favorable seed, subgroup or revision is chosen by reference performance. Repeated draws from one construction are conditional Monte Carlo repetition, not between-Agent replication.

## Reserved evaluation

The independent reviewer writes the analysis family before reading outcomes. It fits the same weighted scientific analyses to real and generated values: overall and adjusted relationships, nonlinear shape, and subgroup dependence. Exact formulas and predictor-only spline choices are sealed under review/ and not delivered to construction. Intercept/marginal checks are ancillary, not the primary scientific target. Prespecified secondary questions and failures remain visible.

Use the fasting subsample weight and a full positive-weight stratum/PSU spine with zero score contribution outside the target domain. Report Taylor survey intervals and design degrees of freedom. Synthetic intervals condition on the generated outcomes and are not automatically calibrated uncertainty about real unobserved insulin. Do not stack synthetic rows or pool distinct generated models as more observed people. No automatic Rubin pooling.

Main reports describe scientific direction, shape, adjusted/subgroup interpretation, uncertainty and between-generation stability. They do not define success by matching p<0.05 or matching arbitrary decimal tolerances. Estimates and diagnostics help explain agreement/disagreement. Reference uncertainty is retained; absent significance is not proof of a null relation. No multiplicity-adjusted confirmatory discovery claim is made from this small descriptive family.

After source review, tag each analysis as supplied/evidence-consistency, target-specific reserved transport, or explicitly assumed in the model. A hidden script alone does not make an input-supported relation independent evidence. New locked data means newly sealed for this project; NHANES itself is previously public. This single-cohort single-construction feasibility pilot cannot establish generic superiority or savings in patient recruitment.

## Freeze and release

Before any true-outcome analysis: freeze source/eligibility and visible inputs; freeze reviewer specification and predictor-only quantities; freeze Agent request/evidence/model; execute and freeze every generation output; bind all these plus reference/spine hashes in an evaluation manifest. Review code and run artificial-fixture tests before release. Evaluate once into a new versioned directory, retain every result, and audit calculations after release without modifying generation.

Only code, metadata, eligible aggregate evidence and aggregate results may be synced to the authorized private GitHub repository. Original public patient tables, masked visible rows, row mappings, full synthetic tables, and downloaded fulltext articles stay local.
