# Larger biomedical experiment campaign

1 November 2026. The user explicitly requested increased experimental scale after asking for sufficient experiments. This defines a **new, larger prospective phase**, superseding the previous recommendation to plan only one additional case. Earlier budgets and results remain historical; revealed targets do not become fresh. This unit prepares the design and machine-readable slot inventory, not generated data.

## Scientific objective

Assess whether one declared evidence-to-cohort procedure can construct joint virtual data useful for multiple biomedical analyses across independent measured settings. Complete-cohort generation without individual input remains the primary regime. The emphasis is actual analytical usefulness, scientific construction variability and cross-setting consistency. Model architecture novelty, multi-Agent collaboration and superiority to a direct-analysis Agent are not requirements.

## Planned scale

| Unit | Per cohort | Four-cohort cap |
|---|---:|---:|
| Independently admitted measured reference cohorts | 1 | 4 |
| Independent Agent construction contexts | 5 | 20 |
| Transparent statistical reference constructions | 1 | 4 |
| Stages per construction | Initial and final after at most one source-feedback opportunity | Up to 48 candidate-stage records |
| Sampling seeds per stage | 3 | Not independent biological replications |
| Agent table slots | 5 × 2 × 3 = 30 | 120 |
| Statistical-reference table slots | 1 × 2 × 3 = 6 | 24 |
| **Total table slots** | **36** | **144** |
| Rows per table | 5,000 | At most 720,000 generated rows if every slot creates a new table |
| Primary scientific analyses per table | 3 | 12 case-specific primary questions; at most 432 slot-level evaluations |
| Secondary scientific analyses per table | Up to 2, justified before outcomes | Up to 8 additional case-specific questions; at most 288 slot-level evaluations |

Thus the upper bound is **720 table-slot/analysis evaluations**, not 720 independent validations. Actual independent biomedical validation scale is at most four cohorts. Agent construction scale is twenty fresh authoring contexts, not twenty model brands. The statistical reference has four independent constructions and up to eight fit instances including permitted final recalibration; seed draws do not create additional fits. Actual eligible reference participants are unknown until appropriate preparation and must be reported separately from virtual row counts.

The 5,000-row output size is a computational design choice fixed independently of target effects. It supplies simulation resolution, not extra measured information. A retained final stage references the initial output hashes and is not rerun merely to fill its three slots. If every construction retains, there are at most 72 newly sampled tables; changed final stages can raise that number to 144. Failed or unstarted stages can reduce it further. Identical files and identical scientific models are also identified explicitly rather than counted as new discoveries.

## Four intended biomedical case slots

These are admission specifications, not datasets already found or guaranteed to qualify. Aim for four independent target cohorts from at least three study families, with documented participant and source overlap. Several waves of one survey do not automatically establish independent families or unaffected observations.

A target with relevant source–target participant overlap or prior target-effect exposure does not count among the four independent validations unless affected evidence or participants are prospectively excluded sufficiently to restore the stated independence. Otherwise it is reported separately as development or non-independent evaluation. Merely documenting exposure or changing the case label does not restore independence.

| Slot | Intended subject | Intended analyses, to be specified from permissible evidence and metadata |
|---|---|---|
| K01 | Adiposity and glycemia | Adjusted adiposity/glycemic associations and one relationship requiring additional conditioning, testing the quantitative-use gap seen in development. |
| K02 | Lipids and metabolic indicators | Adjusted lipid associations and a scientifically motivated subgroup or joint contrast. |
| K03 | Directly measured renal biomarkers | Two conditional biomarker associations and a reuse analysis; a formula-derived renal index is not an independently recovered biological relationship. |
| K04 | Inflammatory or hematological indicators | Conditional associations and a distribution-sensitive analytical use justified by the measured indicators. |

Each case should contain a manageable joint table, approximately five to eight substantive variables. Different indicators must serve different scientific questions; extra columns alone do not establish breadth. Exact variables, eligibility, measurement scales, source applicability, adjustment sets, missingness and uncertainty methods are determined before reference effects are inspected. Two of the three primary analyses should test meaningful quantitative uses; the third tests reuse beyond direct numerical fitting. Supply/implication/assumption status is recorded separately from target holdout status. Secondary analyses are optional, not targets to fill.

Evidence-only whole-cohort generation is used throughout this primary campaign so that setting changes are interpretable. Enrichment, missing-cell completion and dynamic user requests retain their separate status; no factorial expansion over every optional mode is planned.

## Generation arms

**Evidence-guided Agent:** five fresh construction contexts per case receive the same approved source packet, population request and interface. They independently choose joint structure, parameters and assumptions. Every constructor has one initial design and at most one source-feedback revision/retention opportunity. The coordinator does not supply target-informed coefficients. Available backend identity/settings are recorded; unavailable metadata stays unavailable. Fresh contexts are procedural separation, not proof of pretraining non-exposure or distinct foundation models.

**Statistical reference:** one transparent conventional construction per case uses the same admitted aggregate/conditional evidence and population description, without target-row fitting. Its distribution family, treatment of incomplete constraints and parameter-estimation rule are selected for compatibility before outcome access. A transformed conditional model or copula is an option, not a universally appropriate forced baseline. It receives the same source diagnostic information and one predeclared calibration/retention opportunity. The full evidence packet and unhandled constraints are documented. Calibration may not secretly generate additional trial cohorts outside a declared budget; the initial design assumes analytical or deterministic aggregate fitting. A comparator needing extra simulation must have that work separately budgeted before execution.

This reference helps interpret practical data construction. Five Agent authors versus one conventional specification is an asymmetric robustness design, not an equal-search-budget superiority test. Report all Agent constructions and the fixed reference; do not select the best Agent and call it a fair win. A stronger method-superiority comparison would require an explicit matched selection/compute design and is not implied by this campaign.

## Two waves and a fixed continuation decision

1. **Admission and global freeze.** Screen at most six additional candidate families and seriously audit at most twelve new original source studies in this new phase, using existing records first. These are new prospective ceilings, not resets of prior ledgers. Target families used in construction evidence or with prior result exposure need explicit exclusions/qualification. Fix all admitted case identities, evidence packets, analysis questions, interpretation criteria and generation procedure before the first target results are revealed. Select using availability, measurement and evidence relevance, never inspected target effect favorability. If four eligible cases cannot be found within the ceiling, report the shortfall; do not invent independence or silently expand the search.
2. **Wave A:** K01 and K02, at most 72 table slots, ten independent Agent constructions and two statistical references. All scientific decisions and outputs for both cases close before either target is disclosed.
3. **Prospective gate:** pause for a method/claim decision if neither case satisfies its frozen quantitative-use bundle, or if a material implementation/information-boundary defect invalidates interpretation. The case contracts must define that bundle and any scientifically justified tolerance before execution. Numerical resemblance or significance alone is not a retrospective gate. Preserve failures and record unexecuted Wave B slots. If the method is changed, version it; the first wave cannot be retroactively relabelled as validation of the changed method.
4. **Wave B:** K03 and K04, at most 72 remaining slots under the unchanged procedure and pre-admitted scientific contracts, provided the gate allows continuation. Builders receive no earlier target results. All of their scientific decisions and outputs close before their target disclosure.
5. **Close once:** evaluate every planned available output, independently recompute, and report all cohort-by-analysis results. No case replacement, extra seeds, endpoint switching or target-informed repair to obtain favorable findings. Four cohorts do not guarantee publication or general biomedical fidelity.

A case can support directional use while failing its quantitative-use bundle. That is a reportable result, not success on a stronger claim. Reference sampling uncertainty is accounted for without treating a wide interval as agreement. Construction variation, simulation variation and source/transport uncertainty remain distinct; multiple authors or seeds do not constitute a calibrated posterior.

The frozen contract must also specify how all five constructors contribute to case-level bundle success. Seeds assess conditional simulation variation; neither the best constructor nor a post-hoc subset can satisfy the continuation gate. The current plan deliberately has no universal case-success threshold: that unresolved scientific criterion prevents executable release until it is specified for each intended use.

## Implementation and resources

The existing `cohort_harness` candidate lifecycle, isolated execution, receipts and `semantic_feedback_v1` can be reused. The conditional interpretation module remains limited to its reviewed operators. The CHNS controller hardcodes two constructors, its five variables, seeds and twelve slots; the CHNS evaluator hardcodes that cohort's preparation and three projections. They must remain frozen historical code and cannot be presented as a generic batch runner.

The next implementation should be a thin new campaign orchestrator over existing interfaces, plus independently reviewed per-cohort preparation and analysis adapters. It must require resolved case IDs, approved source/task contracts, hashes and a target-access gate. It must refuse placeholder slots and never fall back to CHNS or discover patient files through directory globbing. A later generic runner is not claimed to exist merely because a plan file has been written.

The [machine-readable campaign plan](../reports/scaleup_2026-11-01/campaign_plan.json) reserves all 144 slots with unresolved case IDs, zero attempted executions and execution disabled. Its [build script](../reports/scaleup_2026-11-01/build_plan.py) only writes and checks the design inventory; it does not launch Agents, generators or target evaluation.

Start with the existing local runtime after case release. The prior CHNS receipts totalled 8.406 seconds for twelve generation slots, excluding Agent work, evidence curation, review and reference preparation. That is not a runtime estimate for this larger phase. Meter actual authoring/review effort, execution, memory, failures and wall time separately. The plan allows at most forty Agent design/feedback turns before separate reviews; packet/interface clarifications must be recorded and must not become extra scientific trials.

HPC is not required merely to generate more 5,000-row tables. Its use would depend on observed analysis/data costs, substantial resampling or memory demands. The current isolated adapter is tied to the inspected local WSL runtime; HPC would need an explicit reviewed backend and a resource decision. No training, new paid API, HPC job, new account, restricted-data application or recurring schedule is launched here. This new source-screening allowance does not reset download accounting. Browser traffic remains separately unmetered.
