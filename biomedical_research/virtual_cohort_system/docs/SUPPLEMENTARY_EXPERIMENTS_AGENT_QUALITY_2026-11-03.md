## 贡献与实验问题

论文的核心是：研究者给定人群、研究用途和可用证据，Agent 构造适用的生成模型，输出能用于科学分析的虚拟数据。无个体输入的整个人群生成继续作为主实验；指标增广和缺失补全保留为不同信息条件下的扩展。

补充实验回答三个问题：

1. **质量：** 虚拟数据能否支持与真实样本相近的指定分析，并避免明显的分布、尾部和联合关系失真？
2. **建模自动化：** 给定已整理的证据与任务，Agent 能否自行选择结构和科学参数，换任务时需要多少人工适配？
3. **信息条件：** 外部研究证据与明确提供目标摘要分别能达到什么质量？它们支持不同用途，均是合法生成情境。

不把“全自动检索任意论文”“任意指标均能生成”“修订一定改善”作为现有主张。给定任务后的自动建模可单独构成待评价的能力。人群和分析问题可以公开给作者；是否提供目标数值决定评价解释。

## 已有证据直接保留

## 比较方法及优先级

| 方法 | 定位与当前状态 | 允许输入及比较价值 |
|---|---|---|
| 我们的 Agent 科学建模程序 | 主方法，已有实现 | 同一任务/证据接口下自主确定生成律；输出完整数据、假设和证据使用记录 |
| 已有 Gaussian-copula moment-completion | 已运行的实质性传统对照，保留全部结果 | 来源边际及相关/回归约束；已经比部分 Agent 更准，不能降格为独立边际弱基线 |
| Summary-constrained sequential statistical adaptation | 建议新增的统计适配版，尚未实现 | 固定条件分布族，用同一摘要和算子校准；明确残差、来源和迁移假设，衡量专门统计建模能达到的质量 |
| G-Sim 或 LLMSynthor 的一个适配版 | 第二优先，先做有界适配审查；未运行 | 确保相同证据和反馈权限，记录为接入生物医学算子所增加的代码；能保持原方法核心时才进入正式比较 |
| 普通单 Agent/直接输出数据 | 可选实现消融 | 只有要证明特定 harness 或生成路线的增益时才做；不要求主论文证明优于“普通 Agent” |

新增统计适配版必须有实质区别，例如更合适的残差/边际族、可执行的遗漏约束或透明的来源完成方案。仅把同一个 Gaussian copula 改写成顺序抽样不构成新方法。不能由根任务看着目标结果手填有利的斜率、均值或波动；依据明确提供的校准摘要进行预定优化则是合法的。

Filshtein 原研究由来源分析员从个体数据估计规则。此处从论文摘要构造条件生成律应称为适配，不能冒充原版复现。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8338788/)

SynthIPD 原算法需要同一人群的 KM 曲线、风险集和亚组统计。CHNS/ENSANUT 当前是横断面生物标志物任务，不适合直接运行原算法。它保留为重要近邻和校准设计参考；不能用输入不适用来宣称胜过它。[原文 §3.2](https://arxiv.org/html/2509.16466v2)

synthpop 等个体数据训练方法可以作为未来“允许训练记录”的单独参照，当前零个体输入条件下不把它们放入主排名。synthpop 的原始用途确实需要原始数据生成其合成版本。[原论文](https://www.jstatsoft.org/article/view/v074i11)

近邻 Agent 适配审查只读方法、输入接口和代码依赖，最多深入一条可执行路线；此方案不自动授权无限适配或新付费调用。G-Sim 的结构/参数校准与本任务接近，LLMSynthor 的宏观约束生成也相关；选择应由输入兼容性与可复现性决定，不由先试后的胜负决定。[G-Sim](https://proceedings.mlr.press/v267/holt25b.html)、[LLMSynthor](https://arxiv.org/html/2505.14752v4)

## 两种信息条件

| 条件 | 给所有方法的内容 | 主要回答的问题 |
|---|---|---|
| L 外部文献 | 已有 E1 研究条件与数值证据，目标人群、单位、筛选与研究请求；不给目标数值摘要 | 外部证据经生成律和迁移假设后，对目标分析有何用途 |
| R 文献加目标摘要 | L 的材料，加明确开放的目标摘要；CHNS 现有 30 项，ENSANUT 现有 31 项，须逐项核对绑定 | 能否把可获得的汇总信息转成连贯、可分析的个体表 |

R 的匹配成功称为校准一致性。未直接校准分析另列，区分代数蕴含与补全假设依赖；不把已经输入的结果当成未见关系。L 与 R 的研究问题都公开。任何目标或来源数据重叠须列明。

两家真实参照均已被研究团队接触，新增构造仍是开发性评价。新作者上下文能限制其输入，不能恢复队列未暴露状态。来源统计重放必须在相应来源条件下计算；任务人群统计不能冒充来源重放。无法绑定原来源分布时，明确标记近似或不可用。

## 推荐的有界补充设计

若要系统检验“信息条件 × 方法”以及换任务的建模过程，建议使用现有 CHNS 和 ENSANUT，不新增队列：

- 2 个案例 × 2 种信息条件。
- 每格 3 个独立 Agent 作者上下文，以及 1 个预先规定的统计适配构造。
- 每构造 3 个固定最终种子，每表 3,000 行。
- 合计 **16 个构造、48 张最终表**。
- 每构造最多 1 次探索性出表以及 1 次来源/开放摘要反馈后的保留或修订机会；合计最多 **64 次物理出表尝试**。无改动不额外复制初稿表。
- 最终种子、作者分配、可见输入、模型标识、工具预算和统计求解预算须在释放文件中绑定。非出表解析计算和优化调用也计量，不能隐藏在“采样很快”之下。
- 全部构造完成后统一评价；失败、不可计算分析、非收敛和无修改均保留。
- 3 个 Agent 结构对 1 个固定统计构造仍是结构不同的重复，不宣称方法家族显著优胜；展示全部结构、种子和实际资源。

此设计重做部分已有条件的理由只能是：统一协议并前瞻性记录人工干预/成本、形成完整 L/R 因素比较。不能把新表数算作新患者证据。若这些额外问题不是论文主张所需，优先保留现有结果，执行下面更小的统计补充，不必跑满 48 张。

**最低成本替代：** 在历史 CHNS 30 摘要条件下只新增 1 个统计适配构造和 3 个最终种子，与保留的 Agent 汇总比较。它只回答描述性的校准质量问题，不能比较历史未记录的人工成本，也不能当作完整因素实验。[已有细化设计](FAIR_PREDECESSOR_COMPARISON_PLAN_2026-11-03.md)

本轮建议先完成统计适配与新评价模块的规格审查，再选定上述规模并冻结；本文件不是释放记录。G-Sim/LLMSynthor、直接行生成、额外消融均不包含在 48 张预算中，不能默默扩展。

## 质量评价

一般分布质量与具体分析用途应同时看，主结论放在后者；两者的区分已有合成数据方法学依据。[Snoke 等](https://arxiv.org/abs/1604.06651)

| 层次 | 保留或新增项目 | 解释 |
|---|---|---|
| 主要科学用途 | 每案例原定 3 项回归；原始单位效应、方向、绝对/有符号差异、参照不确定性；完整显示所有构造 | 数据是否支持相近的研究结论；不只比较显著性 |
| 分布与联合质量 | 复用 27/28 项诊断中的均值、SD、分位数和 Pearson/Spearman 等；逐项查完整定义 | 防止中心位置接近而波动、尾部或依赖失真 |
| 有限扩展分析 | 每案例至多 1 个用途明确的新分析，优先预先定义的非线性对比或亚组关系；至多 1 个必要尾部指标 | 新公式、分析人群、参照不确定性和可见性先固定；属于开发性扩展，不择优挑分析 |
| 证据使用 | 约束残差、单位/调整集/筛选一致性、使用/检查/未使用；来源近似另标 | 区分“引用了”与“实际约束了”，不把语义检查等同于迁移正确 |
| 稳定性与有效性 | 独立作者、固定种子、有效行比例、支持范围、有限矩、拟合失败 | 防止幸运种子、模式塌缩或有限样本掩盖理论尾部缺陷 |

主要端点保留已有定义，不混合不同量纲成“总体准确率”。相对误差在接近零的系数上不可靠，不能作为唯一指标。没有预先有科学依据的容许差异时，只报告差异，不创造“临床等效”判定。置信区间重叠也不是等效检验。

方向一致有意义，但效应接近零或倍数失真不能仅凭符号判为完全保留。两个结果都 p<0.05 也不等于科学用途一致。生成行数增大只减少某个模型的模拟误差，不能制造更多患者证据或自动缩小来源与结构不确定性。

新的非线性/亚组分析应从用途出发指定，不从目标结果中挑有利者。本方案没有指定一个尚未审查公式的曲率统计量，也没有读取目标后选择检验。其主张仍应限定于实际分析覆盖范围。

## 真实对真实的抽样参照

用户关于“同一真实队列分成两份也不相同”的判断应纳入解释。当前记录只有 CHNS 聚类系数区间和 ENSANUT 聚类重采样稳定带，未建立匹配 n=3,000 的真实对真实差异分布；不能从现有区间反推出它。

建议独立评估端在新的暴露记录下，按已有纳入规则和估计定义，先冻结社区/聚类、分层与权重处理。至多每案例 200 个预定真实—真实抽样对，失败不替换。只向结果层输出统计量和抽样设计，患者行不进入构造 Agent。原始及派生数据仍只留本地。

抽样方案必须明确：是两个不重叠子样本，还是在同一经验队列下的两个重采样。两者不能混称独立临床验证。样本量匹配应分别对应比较的两端：生成端为 3,000 行，而完整参照端为 CHNS 6,631 人或 ENSANUT 6,931 人。两个真实样本都取 3,000 人不能严格模拟当前生成—完整参照比较。释放前应绑定两端样本量及有效设计；若只做半样本分割，或整群结构导致无法精确配平，报告实际样本量/设计，仅作描述性尺度，不计算声称严格匹配的相对质量分数。对同源摘要校准的生成—参照差异，还须承认二者共享信息而相关。

图中并列展示真实—真实与生成—真实差异，解释自然抽样尺度。不能把真实—真实差异的 95% 分位数事后当作临床等效阈值，也不能因参照有不确定性忽略系统偏差。重复抽样不增加独立队列数。

这是新增评估工作，不修改冻结评估器；实现须独立审查，再读取必要的现有本地记录。本轮没有运行此分析。

## 自动建模与可扩展性作为同一实验的过程终点

固定共享 skill、作者契约和控制器，只替换预定任务、证据及分析包。研究请求变化允许 Agent 改变生成器；无需强制所有用途共用同一生成律。

分别记录：
- 文献整理、证据提取、算子/案例适配的人工工作；
- 启动后人工科学结构/参数修改次数；
- 机械修复、配置修改、新增专用代码与重试；
- 首次有效交付率与最终完整分析交付率；
- Agent 时间、采样/优化时间、审查时间、可获取调用成本与不可计量部分。

若允许人工救援，保留自动尝试的失败，救援结果另列。若只用固定统计模板与 Agent 比较，不声称减少了人类专家时间；这种时间优势需要前瞻性记录真实人工建模对照。当前两个同属糖代谢、五变量案例最多支持有限范围的任务适应，不支持任意疾病/模态可扩展。

## 消融只围绕实际贡献

首要信息消融是 L/R；已有 E0/E1 描述不同证据丰富度，保留而不必再次扩展。若另要声称某项新机制有效，才添加一个受控消融：

- 数值约束记录 vs 只给同样证据的文本提示：仅当需要归因数值落实机制，必须固定其余工具与预算。
- 来源条件处理 vs 合法的简单合并：简单合并须保持单位与算子正确，不能故意使用错误统计量制造对手。
- 反馈修订：现有主实验为零科学修订，不强制再做“修订有增益”的实验，也不把保留决定隐去。

所有消融需要新的有界规格，当前预算不含额外消融。不同架构、更多 Agent 角色或更多种子不自动增加科学贡献。
