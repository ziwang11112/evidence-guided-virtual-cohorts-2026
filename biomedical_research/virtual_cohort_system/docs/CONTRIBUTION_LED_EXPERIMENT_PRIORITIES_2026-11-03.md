# Contribution-led experiment priorities

3 November 2026, after the completed CHNS summary-comparator supplement and the user's explicit correction of the research priority. This is the current prospective plan. Completed experiments, their recorded failures, results and interpretation boundaries remain unchanged.

## The paper's central proposition

**An evidence-guided scientific Agent constructs virtual biomedical data from available published findings, a population description and a research request, so that researchers can conduct useful analyses when individual measurements are unavailable or incomplete.**

Complete-cohort generation without individual input is central. Enrichment and missing-value completion are additional uses. The Agent may choose a different scientific model for a different request; its authored program and statistical tools are part of the generation method. The delivered data, scientific construction and demonstrated analytical uses are the contribution.

There is no requirement to beat an undefined, sufficiently customized statistical generator on every dataset. Such a comparator has no universal design standard and can require a new modeling project for each case. It can be an informative reference, but universal superiority is neither our research question nor a drafting gate. An ordinary capable Agent is a valid implementation.

## What the experiments should establish

| Priority | Evidence to present | Work decision |
|---|---|---|
| 1. Scientific usefulness of generated data | Apply the specified analysis to generated and real-reference data: relationship direction, meaningful effect scale, and any declared subgroup or nonlinear conclusions. Include the distribution and joint checks needed to interpret these analyses. | Consolidate the completed CHNS/ENSANUT and summary-assisted results first; retain all specified endpoints. |
| 2. Evidence-guided scientific construction | Show how an Agent turns reported statistics and study conditions into actual model structure and numerical constraints, then produces analyzable tables. | Use existing model specifications, evidence-use records and E0/E1 results. Explain one worked example rather than add infrastructure. |
| 3. Applicability of the procedure | Show the same Agent workflow handling the documented populations, evidence regimes and research requests, with the scientific choices it made. | Reuse existing cases; do not demand a bespoke expert comparator for every case. Broader task coverage is a targeted extension if it materially strengthens the retained claim. |
| 4. Comparison with published methods | Use a predecessor's accessible public example and its native scientific analyses where the inputs and outputs are compatible. | Select one manageable case after checking actual artifacts. Use the published implementation when executable; name adaptations explicitly. No automatic multi-method tournament. |

Scientific usefulness is not exact individual-value recovery or equality of sample statistics. Conversely, comparing analysis results is more informative than plausible-looking rows or a single matched mean. A requested analysis may be visible to the Agent. Available summaries can legitimately guide generation; clearly label whether a comparison checks supplied-summary reconstruction or an analysis/reference not used for construction. These labels explain the result; they are not extra hurdles that invalidate the summary-assisted use case.

## Existing evidence and the role of the new statistical supplement

The main developmental study is complete: two real-reference cases, 20 Agent constructions, four statistical constructions and 72 final tables. Additional qualified relational evidence reduced the mean absolute coefficient discrepancy for five of six designated analyses; CHNS BMI worsened. The summary-assisted CHNS study and the subsequent three-table statistical supplement both demonstrate substantial alignment on the supplied regression summaries. Report the full results rather than select only favorable analyses.

The custom statistical supplement is now closed. Keep it as a descriptive quality reference in the supplementary material, with its purpose-built nature and the disclosed path-only technical recovery. Its successful calibration does not undermine the Agent data-generation use case, and does not require a new manual-cost competition to rescue the paper. Do not build further bespoke statistical families just to seek a win.

We will not claim superior accuracy, lower human effort or complete autonomous literature processing unless those particular comparisons are observed. Present the tested capability positively and specifically; place untested extensions and residual modeling weaknesses in a concise limitations section.

## Next work, in order

1. Reorganize the existing results and figures around analytical usefulness, evidence use and the tested scope. Preserve the main method and completed outputs.
2. Check one published method's public example for available inputs, code and original analyses. Prefer a small runnable example over another custom CHNS comparator. Dataset accessibility and task compatibility determine selection, not a favorable result. This planning update does not itself download data or launch a new experiment.
3. If that example is feasible, fix a compact protocol, run our method on its permitted material, and evaluate the complete original analysis set relevant to the task. Compare execution results directly when the original method can be run; label author-reported results separately otherwise. Account for differences in information or use them as an explicit input-availability experiment.
4. Integrate the comparison into the manuscript. If the public example is unavailable or requires a substantial new subsystem, document that and complete the paper from the existing evidence instead of opening an indefinite comparison branch.

The proposed 48-table supplemental factorial study is not the default continuation. Real-versus-real resampling is optional interpretive support, not a compulsory new benchmark. Additional mechanisms, authors, datasets, cost studies or ablations need a concrete contribution they would substantiate.
