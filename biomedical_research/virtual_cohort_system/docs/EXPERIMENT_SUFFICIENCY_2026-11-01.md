**Decision: the existing experiments support a bounded methods-and-feasibility draft. They do not yet establish reliable quantitative usefulness across biomedical settings. Draft completion and experimental sufficiency for a stronger paper are different milestones.**

The research product remains generated biomedical data and its construction method. Evidence adequacy is judged against scientific uses, not a quota of models, figures, tests or generated rows. Important failures in primary analyses must constrain the central claim; they cannot be dismissed as peripheral limitations.

## One prioritized prospective experiment, if quantitative usefulness is retained

This is a design recommendation, not a frozen protocol or authorization to reset exhausted intake budgets.

1. **Claim:** applicable published evidence can generate reusable joint data with quantitatively useful results for specified biomedical analyses.
2. **Gap:** present real-case evidence establishes directions but not adequate effect scales and variability. Writing alone cannot close it.
3. **Minimal discriminating design:** one separately admitted, genuinely fresh biomedical setting using the same declared construction procedure; relevant external joint/conditional evidence; a reserved measured reference; approximately three scientifically motivated analyses applied to the same frozen release, including an analysis not directly fitted. Record which results are supplied, algebraically implied, assumption-dependent and independently evaluated. If the procedure is modified, version and freeze the modification before target disclosure.
4. **Interpretation before disclosure:** specify meaningful effect scales or contrasts and scientifically justified tolerances where available. Include reference uncertainty and only the distribution/dependence diagnostics needed to interpret those uses. No universal error threshold is imposed. Where a defensible tolerance is unavailable, report quantitative discrepancies without claiming equivalence. A confidence-interval overlap or significant direction alone is not sufficient evidence of quantitative agreement.
5. **Decision and stop:** lock construction count, feedback opportunities, output seeds and every endpoint before execution. Evaluate the entire fixed set once, independently recompute and retain all failures. Support only the uses justified by the prospective interpretation. If the stronger claim fails, narrow it or make a separately justified method decision; do not keep tuning a revealed target, adding seeds or replacing cases to obtain a favorable result.

A successful additional setting would provide bounded prospective validation, not universal validity or automatic venue readiness. The reference sample itself has uncertainty and is not known population truth. More synthetic rows reduce conditional simulation noise, not source uncertainty or the need for measured validation. Agreement is assessed for the intended scientific conclusion or effect scale; exact individual-row recovery or exact equality of every distribution is not the objective.

## Comparators and breadth should serve the retained claim

A transparent statistical generator using the same permitted evidence is a useful comparator when it helps establish what the construction contributes. It becomes necessary for a claim of improved generation over that alternative. A direct-analysis Agent is not a mandatory opponent. Methods trained on unavailable target individual records cannot be treated as equivalent-information comparisons; an oracle setting must be labelled separately.

Evidence ablations, revision contrasts, independent model backbones, multiple biomarkers and additional information regimes are selected only for named claims. If the paper promises reliable enrichment, dynamic variable extension or repair, those promises need their own adequate tests or must be narrowed. The present whole-cohort paper need not validate every optional feature. Conversely, primary quantitative failure cannot be reclassified as an optional feature simply to finish writing.

Use existing historical cases in a clearly version-labelled supplement. Do not combine their counts into a larger prospective validation of the latest method. The mechanism illustration can remain supporting material; another invented test would not fill the present real-data usefulness gap.
