# Evaluator-only analytical validation design

This document discusses exposed development findings. Do not include it in a blinded builder package.

## Follow-up test of conclusion robustness

The M3 age and curvature directions motivate a fresh, blinded experiment. They must not be built into harness defaults or target thresholds. Before opening new target outcomes, the builder should document a small set of scientifically plausible, source-compatible structural alternatives, including where age shapes, dependence and tail behavior are not identified by the papers. Keep generation choices in submitted models, not controller code.

Apply identical reserved analyses to every frozen model, using the same eligible participants and analysis weights. Report point direction, supported/inconclusive reference evidence, effect magnitude, and whether the qualitative conclusion survives plausible model alternatives. Synthetic-table sampling intervals omit evidence/model/transport uncertainty and must not be treated as calibrated evidence of a scientific discovery. A reference interval crossing zero is inconclusive, not a known null. Post hoc new analyses on M3 remain development analyses.

For M3 specifically, the negative curvature endpoint is a quadratic **log-TG** projection over the full analysis domain. Positive linear arithmetic means can induce negative curvature after a log transformation; reproducing its sign alone does not validate a BMI threshold or the entire response curve. The next study should distinguish robust analytical utility from a convenient functional-form assumption.
