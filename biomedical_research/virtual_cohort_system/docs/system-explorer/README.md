# System design explorer

Design/status snapshot dated 28 October 2026. Open `index.html` in a modern browser. It is a standalone Chinese interactive document, not an Agent application or a new experiment.

## Contents

- Five views: architecture, task walkthrough, component responsibilities, validation/results, and contributions/milestones.
- Eight architecture details, three task modes, two generation routes and eight walkthrough steps.
- Embedded complete architecture SVG; the editable original is `architecture.drawio`.
- Local links to implementation, skill, experiment and review records; these links require the original repository layout. The core document and embedded diagram work offline when the HTML is copied elsewhere.
- Printing includes all five views plus the currently selected walkthrough step. It does not print all 48 walkthrough states.

## Status discipline

Implemented M1 interfaces/tools, capabilities executed in older pilots, and planned integrations are separate categories. The M1 program route is statically checked, not executed. Source-statistic checks do not certify that their tables were generated by the frozen code. Source feedback can guide revisions; locked target answers cannot guide the same confirmation run.

No patient-level records or fabricated biomedical results are included. The three displayed HDL endpoints are a labeled subset of the existing eight-endpoint report, not new results or a complete evaluation.

## Checks

`verify_explorer.cjs` uses locally installed Chrome in a new headless context. It checks all five tabs, eight details, 48 walkthrough combinations, keyboard navigation, local links, 20 viewport/view combinations, offline SVG loading and print visibility. Results/screenshots are under `qa/`; they establish presentation behavior only.

After editing/re-exporting the diagram, run `embed_diagram.py` to refresh its embedded copy. Browser QA requires the locally documented Node/Playwright runtime; the document itself has no runtime dependency or network requests.

The HTML and editable diagram were visually inspected. A separate read-only content review checked status boundaries and the displayed HDL values against source records.
