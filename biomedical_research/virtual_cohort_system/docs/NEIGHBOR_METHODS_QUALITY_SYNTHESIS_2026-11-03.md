# Filshtein / SynthIPD：方法差异、生成质量与我们的改进空间

日期：2026-11-03。此次工作是原文、附录可得部分、公开代码和现有实验记录的比较；没有运行新的生成实验，没有重开冻结主实验。两篇前作的成绩为作者报告，不能当成本项目已复现的结果。独立详读记录见 [Filshtein](FILSHTEIN_DEEP_COMPARISON_2026-11-03.md)、[SynthIPD](SYNTHIPD_DEEP_COMPARISON_2026-11-03.md)；具体可执行比较设计见 [公平对照方案](FAIR_PREDECESSOR_COMPARISON_PLAN_2026-11-03.md)。

## 判断

**值得继续比较和改进。有前作会限制“首次”的表述，但质量改进、输入要求降低、可用分析范围扩展、人工建模负担减少，都可能成为方法贡献。** 每一项需要相应的证据，不能仅用系统更灵活或加入了 Agent 来代替。

现阶段我们尚未与原方法完成同场实验，不能判断谁总体更好。现有信息足以说明：三者提供的输入与输出用途存在重要差异，直接比较各论文里报告的误差没有统一含义。

## 先按它们的强版本理解方法

| 方面 | Filshtein 等，2021 | SynthIPD v2，2026 | 我们目前完成的版本 |
|---|---|---|---|
| 主要任务 | 不共享个体记录时合并队列，补充不同研究缺失的混杂变量并分析 | 从临床试验的生存图表与亚组摘要构造可分析记录 | 由不同外部研究的统计证据、目标人群和分析请求构造完整虚拟队列 |
| 输入来源 | 本地分析员可访问源个体数据，按预设依赖关系拟合并交换生成规则 | 同一研究人群的 KM 曲线、风险集信息、亚组统计；可能分散在该试验的多篇报告 | 经整理的外部论文摘要，来源人群与目标人群可不同；另有明确提供目标摘要的开发实验 |
| 核心操作 | 按 DAG 的变量顺序运行条件分布模型，之后合并并插补 | 先重建生存时间/删失，再优化分类协变量配置，使摘要一致 | Agent 选择联合结构、数值参数和补全假设，数值程序采样 |
| 最强证据 | 在来源规则较完整时，指定纵向分析的系数复现很接近 | 在所要求图表与亚组输入充分时，摘要重建精确，并有额外亚组曲线检查 | 数值证据参与生成；多项指定回归方向和部分幅度接近，结果仍有明显局限 |
| 当前不宜直接相比之处 | 专门从原始数据拟合的规则比普通文献摘要信息更充分 | 生存重建与我们的连续生物标志物联合生成不同 | 不能把更少输入、更难迁移自动解释为质量优势 |

Filshtein 的 Step 2 与 Table 1，和 SynthIPD 的 §§3.2–3.2.3 支持上述输入/操作区别。[Filshtein 主文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8338788/)；[SynthIPD v2](https://arxiv.org/html/2509.16466v2)。

我们可以把前作作为强工具接进系统。Agent 负责解析研究条件、选择适用生成模型与需要约束的分析，成熟数值方法负责拟合和采样，是合理实现。最终应评价数据用途，不能因为统计程序承担采样就否定 Agent 的作用；也不能因为 Agent 参与就预先认定更好。

## 质量结果：既要看它们成功的地方，也要看成功的范围

**Filshtein。** Table 3 中，ARIC 的年龄×HbA1c（低于6.5%）系数在真实和合成数据均报告为 −0.055；HRS 均为 −0.047。与此同时，Table 2 的 ARIC 高 HbA1c 组均值/SD 为真实 8.5/2.0、合成 7.4/0.7。来源规则包含结局模型，因此指定模型系数复现并不等于所有亚组分布得到恢复。两类结果都应承认。[原文 Tables 2–3](https://pmc.ncbi.nlm.nih.gov/articles/PMC8338788/)。

**SynthIPD。** N9741 的输入亚组摘要在 Table 4 中复现至报告精度，Figure 5 还对照了未用于构造的 Mayo 亚组曲线，这是有价值的额外检查。复杂的8层、n=1,200场景中，Table 9 在一百万次累计提议预算下的中位生存 mRAE 为0.150–0.213，HR mRAE 为0.068–0.119，随配置而变。这不是其最终选优重建的一项统一误差，也不能与我们的回归系数绝对差异横向排名。[原文 §4.1、Appendix D.3](https://arxiv.org/html/2509.16466v2)。

由此得到的研究判断是：**需要明确“数据质量用于什么分析、利用了什么信息”。** 对公开摘要的匹配本来就是一类有效质量结果；重用同一数据计算新的统计量也有实际价值。进一步在未参与构造的函数、关系或人群上有效，则支持更强用途。不能把这些不同层次合成一个“真实度”数字。

对“未报告分析”还应分三类：从给定曲线可以直接算出的分析，依赖额外联合结构的分析，以及另一个独立样本上的分析。它们需要的验证强度不同。一个统计量没以数字印在论文里，不代表输入图形没有包含它的信息。

## 我们已有的结果也要按信息条件对齐

现有主实验使用外部文献条件，E1 相对 E0 在5/6项回归的构造平均绝对差异上减小，CHNS BMI 增加，部分效应大小仍偏离；固定统计构造也有胜过所有对应 Agent 的端点。这不能证明优于 Filshtein 或 SynthIPD，因为没有运行它们。

另一个已经完成的 CHNS 开发实验明确给了 Agent 30项真实参照摘要。三个作者的三种子均值范围如下：

| 分析 | 样本参照 | 仅外部文献 | 文献加参照摘要 |
|---|---:|---:|---:|
| BMI系数，调整年龄/性别 | 0.054946 | 0.013001–0.034287 | 0.052821–0.055789 |
| 血糖系数，调整年龄/性别 | 0.402093 | 0.356064–0.487815 | 0.396941–0.413715 |
| 年龄系数，调整性别/BMI/血糖 | 0.008107 | 0.003552–0.006910 | 0.007569–0.007947 |

单位分别为 HbA1c 百分点每 kg/m²、每 mmol/L、每年。范围跨三个作者的三种子均值，不是置信区间。参照辅助组确实体现了有效的摘要校准；该实验没有“同信息统计方法”组，故尚不能把改进归因于 Agent 相对统计生成的优势。[完整已完成记录](https://github.com/ziwang11112/evidence-guided-virtual-cohorts-2026/blob/26ccdfb5a77c665ddce1d1c0c73ce991b7107fb3/biomedical_research/virtual_cohort_system/reports/information_revision_ablation_2026-11-03/RESULTS.md)。

与前作对标时，应该同时保留这类一致性结果和外部文献迁移结果。不能只拿前作的同来源拟合质量，去比较我们较困难的跨人群生成质量；反过来也不能把它们能看见更完整信息说成方法缺陷。

## 哪些改进能形成有价值的贡献

| 可争取的结果 | 需要怎样的证据 | 不能用什么代替 |
|---|---|---|
| 同样信息下，分析质量更好 | 同任务、同证据、同反馈权限，比较全部预定分析和失败 | 从不同论文摘两个误差数字直接排序 |
| 少一些输入，仍能支持相近分析 | 在同一任务逐级减少摘要/条件规则，对两种方法做合理适配，并预先定义用途与可接受损失 | 缺少信息的方法仍输出了数据，就叫扩展成功 |
| 连续指标、异质来源或新任务下的可用范围更广 | 相应变量/来源场景的真实参考分析与约束审查 | 接口允许用户输入任意变量名 |
| 更少人工建模工作 | 记录从同一输入到可用数据所需操作、失败、人工更改和总成本 | 仅比较最后采样程序耗时 |
| 缺信息时能识别哪些结论不稳 | 多个符合来源证据的合理模型，对未约束分析给出稳定性/敏感性结果，并检验其提示是否准确 | 把随机种子差异当作全部模型与迁移不确定性 |

这些不是本项目已证明的优势，而是可以检验的增量。更大的虚拟行数可降低某个既定模型的蒙特卡洛误差，但不凭空增加患者证据；“能生成更多行”不是区别这几种方法的强创新点。

## 最近一步：用现有 CHNS 做信息对齐的质量比较

建议先检验一个窄而明确的问题：**当各方都拿到同一套可用摘要时，Agent 方法与合理适配的条件统计生成器，在分析质量及所需人工建模上有何差别？**

第一轮可使用已有的30项 CHNS 参照摘要，比较 Agent 路线与 Filshtein 式条件分布分解的统计适配版。核对实际可见信息，保留相同分析请求、变量单位和全部结果；禁止目标行级拟合。最小方案复用历史 Agent 结果、只增加一个统计构造，必须分别披露历史与新构造的预算，不声称人工成本或搜索预算完全匹配；新流程的操作成本可记录，但历史未计量成本不能补造。此比较测开发条件下的校准质量，不称为新的独立验证。现有固定统计组不能直接改名为 Filshtein 原版。

先把这一轮做成可靠的同信息比较，再判断是否值得进入外部文献稀疏条件。两阶段之间不能把第一轮的目标均值、斜率或选择结果暗中带进所谓文献独立组；现有来源/目标暴露记录继续有效。

SynthIPD 应保留为直接近邻与设计借鉴。其原始算法需要生存图表；当前 CHNS 任务没有相应输入，不能填假 KM 曲线让它失败，也不能把“无法原样运行”算成我们的胜利。若以后明确要进入生存重建，才值得在它原来的合法输入条件下做直接对照；目前没有必要为凑比较换研究领域。

若最小同信息比较显示统计适配版已经解决任务，就把它吸收为 Agent 的数值工具，并收窄比较优势声明；若 Agent 在预定用途上稳定更好，再追问是结构选择、证据解释还是补全策略带来帮助。依据明确提供的参照摘要、按预定规则校准参数是允许的；需要避免未记录的追加调参、只保留优胜结果，或把这种校准冒充独立验证。

本轮只完成阅读、实现审查和比较设计，未进行新的生成或性能对照，也未修改原冻结结果。后续若执行，使用新的开发实验记录，明确任务、预算、比较方法和停止条件。
