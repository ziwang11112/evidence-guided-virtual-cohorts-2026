# Public scope of the v0.12 paper-figure revision

This release contains original manuscript text, an implementation-grounded Agent diagram, native-unit scientific result figures, interpretation guides, the reading/Overleaf package and independent reviews. It changes presentation and explanation. It adds no generated cohort, patient-level analysis, clinical model fitting or scientific experiment.

The fixed allowlist in `export_reviewed.py` contains:

- The implementation trace, independent numerical figure review, figure/guide review, final PDF review, manuscript change audit and completed state.
- Original G-Sim/SPADA and LLMSynthor result-reading notes, the six-endpoint Chinese reading guide, this scope, the exporter and the diagram repair helper. The specifically named original `prepare_manuscript.py` is included only if present.
- The project README, manuscript README, current research-focus pointers, repository-root README template and full `DRAFT_v0_12.md`.
- Exactly five original figures in SVG, PNG and PDF; three figure-building/rendering scripts; two numeric-binding JSON files; `CAPTIONS_23.md`, `CAPTIONS_45.md`, a figure README and `READING_GUIDE_ZH.md`.
- The reading package: `paper.tex`, `paper.pdf`, build script, input manifest, repository README, `OVERLEAF_README.md`, `overleaf_v12.zip` and the five copied figure PDFs. ZIP membership is fixed, and each member must match its corresponding reviewed package file byte for byte. The ZIP's standalone `README.md` is checked against `OVERLEAF_README.md`, which deliberately avoids links outside that package.

There is no new HTML gallery. The editable diagram is embedded in the SVG/PNG/PDF exports and regenerated by its original builder. The intermediate standalone `.drawio` file is not exported. Previous drafts, the v0.11 gallery, frozen protocols and original empirical records remain in repository history and navigation.

Excluded content includes patient-level real/generated records, third-party originals and codebooks, reference-page images, source caches, internal model contexts, credentials, temporary screenshots, logs and rendering intermediates. No directory is recursively copied. Coefficients, uncertainty limits, aggregate summaries, mathematical transformations, provenance paths and hashes remain available for audit; provenance to a local file does not include that file's records.

## Release gates

The exporter requires:

1. A clean existing review checkout at commit `2bf466071c304cb0ce972f64f2fe20385db4701f`, independently checked against GitHub `main` during preparation.
2. `STATE.json` with `status = complete_independently_reviewed`, every required allowlisted file, and passing independent review statuses.
3. Current file hashes matching the independent figure review, numerical figure review and final PDF review. The manuscript change audit must match raw file bytes and confirm unchanged scientific body/tables/references with no new experiments or patient analyses.
4. The reading-copy manifest matching the current Markdown and TeX, and all five copied figure PDFs matching their reviewed originals.
5. Valid PDF/PNG signatures, fixed and safe ZIP membership, credential-pattern checks and resolved public Markdown links.

Missing or stale artifacts cause a failure. No manuscript reference is silently removed to make export pass. Local navigation from `work/` is rewritten to `reports/`; historical report paths are resolved only when the intended existing public file is unambiguous. Historical original bindings are not rewritten to pretend that their source inputs were newly created.

JSON values and whitespace are preserved. A separate export manifest records original local-source hashes and actual exported-byte hashes. These differ when portable Markdown navigation or UTF-8 byte representation changes. Original scientific hashes continue to identify their frozen inputs.

PDF, PNG and ZIP entries are prepared as local base64 payloads. A coordinating publisher must create corresponding Git blobs with base64 encoding and substitute the returned blob hashes before tree creation. Other allowlisted artifacts use text payloads. Payload groups preserve complete files and report exact sizes.

The exporter only prepares payload files and manifests in this report directory. It does not alter the checkout, create remote blobs, commit or push. Preparation of this exporter is not publication; it is not run before the completed state and final reviews. The reading PDF is a generic review copy, and the Overleaf bundle is an editable starting point rather than a certified venue template.
