# Independent implementation review

3 November 2026. Source-free preparation for the live two-request integration.

The original runner bound each stage independently and could have accepted a
different initial model for delivery or an unrelated final candidate. This was
reported before scientific execution. The coordinator added initial/final family
bindings, direct-parent verification, explicit retention and initial-delivery
completion checks. The reviewed runner hash and eight passing control-flow checks
are in `WRAPPER_MOCK_CHECKS.json`. No generator was executed by these checks, and
no table or patient record was read. The first mock attempt failed because the
mock lifecycle object omitted `read_json`; the mock was corrected.

The generated-only diagnostics helper computes every specified coefficient,
HC3-t conditional intervals, marginal summaries and pairwise relationships. It
cannot read a reference dataset. An initial dependency import failed because
Windows Application Control blocked a statsmodels robust-estimation DLL. The
helper now uses the ordinary NumPy/SciPy implementation. Independent QR algebra
checks all coefficients, standard errors and interval endpoints; results are in
`DIAGNOSTIC_SELF_CHECK.json`. No policy was bypassed or package installed.

The reference comparison core uses community-cluster CR1-t intervals for the
selected real cohort. A separate QR score formulation and independent marginal
and rank-correlation expressions matched the main implementation on one bounded
invented in-memory fixture; see `COMPARISON_CORE_SELF_CHECK.json`. These fixture
checks test numerical implementation, not scientific usefulness or accuracy.

`EVALUATION_DEFINITION.json` was frozen before new reference analysis. The final
evaluator requires both authors to close, verifies model lineage and all twelve
declared initial/final slots, and charges every physical attempt. Identical
retained final slots may alias original tables. It writes an exclusive reference
read receipt only after these gates. The original four input hashes and original
pure linkage function preserve the same already exposed CHNS development
population. A separate linkage expression and QR analysis provide independent
recomputation. Previous release controllers and their frozen receipts remain
unchanged.

All clinical inputs and generated rows remain local. Numerical diagnostics are
descriptive; no interval overlap criterion, global score, equivalence threshold
or claim of a new untouched confirmation has been introduced. Generated HC3
intervals exclude model, source and transport uncertainty.
