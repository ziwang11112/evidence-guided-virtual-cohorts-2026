# Wave A production integration

This directory connects the two already designed whole-cohort cases to the existing generator sandbox and source-feedback system. It does not change the scientific questions or provide an Agent's scientific structure, coefficients, noise scale or transport law. Clinical execution remains disabled until the actual global release and designated evaluator are reviewed and committed.

## Implemented path

1. `bundle_assembly.py` verifies the committed K01/K02 inputs and compiler outputs, registers exact selected source artifacts under the coordinator's scoped curator decision, and creates a finite constructor input package. Its mechanical bridge plan copies Agent-authored model choices unchanged and fixes context metadata, rows, seeds and resource limits. The target feedback policy is always `none`.
2. `case_execution.py` requires a durable campaign authorization for the exact frozen stage. It uses the existing isolated execution adapter and retained bridge receipts. Before any numerical feedback, every generated row must satisfy the case guard. K01 applies the correct source/target age population; K02 additionally requires every source row to match its declared sex stratum. Rows are not filtered to make a source statistic available. A failed guard consumes the attempted slot.
3. `k01_sources/k01_sources.py` compiles the 34 selected records and binds eighteen descriptive approximations to successful, verified source executions. Strict semantic-v1 checks remain unavailable where the source estimator is unknown. Raw descriptive differences are separately labelled, never substituted for strict replay, SD-based precision or target validity. The review binds the entire model specification, including assumption prose.
4. `campaign_control/campaign_control.py` fixes one release-bound ledger directory and all constructor/stage reservations, verifies actual frozen bridge/guard artifacts, delivers only source reports, and records one retain/revise/stop decision. Retention aliases the same outputs; it does not generate a favorable replacement draw. Failed, interrupted and unrun slots remain visible. Both cases' complete final inventories must close before a single designated-evaluator disclosure authorization.

The original bridge executes an initial stage's source and target draws in one call. The guarded runner preserves that schedule. Generated target tables, target execution logs, target analyses and the measured reference are not constructor feedback. Source messages are assembled from successful source slots only. A generation-link flag is not a case-validity flag: source feedback also requires the correct guard and successful source slot.
