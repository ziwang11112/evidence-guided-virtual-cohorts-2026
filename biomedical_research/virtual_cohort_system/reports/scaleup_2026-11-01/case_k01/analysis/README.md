# K01 scientific analysis specification

The [exact prospective specification](K01_ANALYSIS_SPEC_v1.json) and [pure analysis](k01_analysis.py) define the same three analyses for every release: adjusted BMI contrast, adjusted age contrast, and the Female-minus-Male BMI contrast difference. They contain no data loader, target estimates, desired signs, calibrated parameters or automatic execution.

All analyses use one common reference subset. The rule retains finite positive released cleaned BMI/glucose, census age at least 40, and verified sex. Native/tagged missing values are excluded before numeric use. No finite numeric nonmeasurement sentinel is documented in the reviewed metadata; the empty sentinel list does not prove none exists. No range, flag, fasting or treatment exclusion is introduced. Unknown nonmissing sex or malformed numerical schema fails the invocation. Generated tables must pass the full context guard and every row must remain eligible; the analysis function independently rejects ineligible generated rows.

The two unweighted OLS designs include an intercept, scaled age, female indicator and scaled BMI; the second adds female-by-BMI. Fixed centering at age 50 and BMI 25 is only a numerical coordinate choice. Both sex levels, more than five rows, and full rank in both designs are required. Failure in either design retains all three unavailable endpoints. A constant response is unavailable under the prespecified rule. Identifiable point contrasts can remain when HC3 working intervals are unavailable because residual variation is degenerate.

Reference-only HC3 intervals are descriptive sensitivity summaries. They do not establish clustering, sampling-design, transport or population coverage. Generated rows receive no inferential precision. The reference glucose sample SD (ddof 1) is an evaluation-only discrepancy denominator; it is not a generation input or population truth.

Report raw contrasts and differences, directions and the complete fixed normalized discrepancy grid 0.05/0.10/0.20/0.30. The working resolution is 0.10 with an inclusive boundary; it is an exploratory criterion, not 10% relative error or clinical equivalence. A constructor passes only when all three contrasts on all three seeds meet the criterion. At least four of all five Agent constructors are needed for the case criterion; failures stay in the denominator. The single statistical reference is evaluated separately with the identical all-use/all-seed rule. If all three zero-effect anchors already lie within the working margin, the case cannot unlock positive Wave B for joint-signal recovery. No endpoint or margin is selected after disclosure.

The new tests use invented arrays. They check closed-form effects, independent statsmodels HC3 calculations in unscaled coordinates, interaction-sign reversal under sex relabelling, distinct rank failures, fixed common rows, generated-output rejection and schema/degeneracy failures. They are software arithmetic verification, not patient evidence. Test outcomes and independent review are recorded in the case implementation checkpoint. A reserved evaluator and authenticated final inventory must still bind these functions to actual frozen outputs before any target access.
