# K01 necessary pure components

These functions process explicitly supplied in-memory objects. They do not load participant data, execute clinical generators, activate source approvals or release the campaign.

`generated_validity.py` checks the entire supplied table against the exact canonical task and one of three fixed context/population pairs. The target requires age at least 40 with no upper limit. MIND requires 61–80; Ayele uses the Methods' 25–64 interval while retaining the table-caption discrepancy. Age is finite numeric in the shared column schema; cohort eligibility is a separate mandatory guard. Every output must have exactly the requested rows, unique nonempty identifiers, F/M sex, and finite positive BMI/glucose. There is no filtering or repair. A context ID inconsistent with the task population is rejected.

The production caller must derive the context ID from immutable execution/child-task bindings and authenticate the approved task, not select a convenient source context after inspecting a table. The returned task/context/frame hashes certify only consistency of supplied objects. They are not execution, source-population or scientific-validity certificates. The same canonical columns allow the existing bridge to change only population/row count across contexts; no frozen bridge was modified.

`source_descriptives.py` adds only the fixed K01 arithmetic needed for seven MIND and eleven Ayele comparisons. It delegates means, sample SD and proportions to the existing source-check operators. Compound bin events are represented by a derived 0/1 indicator over all original rows; bin-negative rows remain in the denominator. A lower-bound selection followed by an upper-bound event would estimate a different conditional proportion and is not used.

The source scenario explicitly assumes equal weights and SD divisor n−1. Ayele age categories use completed-year half-open decades; BMI middle retains the printed closed interval 18.5–24.9 and its gap before 25. Source count ratios and printed percentages remain separate in the admitted evidence view. Source weighting, imputation and selection remain imperfectly reconstructed. These descriptive comparisons cannot change strict `semantic_feedback_v1` checks from unavailable to exact replay. The helper has no evidence values, source discrepancy comparison or approval creation. An execution-backed collector must invoke and bind semantic v1 first, then preserve separately reviewed descriptive approximations.

The statistical reference component, when present, follows its separately reviewed proposal and invented-only verification. No real source fit or clinical sampling is part of this preparation. Before campaign execution, production must still bind the source plan, context guards, strict/descriptive feedback, finite cross-version attempt accounting and reserved reference evaluator. This directory is a bounded implementation step, not a replacement general framework.
