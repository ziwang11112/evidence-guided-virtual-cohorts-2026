# Independent K02 analysis implementation review

2 November 2026. The coordinator reviewed the new pure DataFrame adapter, its prospective JSON specification and the author's 17 invented-array tests. No target participant table or scientific result was accessed. This is implementation review, not a case admission, target-data release or scientific validation.

The code uses one common eligible subset and the same intercept/age/sex/BMI design for both lipid outcomes. Fixed centering and scaling make the BMI coefficient a per-five-unit contrast without changing the fitted projections. HC3 is computed from the relevant pseudoinverse row and squared residual/leverage adjustments. Generated-table calls suppress inferential intervals and reference-only normalization denominators. All three endpoint records survive invalid input or unavailable estimation; singular designs, constant outcomes and degenerate residuals are not silently replaced with a favorable analysis.

An independently constructed 43-row fictional frame, distinct from the author's balanced-factorial fixtures, was checked against statsmodels 0.15.0. The independent implementation used raw-coordinate OLS and its HC3 covariance, then multiplied only the BMI coefficient and its SE by five. Both coefficients, SEs, normal sensitivity-interval endpoints, the residual Pearson correlation and reference ddof=1 outcome SDs agreed within 1e-10; actual coefficient discrepancies were below 1e-12. Exact differences and reviewed code/specification hashes are in [INDEPENDENT_ARITHMETIC_CHECK.json](INDEPENDENT_ARITHMETIC_CHECK.json). No fixture table was saved and no passed suite was rerun.

**Disposition: acceptable as the narrowly specified arithmetic component.** It is not connected to a real-target loader or campaign evaluator. File identity, units, literal NA parsing, column mapping, release authorization and generated-output validity still belong to separately reviewed preparation/controller layers. The mandatory role is a caller declaration, not an access-control system. The function reports generated-row exclusions; a future controller must still reject outputs violating the frozen generation contract rather than exploit those exclusions.

Reference intervals are HC3 normal sensitivity summaries under an independent-observation assumption, not cluster-aware or survey-population confidence intervals. No residual-correlation interval is available. The module's sample SD output is only the reference normalization denominator; it does not implement the full future distribution-diagnostic report or the 0.10 case-level criterion. The original scientific-use proposal and exposure qualifications remain in force. No target means, slopes, signs or desired generative parameters were introduced by this review.
