## Findings and corrections

An independently reproduced preflight gap initially allowed a source context outcome with a different numeric unit to enter the assumed lane under `transform: nonidentity`. The strict result was unavailable, but the parallel calculation could have compared an unconverted number to the printed source unit. The final implementation rejects that mismatch. It requires a specified source operator, verifies all source analysis operand units against the child columns, retains the original nonidentity binding, and restricts its nonidentity assumed route to OLS with an explicitly checked standardized coefficient term. Predictor identities must cover every selected operator row. Known role, adjustment, selection and definition mismatches still reject the whole request before reservation or execution.

The controller initially checked only the sum of declared objective counts and the presence of an author-seal file. It now validates each count as a nonnegative integer, restricts candidate names before reads, checks the combined initial/revised objective allowance, and binds target release to the submitted candidate freezes, a retain/revise decision, the author's decision artifact, and the complete retained source-report inventory. Every retained source report is reverified, including its child execution and recomputed diagnostics. Authoring and retrieval actions close after sealing.

Acquisition initially had potentially separate literature and web allowances. The final controller rejects the literature action and combines native discovery reservations with metered web HTTP attempts under the remaining-five allowance. The final session configuration uses zero redirects, so one web fetch cannot consume multiple HTTP attempts and overrun that combined allowance. Failed native reservations are not refunded; the web adapter charges attempts before I/O. The declared cumulative response-byte allowance subtracts the previously recorded source bytes. Native search result transport remains unmetered and must remain separately labelled, as specified in the parent source audit.
