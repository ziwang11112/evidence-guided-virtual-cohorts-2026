# M13-A source-only execution plan

Fixed before construction or source execution on 30 October 2026.

This step uses real published summaries from two externally screened papers, but no real target participants or target measurements. The observed input is an explicitly invented qualification grid. Source-context rows will also be simulated covariates, not recovered patients. No successful source check establishes target analytical utility.

Two fresh, separately instantiated construction Agents receive the same screened sources and interface contract. They independently choose model structure, individual variation, source covariance assumptions and numerical parameter ranges. No existing scientific generator is supplied. Source-specific population support is handled by the existing v2 source context adapter. Deterministic inverse-BMI/interaction columns permit the original Gallagher estimator without a new regression engine; they assign no effect to a variable.

The primary source diagnostics are the Thai development sex-specific mean, SD, BMI correlation and four adjusted equation terms, plus all eight Gallagher DXA equation terms. Each constraint remains visible. Thai validation statistics are not fitting constraints, but are present in source evidence and hence are not described as unseen to the builder. Both sources' covariate joint distributions are incompletely reported; all reconstructed source checks are approximate. Source reconstruction must not use target results.

Each builder receives at most two numerical sessions, nine parameter trials per session, two fixed fitting seeds and two different replay seeds; at most two source contexts. A bounded coordinate search chooses a numerical trial under fixed engineering unit scales. These scales are not source standard errors or a likelihood. A zero stopping loss is used only as an exact-fit stopping rule, not as a clinical acceptance criterion. Nonzero scores and source contradictions are retained. Each bundle permits one scientific revision after feedback; justified retention and stopping are valid. A successful claim of revision requires actual changed scientific code/parameters, not only provenance bytes.

Actual execution uses the pre-existing WSL/bubblewrap generator adapter. The parent does not import generated Python on the host. The Agent's tool access is procedurally restricted and is not an OS sandbox. Construction requests, manifests, source receipts, numerical sessions, review decisions and retained outputs are recorded. A session that errors is inspected rather than silently replaced to reset its budget.

At the end, report actual constructions, executions, all source discrepancies, changes/retentions and implementation findings. Do not choose a winner or infer improved target performance from source loss. If the loop works, the next step is to freeze a real-data protocol, derive a target release with identical scientific bytes and evaluate separately. The proposed real primary population is adults20–59, non-Hispanic White/Black, BMI18.5–<30, valid total-body DXA; BMI30–35 is a separate extension. Target packet acquisition and inference remain outside this source-only step.
