## Search boundaries

- Canonical classification excludes duplicate GitHub mirrors/reports, tests/fixtures and raw/private/patient files. Filenames and metadata identities are not participant observations.
- ENSANUT occurs as an incidental comparison in an unrelated cached medRxiv metadata batch; NHIS in shared mortality documentation; Raine as a UC-guideline author surname. These do not establish local adult metabolic cohort analyses.
- No positive role was established for NHANES 1999–2002 or separate 2019–2020. The prohibited 2017–March 2020 pooled release overlaps exposed 2017–2018.
- Before admission, search exact study name, aliases, DOI/accession, release identifiers and filenames, check local file identity, and resolve uncertain prior use. The inventory cannot establish zero pretrained or undocumented exposure.
- Only this Markdown and its JSON companion were written. The old exposure registry, historical results and state files were left unchanged.
