# Public review snapshot

This snapshot contains the authored model and evidence metadata, generation/controller/evaluation code, fixed protocol, actual execution and feedback records, complete aggregate comparisons, independent reviews and an original aggregate figure. It does not contain patient-level real or generated tables, full third-party papers, or credentials.

The historical aggregate reference already exists in this repository. The current comparison reuses it after author closure and does not decode or refit patient data. One initial model produced four physical tables including its trial; three final deliveries alias the initial outputs.

This is an audit snapshot, not a standalone installation or automatic rerun package. Program execution requires the task-bound source registry, exact admitted source bytes, existing isolated runtime and explicit local bundle paths. Original source articles can be located using the DOI/URL metadata, but a partial publisher render is not represented as a freely redistributed full article or as gateway approval. Patient/generated-row files remain local under the project's sharing policy.

Public Markdown navigation is adjusted to the export layout. PUBLIC_EXPORT_MANIFEST.json records local-source and public-byte hashes separately. Embedded frozen/execution hashes describe the original local bytes and are not rewritten into fabricated public execution receipts. The immutable evaluation report records its review status at evaluation time; INDEPENDENT_NUMERICAL_REVIEW records completed independent checking afterward.

Raw source-feedback comparisons are explicitly approximate comparisons against the generated target table, not reconstructions of separate source populations. Retention, unavailable checks, weaker effects and conflicting results remain included. No universal accuracy, clinical replacement, causal, cost-saving or revision-gain claim is attached to this snapshot.
