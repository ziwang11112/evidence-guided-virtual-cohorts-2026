Prepared 3 November 2026. Metadata and executable arithmetic are bound for
review; clinical execution remains disabled. This is a new developmental reuse
comparison on an exposed target, not a fresh confirmation or a restart of an
old budget. All scientific parameters remain constructor choices.

- `case_card.json` is the curator/reviewer contract, including reference
  identities copied from prior metadata without opening target reports.
- `E0.json` and `E1.json` are byte-identical previously approved sanitized
  source packets. `provenance.json` binds every record and short locator to
  the approved origin. These are curator-derived packets, not paper copies.
- `E0_evidence.json` and `E1_evidence.json` are the unchanged reviewed
  compiler's lifecycle-schema translations, with 32 and 36 items respectively.
  E0 has no numerical relationship record. Each arm registry points only to
  its own sanitized packet and unit note. Copy the matching `E0_sources` or
  `E1_sources` contents to the constructor's `sources` directory; never copy
  both arms or broad original summaries. `packet_scope_audit.json` records this.
- `task.json`, `evaluation.json` and `AUTHOR_COMMON.md` are common author
  inputs. `author_allowlist.json` fixes the arm-specific read boundary.
  `E0_agent_profile.json` and the three other arm/kind profiles match the
  global two-trial/three-final session budget and seeds.
- `source_operations.py` supplies pure analytic Jansen covariance projections
  and Bao Pearson calculations. Inputs must be law-derived moments AFTER
  declared source selection; arithmetic success is not evidence that the law
  or population reconstruction is valid. Ordinary moments do not identify
  MIND Spearman. All strict replay remains unavailable. No source tables are
  allocated here. `source_operations.json` records contextual qualifications.
- `generated_provider.py:evaluate_generated(bundle,candidate,run_id,profile)`
  verifies a successful frozen output and calls the unchanged F2 pure analyzer
  with `reference=False`. It returns three analyses, 27 diagnostics, quality
  and n; it never loads a target reference. Reuse its `generated_statistics`
  function only for already-supplied invented or authorized generated frames.

`verify_case_binding.py` checks invented deterministic arrays and task schema,
without clinical sampling or patient access. `arithmetic_verification.json`
records those author checks, not independent approval. `build_case_binding.py`
rebuilds only this case directory from approved metadata; never invoke old
scientific entrypoints. `binding_validation.json` records the current file
commitments. Independent semantic/arithmetic review, comparator binding and
the common immutable campaign release remain required.

`curator_exposure_note.md` discloses an incidental historical-result sentence
seen while locating implementation documentation; its numbers never entered
these new files or any scientific choice. All author packets exclude that note
