## Remaining blocker

Both primary providers instead read generated CSVs through `cohort_harness.lifecycle.read_table`, whose line 137 explicitly uses `float_precision="round_trip"`, `keep_default_na=False` and `na_values=[""]`. Pandas' default float parser and its round-trip parser are different numerical transport conventions and need not recover the same binary floating-point value from a serialized decimal.

The audit's line 315 requests exact comparison for every quantile endpoint. For ENSANUT's inverse empirical CDF, the returned quantile is an actual parsed observed value. Even when the compensated cumulative masses select the same observation, differing decimal-to-binary parsing can therefore trigger a value mismatch. It can also perturb other downstream calculations. The newly added fixtures pass arrays directly into the numerical functions, so their retained success does not cover this file-ingestion path. No real row or result was opened to determine whether any particular scheduled output encounters this defect, and no numerical experiment was run during this review.

The minimal correction is to give the independent reader the same pinned CSV float/empty-field transport semantics while retaining its independent arithmetic. Loosening the quantile comparison tolerance would not correct this defect. A revised, separately bound implementation is needed before claiming that v2 can certify exact quantile agreement on retained output files.
