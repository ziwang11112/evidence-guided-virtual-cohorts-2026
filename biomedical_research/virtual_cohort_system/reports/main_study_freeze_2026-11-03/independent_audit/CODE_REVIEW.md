This is a static implementation review before common target evaluation, not a result audit. The existing three passed tests were read as code only. No frozen code was edited.

## Findings

1. **Weighted quantile convention differs (blocking).** `independent_audit/recompute.py:34–37` computes ordinary `np.cumsum(weights[order]) / weights.sum()` and searches for `probability`. The pinned ENSANUT engine's `weighted_quantile`, lines 125–160, instead accumulates the sorted original weights with Neumaier compensation and searches for `q * cumulative[-1]`. The original convention explicitly forbids interpolation, midpoint handling and added tolerance. Both intend a left inverse CDF, but their floating-point cutoffs are not equivalent: at a cumulative-mass boundary one can select the adjacent order statistic. Fixed 3,000-row/eight-cell allocation does not justify changing the prescribed accumulation rule. The existing three-value quantile test does not cover this difference. The independent implementation needs to honor the prescribed compensated accumulation/normalization before numerical agreement can be expected. No numerical counterexample was computed during this review.

2. **Required summary coverage is not independently certified.** At `recompute.py:158`, the audit loops only over contrasts already present in the report. An empty or incomplete `agent_information_contrasts` list is not rejected; required case/endpoint coverage is not checked. The code correctly derives the complete-case E1-minus-E0 value by averaging three seed absolute discrepancies within each constructor and then five constructors within each arm. However, it does not compare `construction_summaries`, the arm counts/means, or the explicitly reported `incomplete_available_value_contrast`. Its 72-slot check verifies length and unique `(constructor_id, seed)` pairs rather than equality with the release's exact expected constructor/seed product. Endpoint category lengths are checked without exact ID-set coverage. These are gaps in the stated failure/constructor-first audit scope, even though the reviewed primary evaluator builds the intended structures correctly. At minimum, required slot and contrast identities should be independently established; unverified summary fields should not be presented as audited.

3. **Provider failure is conflated with arithmetic disagreement.** `recompute.py:137–147` decides whether to recompute only from `execution_status == 'success'`. In the primary evaluator, successful generation can legitimately coexist with `analysis_status == 'provider_error'`, a retained error, and unavailable endpoints (`evaluate_main.py:163–177`). If independent arithmetic succeeds on that output, the audit expects computed primary endpoints and marks every unavailable endpoint as `generated_statistic` mismatch. The failure has been truthfully retained by the primary; it should be explicitly classified as provider failure/independent computability rather than an incorrect numeric estimate. This matters for interpreting a future audit report, and it must not lead to replacing unavailable primary results or retrying an analysis.

## Checks that agree by inspection

CHNS E1 is the BMI coefficient in HbA1c ~ intercept + age + female + BMI; E2 is the glucose coefficient in HbA1c ~ intercept + age + female + glucose; E3 is age in the joint BMI/glucose-adjusted model. These match the approved original analysis-plan metadata, `_MODELS`, the pure `analyze/_fit` path, generated provider and independent designs. They are unweighted raw projections with preserved units. For the task's fixed 3,000-row outputs, the independent rank rule agrees with the original default matrix-rank gate; QR is an appropriate independently implemented solver for the same full-rank least-squares problem. Sample SD uses ddof=1, marginal quantiles use linear interpolation, and Spearman ranks use average ties in both paths. Constant-pair correlations are unavailable.

ENSANUT uses the four age bands [25,40), [40,55), [55,70), [70,80), crossed with female 0/1, with 375 generated rows per cell and weights 1/(8*n_cell). The scaled design is intercept, (age−50)/10, female, (BMI−25)/5, (glucose−100)/10. Q1 is full-model age; Q2 is reduced-model BMI without glucose; Q3 is full-model BMI. The BMI coefficient difference, age/sex-adjusted glucose coefficient, weighted residual RMS, weighted means and population SD definitions agree. Positive finite scientific fields, integer age, glucose below 126 mg/dL and all eight cells are required. No invalid rows are deleted. The independent default rank threshold agrees algebraically with the engine's max(shape)*epsilon*largest-singular-value threshold; the original additionally checks the fitted solver rank and finite coefficients. Quantiles remain the blocking exception above.
