# Source-only identifiability pilot: independent design review

Date: 2026-10-29. Scope: approved source evidence, candidate scientific specifications, and source-only replay diagnostics. No patient rows, target outcomes, historical target evaluations, root README, or target associations were read. No scientific candidate was executed or changed in this review.

## Recommendation

Run one bounded, source-only attempt to construct **two materially different conditional laws with the same prespecified source constraints**. Prefer analytic preservation of source functionals to an optimizer that trades discrepancies across statistics. Freeze the pair, the source gate, the independent synthetic probe grid, and the complete run schedule before new candidate execution. Stop if the pair does not survive; failure does not prove identification.

The permissible conclusion is conditional: the retained source summaries and declared source-population reconstruction do, or do not within this finite attempt, distinguish these two laws. This does not establish source-population compatibility, target validity, causal identification, or a probability distribution over models. A law that merely reproduces an imperfect reference's diagnostics must be described as reference-equivalent, not as exactly reproducing the papers.

## Freeze a finite protocol

1. **Commit scope and provenance.** Hash the evidence, operators, complete source recipe, source-covariate artifacts, assumptions, candidate-family definitions, gate script, seed schedule, and synthetic-probe specification. Preserve the papers' original units, boundaries, selections, and estimands. Declare every analytic calculation and whether it approximates a finite-sample replay operator. Use the identical source recipe and assumption descriptions for the pair. A changed source joint-distribution assumption is a separate prespecified sensitivity, not a generator improvement.

2. **Separate constraints from diagnostics before fitting.** List the exact source point anchors intended for preservation, including their published display precision, and all remaining diagnostics. Retain all 34 TG-dependent checks, the 12 input invariants, and all unreplayed evidence. Do not count the input invariants as evidence of biological fit. Do not combine means, slopes, ranks, and probabilities into an unweighted success score.

3. **Use a finite construction budget.** Minimum: one reference and one prespecified alternative, one structural knob and one fixed nonzero amplitude, with nuisance calibration only. Freeze parameter bounds, initialization, deterministic solver, maximum evaluations, integration orders, and numerical convergence rule before evaluating new candidate outcomes. Allow no adaptive structural-amplitude search, model-family replacement, or tolerance enlargement after failure. Algebraic solution or a fixed deterministic root solve is preferable. If an optimizer is necessary, retain all evaluations and failures.

4. **Verify source behavior before structural probes are interpreted.** First check contracts, frozen bytes, input preservation, finite output, supported estimators, and source-generation linkage. Then apply the frozen source rule to every scheduled diagnostic and the semantic audit of unreplayed evidence below. An undefined statistic or failed required execution is a gate failure, not permission to omit that check. Evaluate the synthetic conditional probe only for candidates meeting the declared source rule; release no real-target result to builders.

5. **Use one complete stochastic schedule as a check.** Reserve, for example, paired seeds 77101, 77102, and 77103 for both candidates, subject to the controller confirming no identifier conflict before commitment. Every source context uses each seed. Do not select a favorable draw or add seeds until a desired result appears. This schedule describes residual/latent-draw variation and implementation behavior, not clinical-evidence uncertainty. If it cannot resolve a near-boundary numerical classification, report the result as unresolved and stop this attempt.

6. **Keep a decision record.** Record exact-anchor agreement, every raw discrepancy, the Table 3 CI-location diagnostic, Monte Carlo spread, structural separation, support limitations, and the final retain/stop decision in a source-only artifact. Freeze this decision before any future evaluator obtains or reveals target results. A later real-cohort evaluation needs a separate protocol and cannot revise this gate retrospectively.

## Two defensible meanings of a source gate

**Preferred: point-constraint preservation.** For each explicitly named anchor, show algebraically or by a converged deterministic calculation that both models produce the same functional, ideally the published point value within its stated rounding precision. Numerical error tolerance must concern the computation, not invented source uncertainty. Publication rounding is not a confidence interval. Equality of five fitted anchors cannot be presented as equality of the full 34-check vector. All other diagnostics remain visible and subject to the separately frozen descriptive rule.

**Fallback: a descriptive noninferiority envelope.** Designate a reference before new runs, without choosing it using target results. A concrete rule requiring no invented sampling SE is to compute, for each outcome-dependent check j, `E_j = max_s |T_reference,j,s − y_j|` from its already verified, completely retained source portfolio, and freeze the resulting numeric table. Require every scheduled new candidate draw to satisfy `|T_candidate,j,s − y_j| <= E_j`, apart from a separately specified machine-comparison tolerance. Report all violations. The rule is deliberately a finite descriptive screen; its strictness and seed sensitivity are part of the result. Do not enlarge it after a failure or interpret passing as statistical equivalence. The 12 covariate-only checks must be identical across the pair rather than receiving fit credit.

This fallback can inherit substantial reference mismatch. For example, the permitted `s1_final_portfolio.json` has Bansal Q25/median/Q75 means 76.685/111.585/162.296 versus 81/115/169, and age rank correlation 0.1440 versus 0.18. Reference-equivalent alternatives would therefore demonstrate that the chosen descriptive screen fails to identify a conditional law, not that both laws have been statistically accepted by the published studies. A calibrated multi-statistic acceptance region is unavailable from the present extraction and joint-covariate information.

## Where genuine structural freedom can come from

Vary a dependence feature absent from the retained summaries, not a cohort name, assay flag, record ID, or off-support trigger. Suitable directions include age–BMI interaction or sex-specific allocation of a pooled BMI slope. Altering an assumed source age–BMI copula is a distinct reconstruction sensitivity and should not be silently mixed into the primary structural comparison.

The source designer's bounded density interaction is the stronger minimum construction. For males, let `f_plus/minus(y|a,b) = f0(y|a,b) +/- delta*hA(a)*hB(b)*hT(y)`, with bounded contrast functions hA and hB centered under the frozen independent source marginals and hT integrating to zero. If all densities stay nonnegative, integration over BMI preserves the entire age–TG joint law, and integration over age preserves the entire BMI–TG joint law. Thus all marginal means, SDs, category probabilities, arithmetic/geometric age and BMI stratum summaries, and the adjusted linear coefficient's covariance inputs remain invariant. Females can remain unchanged. Conditional age–BMI interaction can differ despite these invariances; no overall association is required to change sign.

Audit conditions are substantive: hA and hB must have zero expectation over the actual source marginals and must vanish outside their declared active supports. An indicator minus a global probability does not vanish outside the indicator interval. A full product quadrature permits exact centering; a randomly permuted finite source table only approximates independence, so its invariance must be checked rather than asserted. A changed context is explicitly a new common recipe, not byte-equivalent to the historical source comparison. Preserve a complete proof of normalization, nonnegativity, and pairwise invariance.

For the proposed equal-width TG bands 70–120 and 140–190 mg/dL, each uniform density is 1/50. A certified lower bound m on the reference density over all active covariate cells and both bands permits `delta = 0.6*50*m`, when `|hA*hB|<=1`: the perturbation density lies between 0.4 and 1.6 times the reference there. A dense-grid minimum is not a certificate. For a constant-CV lognormal reference, log density is jointly concave in log TG and log conditional mean, so extrema of the conditional-mean range and endpoints of each TG band provide a valid minimum over the enclosing rectangle. The reference soft positive mean must be included in those extrema. The resulting difference of conditional means has magnitude `140*delta*|hA*hB|` mg/dL. If the positivity-constrained delta gives insufficient prespecified separation, stop; do not inflate it after observing the probe.

A global latent age-score rotation can preserve the BMI–TG joint law under an independent source construction, but it can change the published age–TG relationship. It is therefore weaker than preserving both pairwise laws. Within-age-stratum rotation can preserve more of the retained information, but finite age ties, nonnormal scores, and age-adjusted OLS still need review.

A projection onto the null space of source moment sensitivities is another candidate-generation method. First-order orthogonality is only local: a finite perturbation can move quantiles, bins, dispersion, or ranks. It needs the same full replay gate. A perturbation supported only outside the declared source support demonstrates extrapolation freedom, not in-support failure of the source summaries to distinguish conditional structure.

## Unreplayed evidence is still evidence

The 23 `source_checks.json` entries marked not computable comprise 20 Oh Table 2 TG summaries and three differently adjusted/paired BMI estimands. They cannot be treated as no restrictions. Oh male age strata <=29, 30–39, 40–49, 50–59, and >=60 report TG summaries 143, 147.5, 140.6, 143.5, and 128.1 mg/dL; their counts are 127, 360, 212, 154, and 176. The female summaries are 78.1, 80.7, 89.4, 127.8, and 135.3. The narrative describes age increases in women, not men. Arithmetic/geometric ambiguity does not erase that pattern.

Freeze an explicit coverage audit before execution: show the model's arithmetic and geometric stratum summaries as two labeled interpretations, without relabelling either as the reported estimand; preserve the table values and original ambiguity. Under the declared independent covariate construction, a strongly increasing male conditional law can increase both summary types and conflict descriptively with the table. Without uncertainty this is not a calibrated statistical rejection, but it prevents an all-evidence-compatible claim. If the 46-check gate passes while this semantic audit reveals conflict, classify the result as a **diagnostic-coverage counterexample**. If the bounded interaction preserves both pairwise laws, it preserves these alternative interpretations between candidates, but any pre-existing reference mismatch remains. The three unavailable adjusted/paired estimands remain unassessed; neither alternative is declared compatible with them.

## Analytic calibration and the independent probe

For a conditional lognormal law, conditional moments and threshold probabilities are available directly: `E(Y|x)=exp(eta+sigma^2/2)`, `E(Y^2|x)=exp(2*eta+2*sigma^2)`, and `P(Y<t|x)=Phi((log(t)-eta)/sigma)`. Integrating these over the fixed synthetic source covariates avoids optimizing Monte Carlo noise. OLS coefficients follow from the frozen design matrix and conditional mean. Reverse-conditional age/BMI moments use bin probabilities as weights; marginal quantiles invert the mixture CDF. Rank statistics require their own tie-aware calculation or replay, not substitution of a linear correlation. Finite-sample SD/quantile/rank operators need explicit finite-sample approximations even when population functionals are exact. Fixed nested integration orders can expose numerical error without being mistaken for source uncertainty.

Freeze a small independent Cartesian covariate grid before probe calculations; for example sex in {male, female}, age in {30, 40, 50, 60, 70}, and BMI in {20, 25, 30, 35}, with common weights and measurement mapping. Call this support **within the declared reconstruction support**, since empirical joint support is unknown. Report conditional means, medians, exceedance probabilities, and an age–BMI contrast, with analytic expectations wherever possible. A difference in conditional distributions can matter even if a single adjusted slope has the same sign.

If a binary materiality rule is required, freeze an operational magnitude in advance, e.g. at least a 10 mg/dL conditional-mean difference at four named grid cells, or a 0.05 exceedance-probability difference at four named cells. Choose one primary rule before runs; these example magnitudes are sensitivity-design choices, not clinical thresholds or evidence-derived acceptance bounds. Report the whole grid and do not select the four cells after seeing results. An off-support-only difference and an in-support difference receive separate labels.

## Stop and claim limits

Stop this finite attempt if no second law passes every frozen source requirement and the prespecified structural-separation rule; if exact invariance fails; if any required computation is undefined; if the execution backend is unavailable; or if keeping fit requires changing source assumptions or widening the envelope. Do not fall back to unsandboxed generator execution. Report whether the obstacle was construction, source discrepancy, numerical precision, or insufficient separation. A failed bounded search does not establish uniqueness. A passing pair establishes a constructive, assumption-conditional ambiguity for the retained source functionals, not universal nonidentifiability or validated target inference.
