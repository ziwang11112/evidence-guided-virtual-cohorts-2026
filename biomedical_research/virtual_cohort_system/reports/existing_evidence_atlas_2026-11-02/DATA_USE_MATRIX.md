# Existing data and results: contribution-use matrix

Prepared 2 November 2026. This is a bounded synthesis of local protocols,
completion reports, acquisition audits and aggregate result descriptions. No
participant/generated table was opened, no scientific analysis or experiment
was run, and no campaign budget or frozen artifact was changed.

The immediate objective is to make the existing data product and scientific
uses visible in the paper: **published evidence and a population request become
a reusable joint virtual dataset, with its construction and assumptions
documented**. Complete-cohort generation with no individual input is central;
observed-covariate enrichment is a distinct, supported information regime.
This follows [current research focus](../../docs/CURRENT_RESEARCH_FOCUS.md) and
the [contribution-to-evidence map](../../manuscript/CONTRIBUTION_EVIDENCE_MAP_2026-11-01.md).

The three completed whole-cohort cases should lead the aggregate atlas. The
other measured datasets supply existing evidence about optional conditioning,
transport, comparison and revision; their number is not a count of independent
confirmations of one unchanged method. Historical pending-status text does not
override a later release/closeout. All revealed references remain closed to
tuning and fresh-confirmation labels.

## Contribution keys and priority

- **C1 — Complete joint-data construction:** produce all requested variables
  from admitted study evidence and a population description without giving the
  constructor individual measurements.
- **C2 — Study-conditioned evidence translation:** show how population,
  measurement, adjustment, source uncertainty and explicit assumptions shape a
  scientific generator. Source fit and target analytical use remain separate.
- **C3 — Reusable scientific analysis:** apply several declared analyses to the
  same frozen virtual release, retaining both usable relationships and failures.

**P0** is main Results material available now. **P1** is supporting Results,
Methods or a development appendix available now. **P2** is an existing
preparation asset or prospective gap, not a completed scientific result. These
priorities concern presentation, not new execution authorization.

## What to assemble now

1. **Main Table 1: three completed no-individual-input cases.** Include target
   definition, admitted evidence, generated variables, independent
   constructions, unique output tables, retained aliases, reference n and
   analytical questions. The three cases provide **six scientific
   constructions and eighteen unique target tables**, not eighteen clinical
   validations. Each has one measured reference. Keep method/version labels.
2. **Main Figure: case-separated analytical-use atlas.** Present the existing
   locked analyses from each case's aggregate report, including magnitudes and
   failed/inconclusive quantities. Do not silently drop M17-B curvature and
   interaction because their reference intervals span zero. Distinguish
   M17-B HC3 intervals, ENSANUT empirical cluster-resampling stability bands,
   and CHNS CR1/t reference intervals; they are not interchangeable estimates
   of one common uncertainty quantity. Generated seed ranges remain separate.
3. **Main Table 2 / Methods example: evidence → scientific choice → shared
   dataset → analyses.** Use a few existing construction records: M17-B's
   reverse-projection covariance translation, ENSANUT's shared source/target
   construction with approximate source checks, and CHNS's two structures and
   explicit proxy distinction. Label reported, derived and assumed quantities.
   These are concrete method operations, not claims of a new statistical
   identity or a universally correct population bridge.
4. **Adjacent diagnostic table.** Reuse existing means/SDs and dependence
   summaries where available. Positive association directions must be read
   alongside narrow dispersion and weak or excessive effects. Preserve the
   no-revision findings for all three whole-cohort cases.
5. **Bounded supplement.** Put the M10 enrichment results in a separate input
   regime; use the conditional-evidence illustration and a concise development
   table for Rich/NAGALA and interventions. Avoid turning the paper into an
   inventory of every folder, code check, endpoint or stochastic draw.

These actions reorganize and visualize **already reported aggregate outputs**.
They do not reopen a patient table, create a new endpoint, regenerate a cohort,
fit a model, introduce a retrospective equivalence margin, or establish a new
cross-case success criterion. Do not combine heterogeneous effects into a
single accuracy score or retrospectively choose the best constructor.

## Remaining scientific gap versus remaining presentation work

The current evidence can already demonstrate construction of reusable joint
data and selected analytical uses. Making that evidence legible requires the
atlas, complete case denominators/units, scientific-choice examples and clear
boundaries—not additional raw-data processing.

The gap for a stronger claim is **prospectively specified quantitative
usefulness under defensible external transport and model assumptions**. The
existing whole-cohort results do not establish reliable magnitude recovery,
calibrated source/model/transport uncertainty, or a generally beneficial repair
policy. A future experiment would address a stated retained claim under its
own admission, frozen uses and stopping decision. It is not an extra task
created here, and a new loss, Agent architecture or victory over a direct
Agent is not a prerequisite for the current data-generation feasibility paper.

Existing raw data may remain useful for separately authorized developmental
work, but “reuse existing data” does not mean “fit a generator to revealed
targets.” A new folder, endpoint, seed or split does not restore freshness.
No prior target is released for retuning by this document. The current larger
campaign's budget and release gates remain unchanged.
