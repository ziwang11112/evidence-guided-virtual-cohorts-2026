# Current method implementation

Status at writing, 3 November 2026: source execution and branch decisions are complete; the independently checked target analysis-use profile is pending. This note does not anticipate target findings. The final RESULTS document will supersede this status.

The implementation tests the feasibility of translating published evidence into reusable biomedical data that support several analyses. Its product is a frozen whole-cohort generator and associated joint-distribution specification, with explicit evidence links and assumptions. Each draw produces 3,000 complete rows containing age, binary female membership, BMI, fasting glucose and HbA1c. No participant observations are supplied, preserved or reconstructed. Numerical source feedback versus self-review is a secondary question about scientific decision-making within this evidence-to-data workflow.

The approved evidence packet is fixed: Jansen's separate adjusted HbA1c projections, Bao's glucose–HbA1c Pearson association, MIND's serum-glucose–HbA1c Spearman association, contextual population summaries, and NGSP/IFCC unit guidance. An Agent chooses a joint law, its parameters, dependence structure and transfer assumptions; the evidence does not uniquely determine these choices. Evidence items, individual standard deviations, published intervals, derived identities and unreported quantities retain their distinct meanings. The generator specification separates shared parameters from source-context inputs and a target context, so source agreement and target transfer can be examined within the same explicit construction.

This continuation introduces **zero new initial scientific constructors**. It reuses two laws previously authored by separate Agents. The earlier release closed before generation after an interface admission failure; all its 72 planned allocations remain aborted unrun. The new release preserves that history. A01 uses an additive associative construction: BMI contributes to glucose, and glucose contributes to HbA1c with independent residual variation and no direct BMI term. It shares the corresponding coefficients across contexts, uses bounded uniform innovations in Jansen, and centered gamma innovations in Bao, MIND and the target. Its target biomarker settings use MIND as an explicitly assumed analogue. A02 uses a triangular factor construction, with bounded affine uniform factors in Jansen and Gaussian factors underlying lognormal BMI/glucose and shifted HbA1c elsewhere. Bao's Pearson and MIND's Spearman relationships enter through different distribution-specific identities. Its target combines Bao margins, MIND pair dependence and a Jansen latent association under declared transfer assumptions. Both constructions assume age/female independence; neither treats that assumption as evidence of a null age effect.

Scientific choices remain distinct from deterministic preparation. Root's sole initial correction added the existing HbA1c-percent measurement alias and changed two Jansen conversion inputs to that native name. Generator, complete scientific specification, evidence, final-law and support declarations remained byte-identical. New local parent/retain freezes record administrative reuse without creating independent constructions. Hash binding, metadata validation, context derivation, native-unit conversion, statistic calculation, allocation accounting and execution are deterministic tooling. Independent reviewers assess the actual law/code correspondence, moments, support and scientific interpretation; a metadata checker does not choose a scientific model or grant approval.

Each admitted version has three source draws in each of Jansen, Bao and MIND, using the same fixed source seeds. Context changes preserve generator bytes and the shared specification while selecting the declared population and measurement context. Qualified diagnostics compute two separate intercept-including Jansen regressions with age/binary-gender adjustment, Bao Pearson, and MIND Spearman with average ties. Jansen HbA1c is viewed on its native IFCC scale. Plasma/serum distinctions and unresolved source weighting, preprocessing and selection remain explicit. These are assumption-qualified comparisons; strict replay remains unavailable. Target eligibility requires successful source executions, retained support checks and computable qualified comparisons, but does not impose a source-fit threshold.

Four fresh branch authors then received separate immutable packets: self-review and numerical-source-feedback branches for each inherited law. Self-review received evidence, the accepted initial artifacts and common requirements. Feedback authors additionally received authenticated initial source statistics and eligibility information. Each author had one retain/revise/stop decision and bounded schema-only returns. Static algebra, code inspection and metadata checking were allowed; generator import/execution, simulations, fitting pilots, optimizers, fresh evidence searches and target-result access were prohibited during authoring. Final branch source feedback was withheld until decisions were irrevocable. These are procedural information boundaries for author tools; the separate generator execution adapter supplies process isolation.

**All four authors retained their inherited laws.** Both self-review authors found no identified static defect and no evidence-supported replacement for unresolved dependence or transport assumptions. A01's feedback author explicitly retained the MIND Spearman discrepancy: initial values were approximately 0.279–0.324 against the published point 0.529. Its stated reason was that the discrepancy did not identify a unique defensible change to the common law and target transfer. A02's feedback author noted that all four raw discrepancy vectors spanned zero and identified no structural defect; this descriptive observation was not a statistical adequacy rule. The decisions establish retention under the supplied conditions. They do not establish that restrictions caused retention, that revision would be ineffective, or that the retained laws are optimal. Retained branches have separate immutable records and scheduled executions, but are paired repeats rather than new scientific models.

All 54 planned source executions succeeded. The independent source audit recomputed all 72 qualified comparisons, with no implementation mismatches at its declared arithmetic tolerance. This verifies source-statistic calculation, not adequate source fit or target utility. After scientific decisions and source dispositions close, a frozen inventory permits the 18 scheduled target draws. All target dispositions must close before the evaluator opens the existing reference aggregates. The fixed analyses are HbA1c on age/female/BMI, focal BMI; on age/female/glucose, focal glucose; and on female/BMI/glucose/age, focal age, each with an intercept. Generated data receive point estimates; existing community-clustered reference intervals describe reference-sample uncertainty. Failures and all planned versions/seeds remain reportable, and target feedback cannot revise a candidate.

Native aliases, support checks and moment/design review are necessary engineering safeguards for a scientifically interpretable implementation. The feasibility question remains whether evidence-derived reusable data preserve useful biomedical relationships, including analyses not fed back during construction. Source agreement, finite moments and successful execution cannot establish this. BMI/glucose uses remain partially supported, age use unassessed, and joint-distribution, measurement and population transfer assumptions unresolved. CHNS is a researcher-exposed developmental reference. Two reused laws, repeated seeds and four retention decisions cannot establish method superiority, calibrated inference, clinical utility or publication readiness.
