# Evidence-to-whole-cohort developmental continuation

Completed 3 November 2026. Two reused Agent-authored laws produced whole cohorts without participant input. All 54 source and 18 target allocations succeeded. Independent source and target recomputation found no numerical disagreements. The targets comprise six distinct tables, because all four fresh revision authors retained their initial laws.

The clearest positive result is A02's adjusted glucose–HbA1c coefficient: 0.40034–0.42340 across three seeds, against the existing CHNS sample estimate 0.40209. BMI magnitudes remain low, age associations are not recovered, and glycemic variability and joint relationships remain discrepant. This is analysis-specific developmental evidence, not equivalence or general data recovery. All revision contrasts are zero. CHNS was researcher-exposed; no new independent confirmation is claimed.

Both initial scientific candidates, including their generators, specifications, evidence-use records and support declarations, are included under `candidates/`. Branch decisions and review records document actual retention. No target outcome was used to alter these laws. The earlier pilot remains closed with all 72 allocations aborted unrun; this separately declared continuation does not erase or relabel that failure.

This public package contains code, original documents, metadata and aggregate results only. It excludes real/generated individual tables and third-party papers. Some original bindings point to private absolute local paths, so it is an inspection archive rather than a self-contained runnable dataset. See [pre-target publication scope](PUBLIC_BOUNDARY.md) and [completed-result publication scope](PUBLIC_COMPLETION_BOUNDARY.md). Frozen source/evaluator modules are reused unchanged from the preceding release; postprocessing scripts create reports and figures only.

The bounded unit is closed. There are no further draws, model revisions, dataset acquisitions, or automatic experiment extensions in this release.
