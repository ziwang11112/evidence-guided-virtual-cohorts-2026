# Pre-target public export boundary

`PUBLIC_EXPORT_PRETARGET.json` is an explicit publication whitelist. Each entry gives one exact local source, one relative public destination, its byte size, and its SHA-256. The destination prefix is `developmental_continuation_v1_2026-11-03/`. This preparation creates a manifest only: it does not copy files, change frozen artifacts, access a GitHub checkout, commit, or publish.

Included material comprises the continuation protocol and method explanation; release, lineage and preparation records; original method/admission-failure documentation; authored input contracts and extracted source aggregate evidence; the four actual branch decisions and authoring scripts; six candidate review sets; source summaries and the complete independent source-statistic audit; and both initial generators, specifications, evidence-use declarations, final-law/support declarations, analysis-use records and static reviews. Scientific target-context assumptions already present in those prospective specifications are included. Target observations, generated target rows and evaluated target results are not included.

The whitelist excludes all actual or generated individual-level tables, CSV/TSV/Parquet files, reference contents, third-party papers and codebooks, credentials, caches, raw execution directories, live ledger/event/packet directories, `STATE.json`, and the copied `SCIENTIFIC_FREEZE.json` event. Paths and hashes appearing inside selected provenance records are metadata; they do not authorize copying their referents. Release bindings to private or excluded artifacts remain unresolved publicly by design. This is an inspectable method/source-evidence package, not a self-contained runtime archive.

All selected JSON was parsed and recursively checked for individual-row shapes; text was checked for serialized clinical CSV rows, embedded tables and credential-value signatures. No individual records or credential values were found. The task's `row_id: "row_id"` is a column-name declaration. The long numeric lists in A02's specification are finite age-law supports and weights, not participant records. Generator source contains instructions for producing rows, not retained generated rows. Aggregate source estimates, comparison vectors, support counts, seeds, file hashes, authorship/context identifiers and local paths are permitted metadata.

No public-blocking concern was identified in this whitelist. Original source processing, distributional assumptions, population transfer and study-scale limitations remain disclosed; publishing these records does not establish scientific adequacy or independent target confirmation. Historical and pre-execution status records retain their original dates and meanings. Target summaries and results require a separate review and explicit addition by the coordinator. Before copying, recheck each manifest hash; a changed file needs renewed review. Do not recursively export the parent directories or follow referenced paths.
