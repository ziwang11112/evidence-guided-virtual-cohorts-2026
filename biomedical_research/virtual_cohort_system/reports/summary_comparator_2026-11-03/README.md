# CHNS supplied-summary statistical comparison

This supplement adds one purpose-built fixed statistical calibration reference to retained Agent results. Read RESULTS.md first. Three original pre-launch path failures are preserved; a reviewed path-only recovery generated three tables from the same frozen law and original seeds. No original patient or synthetic row table is exported.

The traditional statistical family was developed with coding-Agent assistance. This is not an Agent-removal ablation, matched-budget competition, independent clinical confirmation, or proof of equivalence. Full fitted distribution parameters in FIT.json are mathematical model parameters, not individual records.

For portable numerical reproduction, statistical_fit.fit accepts input/reference_summary.json; generator.generate(None, {"parameters": fitted["parameters"]}, seed) emits a table. The original host/orchestration scripts retain their fixed local paths and failed-version provenance; do not run controller.py runfinal as a fresh public recipe. The exact successful route was controller_recovery.py after the recorded freeze/review. Existing project harness/runtime is required for that route.

Python3.12.10, NumPy2.4.5, SciPy1.17.1 and Pandas3.0.3 fitted the law; isolated generation used Python3.12.3/NumPy2.4.5/Pandas3.0.3. Use seeds4101–4103 and3000rows. Independent aggregate evaluation and audit are included. Tests use invented data.

Original papers, codebooks, patient records, final CSVs and credentials stay local. Local absolute paths in receipts are provenance locators. This public export is a selected review package, not a byte-complete copy of the private execution workspace.
