# Public audit scope

This unit publishes original evaluation code, the fixed design, aggregate statistics for every prescribed split, independent reviews and a descriptive figure. It contains no individual real or generated records, original papers, credentials or community-membership lists. Hashes of local inputs and selected row positions provide audit bindings without disclosing the rows.

The evaluation reuses an already exposed CHNS sample and three already frozen synthetic tables. It adds no generator execution or independent cohort. The one hundred resplits are computational repetitions within the same selected sample, not one hundred clinical validations. All discrepancies are descriptive; the comparison supplies no pass threshold or equivalence certificate.

The exact local data and the original frozen synthetic tables are required to execute the full row-level calculation. They remain local under the project's data-sharing policy. Absolute paths and frozen hashes document that execution; this snapshot is not a portable package that automatically downloads restricted data. Public Markdown navigation may be rewritten to the repository's reports layout and JSON whitespace compacted without changing its values; the export manifest records local and public byte hashes separately.

The published REPORT.json contains aggregate statistics only. Its quantiles describe the prescribed split distributions, not confidence intervals. The independent review is separate from the original calculation, so later review metadata does not overwrite the original report.
