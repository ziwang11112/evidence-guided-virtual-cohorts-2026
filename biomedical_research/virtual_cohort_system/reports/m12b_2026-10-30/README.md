# M12-B curated engineering records

30 October 2026. Every row in `fit/`, `conflict/` and `undefined/` is invented arithmetic. There are no patients, real target measurements, new literature results or biomedical validation claims in this archive.

- `fit/`: 20 trials, 42 actual WSL/bubblewrap executions. The selected intercept/slope/residual scale equals (3,2,1); source discrepancy reaches numerical precision. Two fit and two separately scheduled replay seeds use a deliberately orthogonal sign-flipped residual pattern.
- `conflict/`: three bounded trials, eight executions; both incompatible same-operator means remain in the objective and the fitting criterion is not met. This short search does not establish the global minimum.
- `undefined/`: three trials, six executions; the required adjusted coefficient is rank deficient in every trial. No model is selected. Successful table generation does not hide the unavailable statistic.
- `summary.json`: machine-readable results, usage and permanently charged reservation budgets.
- `pytest_output.txt` and `pytest.xml`: complete suite, 481 passed and two symbolic-link privilege skips. Unit tests that mock execution are distinct from the real runs above.
- `independent_audit.json`: a separate reviewer checks the real run outputs using direct arithmetic and verifies receipts/selection.
- `historical_preservation.json`: 16 old engine files, 228 M11 artifacts and 54 M12-A artifacts unchanged.
- `curation_script.py` and `file_manifest.json`: allowlisted copying, copied-bundle verification and byte inventory. The script is archived from `work/m12b/package.py`; its fixed path assumptions refer to that original location.

Each case contains an original frozen candidate, a locked plan, a bundle-global budget ledger and a complete session under `cal/s`. Selected parameters are committed before replay; replay never reselects a model. `verify_calibration(case_directory, "s")` recomputes statistics, search decisions, usage and bindings with the preserved engine version.

The scope is numerical source fitting. Independent seeds are not independent source populations or uncertainty intervals. Selected trial promotion and the scientific Agent decision loop are the next milestone. Real confirmation remains separate and must not use these engineering outcomes as evidence of biomedical validity.
