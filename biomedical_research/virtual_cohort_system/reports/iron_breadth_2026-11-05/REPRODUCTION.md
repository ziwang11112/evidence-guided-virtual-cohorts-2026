# Public reproducibility notes

The original study program uses project module cohort_harness and its configured offline WSL/bubblewrap worker. In the working project, the case folder sits at work/iron_breadth_2026-11-05; the public reports folder mirrors its original authored code and aggregate artifacts. Do not execute a scientific generator on the host as a fallback. Data files, individual generated measurements, and isolated-run directories are intentionally not distributed.

The registered protocol, model sources, source-only decisions and public batch seal preserve the original experiment. For an independent rerun, use a fresh working copy of this case beside the project modules; keep archived receipts separate from new receipts (the scripts reject overwriting). Configure the documented worker, run the two source contexts then the final programs with the seeds in EXECUTION.md. Verify the author stages and seal all deliveries before acquiring the three CDC files. acquire.py reuses a matching archived local demographics file if present; otherwise it can fetch the same release. The original run used the existing copy and downloaded only CBC and ferritin. Then run reveal.py, evaluation/independent.py --audit, and plot_results.py. The public declarations and results reference aggregate files only; the cryptographic seal includes identifiers of local artifacts, not their contents.
