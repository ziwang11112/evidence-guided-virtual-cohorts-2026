# Public artifact scope

This package documents a newly prespecified blood-pressure task in an already used PNS release. It is one reference case, not five clinical replications. All five independent scientific authors and all fixed seeds are retained.

The source and method freeze preceded author dispatch; the complete author batch preceded the clinical comparison. `runtime/METHOD_FREEZE.json`, the author seals and the batch seal describe the original local artifacts. Public path sanitization and exclusion of row-level tables and full source documents mean these receipts are historical integrity records, not a claim that this reduced public directory is the complete original execution bundle.

Included material consists of original protocol, implementation and review records, authored generator programs/specifications, source metadata and numerical summaries, analysis code and aggregate outputs. Full third-party articles/scans/codebooks and all real or generated individual-level tables remain local. No patient record is embedded in an authored generator. Generators take `observed=None`; their output law is specified in the adjacent `model_spec.json`. Scientific generation in the experiment used the documented WSL/bubblewrap worker, never direct host execution.

Program replay and replication of the original Agent decisions are distinct. Replaying a frozen program requires the recorded Python/NumPy/pandas environment, interface and seeds. Reproducing the full workflow additionally requires retrieving the cited originals and reference workbook, verifying hashes and rebuilding an allowed local bundle. The host did not expose the exact model snapshot, temperature or token usage; those fields are null. The public package does not invent a standalone API launcher or claim exact repeatability of a fresh model's decisions.

The result plots distinguish reference sample estimates, conditional row-resampling stability and generator draw variation. They do not treat the sample as known population truth or the resampling band as survey-design confidence. Source matching, transport to a reference, and useful downstream analysis are separate questions.

The source packet was curated and independently checked. Actual additional retrieval, revisions, unavailable checks and selected outputs are recorded in `RUN_ACCOUNTING.json`; an available capability must not be described as exercised when its recorded count is zero.
