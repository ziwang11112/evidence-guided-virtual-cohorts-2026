# Developmental evidence-guided whole-cohort pilot

This unit follows the completed source-only integration. Its purpose is to test whether a single evidence-generated cohort supports multiple scientific analyses, with numerical source feedback as a secondary within-method comparison. It does not treat a larger number of generated rows as additional biomedical evidence.

The previous integration reproduced four qualified published relationships reasonably closely in one fixed draw per source and passed independent recalculation. Its author retained the initial law after feedback, so it provided no evidence of a revision benefit. It also exposed a native-unit support issue and an ambiguity between clipping and source-population conditioning. Those findings motivated general requirements for the next prospective constructions; they do not authorize changing the old frozen candidate.

The new schedule permits two independent constructions, each with an initial, a self-review and a numerical-source-feedback version. Every admitted version has nine source and three target draws, at 3,000 virtual rows each. The maximum is 54 source and 18 target tables. Failed or stopped versions retain their planned slots. The unchanged CHNS reference is already researcher-exposed and therefore developmental, not fresh confirmation.

The scientific structure and parameters belong to the authoring Agent. The coordinator supplies the evidence, units, eligibility and analysis contract, not target means, slopes, signs or residual scales. Both revision branches start from the same accepted initial law; the self-review branch does not receive numerical source feedback. All scientific choices close before any target generation. A numerical result remains accompanied by its source support, unresolved assumptions and complete source discrepancy information.

The prospective release is independently approved and activated; two fresh initial author contexts have been dispatched. At this publication checkpoint, no actual biomedical source or target draw has run and no new study result is available. Read PROTOCOL.md and RELEASE.json for the fixed contract, RELEASE_ACTIVATION.json for its activation, and the independent review reports for the implementation boundary. The verification work covers 26 support, 10 controller, 31 evaluator and one actual-controller composition test. The composition uses invented fixtures and a mocked process boundary; it is software evidence, not a biomedical result.

The public directory is an inspection/reconstruction package. Original absolute bindings are preserved, while real/virtual individual tables, temporary test data, private execution histories and live mutable local state are omitted. It is not a standalone executable copy of the complete local study. Reproduction needs the canonical project layout, compatible dependencies, legitimately obtained inputs where applicable, and a separately declared execution budget; do not delete old commitments to reopen a completed run. A planned schedule or passing software fixture does not establish generator quality or method advantage.
