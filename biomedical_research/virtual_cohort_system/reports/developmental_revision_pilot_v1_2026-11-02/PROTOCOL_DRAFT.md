# Developmental pilot of evidence-guided whole-cohort generation

Status: prospective preparation, not execution release. No constructor may start until the executable release, input packets, scientific requirements, analytical policy and independent review are frozen. This unit follows the completed source-only integration; its exhausted three-table allowance is not reopened. The existing research framework remains the reference design in `docs/EVIDENCE_GENERATOR_NEXT_DESIGN_2026-11-02.md`.

## Scientific question and information regime

Can an Agent translate the same fixed external study evidence into whole-cohort virtual data that support the prespecified biomedical analyses? As a secondary within-method mechanism question, does access to numerical source feedback change the analysis-use profile compared with an equally bounded self-review of the same initial law?

The task generates age, female membership, BMI, fasting glucose and HbA1c, with no participant input. It does not supply target means, slopes, signs, residual scales or individual records. The E1 packet and NGSP guidance remain unchanged. The two initial authors use fresh contexts; both revision branches receive the same accepted initial candidate and permitted source evidence. Instructions/allowlists restrict author access but do not establish operating-system isolation or absence of pretrained knowledge. The submitted Python generator alone uses the existing isolated execution adapter.

CHNS is already exposed to coordinating researchers. It is a developmental reference, not a fresh independent confirmation. Existing frozen aggregate references and analysis definitions are reused; no participant redecoding, new reference supplement, additional data acquisition or evidence retrieval is part of this pilot. A single Agent is a valid method; no superiority over an ordinary Agent or direct-analysis Agent is required.

## Native support and population selection

The same requirements apply before branching and to each final branch:

1. Declare the complete final joint law for every source/target context, native measurement views, domain bounds and open/closed endpoints, all observation/processing transformations, and the basis of every bound. Schema support is distinct from population eligibility. Unknown plausible physiological limits must not become invented hard bounds.
2. Review the support of the actual law after every required scientific unit map. The required Jansen IFCC view must be nonnegative under its disclosed NGSP mapping; a positive percentage alone does not prove that property. Each required point-analysis moment and design condition remains separately reviewed. Stated support intervals are declarations, not proof of arbitrary Python.
3. Allow an explicitly assumed joint preselection model conditioned on eligibility, or a directly specified joint law for the eligible population. The latter need not invent a parent population or selection prevalence. Unobserved exclusions remain conditioning assumptions. The current moment grammar does not cover arbitrary conditional/truncated laws. Admission requires a faithful final-law representation in the supported grammar; an unconditional parent or clipped surrogate cannot stand in for a conditional law. This release adds no general stochastic-program proof engine.
4. Distinguish clipping/winsorization from exclusion. An expressly declared clipped direct law or observation model can be reviewed, including its atoms and changed estimand. Clipping cannot be represented as conditioning the original joint law without a valid joint-distribution argument. No silent post-output repair or selective row removal is allowed.
5. Mark algebra as exact for the final law, approximate, or an initialization for a precursor law. Selection, shifting, clipping and rounding can change the relationship. Disclosed approximation is not an admission failure; falsely claiming an invalidated precursor identity is exact is a failure. Numerical feedback always analyzes the final generated source table.

Release-owned mandatory checks include positive BMI/glucose/HbA1c on the output analysis scale, task-compatible age and binary membership, Jansen FPG <7 mmol/L, the Jansen nonnegative native IFCC view, Bao age >=20 with the author's explicit boundary convention, MIND age 61–80, and target age 35–74. Jansen adult support and other unreported source bounds are author assumptions to review, not hidden constants imposed by the coordinator. No maximum biomarker value is fitted to known target data. Each generator declares finite-time/floating-point failure handling; failed runs consume their slots without repairs or replacement seeds.

## Constructors, branches and fixed budget

There are two scientific constructors, A01 and A02, and exactly three possible versions per constructor: initial, self_review and source_feedback. Rejected/aborted versions remain in the denominator.

Each initial author has one submission and at most one common pre-branch scientific-validity correction. Its rejected original is retained. Each branch has one scientific revision opportunity and the same output allowance. At most two schema-only correction messages per authoring stage may fix interfaces without changing scientific parameters, law or code; all submitted snapshots are retained and counted. Internal metadata checks before submission do not authorize generator sampling. There is no optimizer, extra scientific author, evidence search or target-guided repair.

Both branches parent the same accepted initial version, never one another. The self-review packet contains only the original permitted inputs, accepted initial artifacts and common validity requirements; it excludes numerical source results, output rows, source feedback logs and summaries. The numerical branch additionally receives authenticated initial source feedback. Each delivered packet and branch decision is bound to exact bytes and actor/context identity. Final branch source results remain hidden from both branch authors until their decisions are irrevocable.

Each admitted version has three Jansen, three Bao and three MIND source draws and three target draws, all of 3,000 rows. This is at most 54 source plus 18 target tables, or 216,000 virtual rows. Source seeds are 41011, 41012 and 41013 for each context; target seeds are 41911, 41912 and 41913. Run IDs are `{constructor}_{version}_{context}_{seed}`. All constructors and versions use the same nominal seed schedule. Different generator algorithms need not map it to identical latent draws; pairing is by planned seed ID, not matched virtual participants. Retained versions have separate immutable child candidates and distinct run IDs, and are counted as paired repeats, not independent scientific constructions. Two initial constructors cannot establish a general method ranking.

Agent call counts, actual turns, file/tool activity and artifact bytes are recorded to the extent exposed. Model-call and token counts unavailable from orchestration remain null, rather than being guessed from turns. The interactive authoring service does not expose a hard token quota or standardized model hyperparameter interface; do not call the branches token-matched. Both branches receive one scientific revision opportunity and the same candidate-output cap of 1,048,576 bytes, including at most 65,536 bytes of generator code; any technical returns are reported. Fix the actual model/session identity obtainable from the orchestration layer without inventing a model version.

An interrupted source phase cannot be resumed by the existing source controller. Retain consumed attempts and unrun slots, with no automatic retry. A rejected candidate, stop decision, uncomputable required check or runtime failure is not silently replaced. Ordinary target attempts continue through the frozen schedule; any interruption is retained and remaining slots are closed as unrun under the released policy.

## Execution and reveal barriers

The existing source-only controller prepares authentic feedback through semantic_feedback_v1 and the qualified collector. Strict unavailable checks remain unavailable. Each source phase uses its own reviewed/frozen candidate and schedule. No old frozen bridge or receipt is modified. Target eligibility requires all nine source executions to succeed, all retained source frames to satisfy declared and required support checks, and each of the four required qualified relationships to be available on its three prespecified source seeds (12 results). Numerical closeness to a published point is not an admission threshold. An initial failure can still inform its bounded revision branches; an ineligible version's target slots remain not run with reasons.

All constructors, branch decisions, accepted/rejected versions and source dispositions close before the first target generation. A new immutable scientific inventory binds them. Target executions use the frozen parent candidate, whose active context is target, and write outside its completed source bridge. The new pilot ledger binds target trials to the same scientific specification and sealed target child. The old full bridge remains incomplete by design; its source-only completion remains valid.

After all target dispositions close, a second immutable inventory authorizes evaluation with the frozen evaluator. It checks all output and execution identities before reading the existing reference aggregates. Changed identity during evaluation is a fatal integrity failure, not an ordinary scientific-analysis failure. No target feedback returns to an author. Reference bytes and source/target outputs are absent from author packets. Controller, evaluator and runtime identity changes stop release rather than silently upgrading an ongoing study. Bind both the WSL generator runtime and the separate host analytical environment; the latter records Python, NumPy, pandas and SciPy versions checked before reference access.

## Scientific analyses and reporting

Keep all three F2 projections, each with intercept: HbA1c on age/female/BMI (focal BMI), HbA1c on age/female/glucose (focal glucose), and HbA1c on female/BMI/glucose/age (focal age). Reuse the existing common complete-case selection and community-clustered nominal 95% reference intervals. Generated data receive point analyses without fabricated patient-inference intervals. Reference uncertainty does not make discrepancies irrelevant; reference point estimates are not known population truths.

Report every constructor/version/seed, with the source discrepancy vector, analysis-support labels, coefficient, signed discrepancy, reference interval and direction description. For each constructor/endpoint/version, report mean absolute discrepancy across exactly three planned seeds only when all three are available; otherwise report incomplete status and all failure reasons. Report both branch-minus-initial and numerical-feedback-minus-self-review changes. Any cross-constructor average is descriptive; no pooling rows or seeds as independent method replications.

Retain existing reference-comparable means, sample SDs, q10/median/q90 for all five variables and glucose–HbA1c Pearson/Spearman. Add only generated-side q01/q99 for BMI/glucose/HbA1c, ten pairwise Pearson correlations, duplicate-row counts excluding row_id, finite/support failures and design diagnostics. These added diagnostics have no reference comparison because no new reference decoding is authorized. Quantiles use linear interpolation; Spearman uses average ties. These finite-table diagnostics do not prove population moments or transport.

No new scientific adequacy/equivalence tolerance or binary overall success gate is introduced. Numerical agreement tolerances apply only to independent recomputation. Keep source uncertainty, reference uncertainty, simulation variation and transport assumptions separate. Analyses unsupported by the evidence, including an age effect where only an independence assumption is available, remain visibly assumption-dependent/unassessed even if a coefficient can be computed.

## Closure

Independently recompute focal estimates, diagnostics and paired summaries; retain all failures and no-op decisions. Continue, simplify or stop based on the complete analysis-use profile. Source fit alone does not establish target utility, and revision is not mandatory for success of evidence-guided generation. No outcome automatically expands the budget or starts another dataset search. Only reviewed code, original documents, metadata and aggregate results go to the existing public repository; all individual real/virtual tables stay local.
