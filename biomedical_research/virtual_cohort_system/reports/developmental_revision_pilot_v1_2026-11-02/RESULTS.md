# Developmental pilot: closed before generation

This release produced two Agent-authored scientific constructions but no new biomedical tables. Both failed final executable metadata admission after their permitted initial correction returns. All 54 planned source slots and 18 planned target slots are retained as **aborted, unrun**, not as failed generated tables. The release is closed. No target evaluation was authorized and no conclusion about comparative data quality follows from this unit.

## What was completed

The released controller, support checks and evaluators passed 68 distinct software checks, including a composition check through the actual controller with an invented candidate and a mocked process boundary. These checks support implementation readiness within their test scope; they are not patient validation. The prospective package was publicly synchronized at commit `71cffa670f629efd4a7f2527f160185712df920b` before any biomedical draw.

Two fresh author contexts constructed complete five-variable cohort generators without individual observations or target analysis answers. A01 proposed a common affine, glucose-mediated law with bounded source innovations and Gamma innovations in other contexts. A02 proposed a shared latent-dependence law with bounded Jansen biomarkers and shifted/lognormal biomarkers elsewhere. Both authors chose their scientific structures and parameters. Independent review found finite moments required by the planned point analyses, nondegenerate population predictor designs, and coherent declared native-unit supports. Those static findings do not establish successful finite-table execution, source fit, transport or analysis utility.

The source-to-target dependency paths are real code paths, but their scientific transfer remains assumed. Both constructions leave age associations dependent on independence assumptions rather than evidence. Neither has been shown to recover the target age analysis or to improve the whole analysis-use profile.

## Admission failures and accountability

1. The author-facing material did not expose the complete `checks.json` grammar clearly enough. The same technical schema disclosure was supplied to both authors and conservatively counted as their first return.
2. Both initial plans used named empty-string binding placeholders. The frozen source controller requires authored `bindings` to be exactly `{}`. The second technical return produced retained child candidates. Their generator, scientific specification, evidence and law/support declarations were unchanged. This also consumed the common initial correction allowance; no hidden extra scientific construction was introduced.
3. Final qualified validation then rejected both Jansen contexts: the measurement mapping used input `hba1c`, whereas its unit evidence identifies `HbA1c_percent` and `HbA1c_IFCC`. The plan lacked the corresponding native percent alias. The inverse conversion formula was mathematically correct, but the supplied metadata did not satisfy the executable name contract. Bao and MIND metadata passed. No source phase was opened.

One reviewer initially approved A02 by checking semantics, hashes and mathematical equivalence without invoking the actual metadata validator. Upon independent recheck, that reviewer reproduced the Jansen failure, preserved the original approval and explicitly revoked reliance on it for execution. The coordinating process separately reproduced J failure and B/M passes using the frozen implementation. A hash-consistent review is not a substitute for running the relevant admission validator.

These are shared author-interface/composition failures, not observed failures of the biomedical relationships. The protocol allowed no further initial correction. Rather than editing frozen candidates or expanding the allowance, both initial versions and their unstarted branches were closed through the released ledger. No branch author received feedback or made a revision decision.

The closure helper first attempted full bridge verification on an original bridge that had only been prepared, not sealed. It failed before writing any ledger event. The corrected helper verified the original candidate commitments, absence of bridge executions and the sealed corrected bridges; the final closure then passed. This helper failure is orchestration history, not a generator attempt.

## What this changes

Retain the core scientific approach and the two reviewed model structures. Do not claim that this pilot improved generated data, and do not reopen its budget. The immediate useful repair is a small, separately versioned **read-only author preflight**, using the actual alias, measurement-mapping and operator validators before submission. It should report all source contexts without inventing an approval, executing a generator or changing a scientific parameter. After sealing, admission must still call the actual bound validator; draft checks cannot replace that step.

Any later execution needs a new prospective release that explicitly retains this failure, states whether it reuses these scientific constructions, counts their provenance, and defines its budget before generating or reading target outcomes. A metadata-only continuation must not be described as fresh independent authorship. There is no need for another dataset, another scientific model component or target-guided coefficient tuning to resolve this interface defect.

The prior source-only integration remains the latest numerical result: four input-source relationships were reproduced approximately in one draw per source, independently recalculated, and the Agent retained its law after feedback. This supports numerical evidence uptake; it does not demonstrate feedback improvement or success on withheld target analyses. See [prior results](../source_integration_v1_2026-11-02/RESULTS.md).

Machine-readable closure is in [ADMISSION_CLOSURE.json](ADMISSION_CLOSURE.json) and [CLOSED_INVENTORY.json](CLOSED_INVENTORY.json). The independent closure review, when completed, is a separate artifact. Historical releases, candidate freezes, source data and prior results remain unchanged.
