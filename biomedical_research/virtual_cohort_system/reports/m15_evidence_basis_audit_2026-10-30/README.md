# M15-A evidence-basis audit packet

This post hoc audit examines what published evidence supports in the already frozen M15-A direct-row pilot. The 20 supplied marginal summaries have a verified published source; the fictional table's dependence, urate spread and individual values remain construction assumptions. Numerical diagnostics describe the same retained table and do not establish clinical validity.

`source_review.md` records the original-source and provenance review. `numeric_review.md`, `numeric_audit.py` and `numeric_audit.json` record the post hoc numerical audit and aggregate findings. `manifest.json` hashes every packet file except itself and identifies the original local sources.

No new generation, revision, calibration or target evaluation was performed for this audit. No scientific script was executed during this export. Generated CSVs and original full-text XML remain local; this packet contains no row arrays or individual records. Paths and hashes identifying those excluded files are provenance metadata only.

The numerical script expects its original local `work/m15a_direct_rows_2026-10-30/evidence_basis_audit` layout and locally retained frozen rows. Its archived copy is for code inspection and is not a standalone reproduction bundle.

The [reviewed narrative](../../docs/M15A_EVIDENCE_BASIS_AUDIT.md) explains the findings and limits. The earlier [M15-A pilot archive](../m15_direct_rows_2026-10-30/README.md) and historical milestone report remain unchanged. These post hoc findings are not additional prespecified successes or new feedback to the original builder.
