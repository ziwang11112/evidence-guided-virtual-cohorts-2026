# Conditional evidence and whole-cohort generation: a bounded mechanism pilot

1 November 2026, America/Chicago. The user authorized this new foreground work after reflection on the completed CHNS case. The CHNS target and all older references remain closed. The CHNS heartbeat remains paused. This protocol authorizes no new dataset, literature search, paid API, training, HPC or recurring task.

## Question and scope

Does changing conditional evidence, while holding source marginal and pairwise evidence fixed, change an Agent's complete virtual-cohort construction appropriately under a known source-to-target composition shift? Which unreported uses remain unresolved even when those supplied constraints are represented?

This is an explicitly invented mechanism/translation experiment. It is not a clinical reference validation, a new biological discovery or evidence that a generation algorithm is novel. Earlier C4 already demonstrated that partial moments need not identify a hidden regression. The incremental test here concerns use of group-conditional evidence and target composition, with a sign-counterfactual evidence control. No selector, ranking score or repair policy is added.

## Custodian and information conditions

An independent custodian commits fictional source laws, source summaries, analysis definitions and an evaluator before any generated output. Variables are a binary group g, continuous measurement x, continuous response y and a fictional identifier. There are no participants. The source group proportion is 0.5 and the target group proportion is 0.75; other transport assumptions are explicitly stated by the custodian. Measurements have invented units and no clinical interpretation.

Four separate task bundles permit only their own registered source notes and evidence. Builder-visible folders/task labels are neutral A/B/C/D, corresponding respectively to the analysis labels below; the analytical labels and protocol are not supplied to builders:

| Packet | Available information |
|---|---|
| T0 | Target specification and variable definitions only; response/dependence require explicit assumptions |
| T1 | T0 plus source marginal moments and pairwise relationships |
| T2plus | T1 plus group-conditional mean/regression and residual-dispersion summaries for one committed source law |
| T2minus | T1 plus counterfactual group-conditional summaries for the other committed source law |

The two source laws have identical T1 summaries, but different group-conditional effects. Within each sign world, two residual-distribution laws have the same T2 means, conditional slopes and variances but can differ in tail probabilities. No source note may silently grant the builder the hidden residual family. These are alternative compatible artificial worlds, not replicated clinical cohorts or outcomes selected after generation.

The custodian's exact commitments, definitions and compatibility checks must be independently reviewed before builder dispatch. Root does not open hidden values or the hidden evaluator until every candidate and output commitment is complete. Reviewers may inspect custody artifacts to verify mathematical consistency; they must not relay hidden values or preferred parameters to constructors.

Use one fresh-context constructor per packet, with the same task wording and technical interface. The Agent chooses scientific structure, parameters, transformations and assumptions itself. The root does not prescribe desired signs, distributions, correlations, residual scale or the hidden equations. Each builder sees only its own task, evidence, registry and registered notes, plus the evidence-cohort-generation skill and the supplied harness interfaces. No sibling candidates, custody files, project results, target statistics or browsing are permitted.

For this pilot the program route is fixed for every arm, so route choice is not another experimental factor. A normal scientific Agent is sufficient. Submit generator.py, model_spec.json, an unchanged copy of admitted evidence.json, decision.md and truthful checks.json. The program must implement the existing three-argument generate(observed, spec, seed) interface with observed=None, NumPy/pandas and no file/network I/O. These are Agent-authored generators executed by existing software, not directly authored numerical rows.

Each builder has one scientific authoring turn, zero source-feedback revision rounds and at most one non-scientific interface/schema repair turn before freezing. A scientific model error or inappropriate assumption is an experimental result, not permission to request a target-improving change. Reviewers check permitted input, contract validity and code/spec correspondence without fitting or instructing desired scientific choices.

Freeze all four accepted candidates and the exact reviewed protocol/controller/custody commitments before any generator runs. Use the existing WSL/bubblewrap executor only; no host fallback. Each candidate produces exactly 3,000 fictional rows at seeds 18101, 18103 and 18107. Maximum **12 final tables**, no fitting trials, no source-context generation, no retries, no extra seeds and no regenerated data after evaluation. All failures occupy their planned slots. The root's small controller reserves the campaign and records every slot; it contains no scientific generation law.

One constructor per packet means that Agent author variation and information differences are not statistically separated. Three simulation seeds test the frozen generator's conditional sampling variation, not independent Agent reproducibility. Equal authoring/execution opportunities do not establish exactly equal token consumption; model/temperature/token metering unavailable from the surrounding Agent interface must be reported as such.

## Prespecified interpretation

The custodian fixes exact endpoint definitions before builders see evidence. Keep three types distinct:

1. **Evidence compliance:** supplied conditional and source moments evaluated under their correct population or a declared source reweighting. Task-population unweighted statistics must not be relabelled as source replay. No compliance result is returned to the builder.
2. **Target composition/translation:** the pooled unweighted target x coefficient in y ~ 1 + x (no g adjustment), under the changed group mixture. With the full conditional summaries and stated transport assumptions this is algebraically implied. Its recovery is a translation check, not discovery of an unreported biological relation.
3. **Assumption-dependent analytical reuse:** an unreported joint tail/threshold contrast. Report against both compatible residual laws and expose unresolved distribution assumptions. A good match to one compatible world cannot identify it as the actual world.

T0/T1 outputs are compared with all committed sign/tail worlds. T2plus and T2minus are each compared with their respective two tail worlds. Do not average errors over worlds with invented probability weights. Report every planned seed, raw statistic, signed/absolute difference, supplied/implied/assumption-dependent label, and any failures. No post-result equivalence margin, global accuracy score, best-seed or best-world selection is permitted.

The pilot supplies a concrete favorable translation example only if both T2 packets yield the expected counterfactual change and their absolute translation errors are lower than T1's errors under the corresponding world on all three planned paired seeds. A mixed result remains mixed. This operational comparison is not a clinical equivalence threshold or a population-level causal claim about evidence. T0 is a prior/scenario reference; it cannot be forced to be a bad model. Tail agreement is reported separately and cannot rescue a failed translation check. The shared T1 outputs have no evidence basis for choosing one sign world.

Independent recomputation verifies source equivalences, target algebra, analytical tail calculations and the complete generated-output analysis using separate arithmetic where feasible. Newly needed numerical checks may use invented fixtures; old passed suites and closed experiments are not rerun. No numerical report is supplied to a constructor after freeze.

## Stop and record

End after twelve accounted-for slots, one complete evaluation, independent numerical/interpretive review and a continue/simplify/stop recommendation. If review finds that the constructed conditions fail their declared equivalence or the unit merely duplicates C4 without a discriminating contrast, stop before generation. If the execution backend is unavailable, record the resource failure without fallback. Do not add components or change source laws to obtain a positive result.

Save the full result and failures, actual execution times, authoring opportunities and unavailable cost metering. Only reviewed original code, artificial evidence/protocols and aggregate results may be synchronized to the existing public repository. All generated row tables stay local. Hidden artificial laws can be disclosed after evaluation; they must remain explicitly invented. Public code inspection is not a claim that this toy demonstrates clinical transfer or that it resolves the project's method-innovation gap.
