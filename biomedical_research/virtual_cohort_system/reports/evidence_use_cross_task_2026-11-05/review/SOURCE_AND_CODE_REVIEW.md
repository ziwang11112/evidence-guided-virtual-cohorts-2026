# Supplemental source and implementation review

5 November 2026. **Admit the sources as qualified external evidence; the implementation is suitable for the proposed pilot after the small metadata wording correction below.** This is not approval of an authored generator or a claim of useful final data. No clinical rows, candidate-generated tables, held reference values or old target-result files were inspected. Tests used invented arrays and metadata only; no cohort generator was executed.

## Lipid source admission

**Agongo 2018:** independently checked the original XML Table 1 age/BMI means and SDs for men, women and pooled participants; the three selected BMI coefficient/CI rows in Tables 4/5; and pooled HDL/TC mean/SD in the main results. Extracted numbers match. The statistical methods distinguish means/SDs from regressions using log-transformed lipids. The log base remains unresolved, and the selected coefficients are not the requested raw-unit age/sex-adjusted coefficients. The correction names waist/hip entries and a reference, not the extracted lipid/BMI/age quantities. Admit the marginal summaries for explicit source-context or transport use; retain the regression entries as context only. [Original article](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0206326), [original XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6261546/fullTextXML), [correction](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0213233).

**Obirikorang 2015:** independently checked all six selected Table 7 entries in the original XML. Rural lower-left values for BMI–TC, BMI–HDL and TC–HDL are 0.212, -0.100 and 0.106; urban upper-right values are 0.293, -0.040 and 0.171. Methods and caption identify Spearman correlations within community, not Pearson correlations or adjusted associations. Units are dimensionless; lipid measurements are reported in mmol/L. Admit these statistics as partial relationship information with declared population, measurement and joint-law assumptions. They cannot be directly substituted for either adjusted slope or the target residual Pearson correlation. The six constraints do not constitute six independent studies. [Original article](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0129494), [original XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC4457529/fullTextXML).

**Greiner 2021, reused source:** checked the published-version PDF main analysis text and Tables 1/2 against the extraction. Age quantiles, geometric means, threshold prevalence, units, rounded/flagged confidence intervals and table-specific counts retain their stated definitions. Generic transformation wording does not resolve each regression row's scale. Keep geometric means distinct from arithmetic means; do not subtract geometric means to obtain the geometric mean of non-HDL. The publisher's DC2 supplement returned HTTP 403 during this review, so I did not independently recheck every supplementary coefficient; their context-only quarantine remains appropriate. No new primary-study search was performed. [Published-version PDF](https://eprints.whiterose.ac.uk/id/eprint/181857/1/e005222.full.pdf).

**Feedback admission is narrower than model-use admission.** The extraction records say source weighting is not explicitly reported. Under the selected semantic-feedback v1 contract, `weights: not_reported` yields `not_computable`; a construction assumption of equal weights does not turn this into reported `weights: none`. Similarly, unknown quantile convention or unsupported geometric/log operators must remain unavailable in this adapter. Amend any source-packet wording that promises computable feedback merely because such assumptions were declared. These gaps do not prohibit using the reported source information in an honestly assumption-dependent model, and they do not require another source search, operator implementation or execution.

The reviewed evidence is adequate for a partial-evidence construction pilot, not an identified full joint distribution. No source directly supplies all three target lipid functionals with matching population, measurement and adjustment. Record source-context gaps and let each constructor decide which quantities to use, check, or leave unresolved. Source registration still belongs to the authorized controller; these review artifacts are not gateway receipts.

## Lipid estimator

`lipid_provider.py` calls the existing in-memory K02 estimator in generated mode and contains no reference loading. It applies the declared mmol/L-to-mg/dL conversion, keeps the three requested IDs, and retains all 23 added diagnostics. The actual regression output is **mg/dL per 5 kg/m²**, matching the admission task metadata. The residual quantity is Pearson correlation after fitting both lipids against the same intercept/age/F-indicator/BMI design on the common eligible rows. `conditional_rms` uses the root mean of squared residuals (divisor n), not the residual standard error with divisor n minus design rank. Preserve that name and definition in the frozen diagnostic packet.

The provider's three controlled tests pass. The added independent factorial-array test also passes and establishes analytical expected values for both requested slopes, residual correlation, marginal sample SD and absolute conditional RMS under a second invented construction. This checks arithmetic and scaling, not biological fidelity or a reference match.

One small naming correction remains: `sex.female_fraction` interprets the literal code F as a biological label, whereas the admitted metadata explicitly says that label legend was not independently verified. Rename it `sex.F_fraction`, or supply the already-reviewed legend before using the biological label. The OLS coding `I(sex==F)` is already consistent with the metadata.

## Evidence-use gate

The initial gate would have rejected three valid cases: retained evidence-backed relationships in a revision; a shared changed parameter supporting more than one requested analysis; and an explicitly assumption-only parameter update. These were reported to the implementer and corrected. The gate now derives changed/unchanged effects separately from source-use choices, accepts shared-path coverage, and reports evidence-only, assumption-only or combined support. The revised targeted tests pass: 53 evidence-use tests plus the three provider tests, with the one independent factorial test run separately (57 passing checks in these scopes).

No remaining blocking defect was found in the reviewed interface for this pilot. It verifies byte bindings, declarations, references and specification changes. It correctly leaves generator parameter use, source admission, actual check execution, scientific validity and data-quality gain outside its guarantee. The controller must select the genuine initial baseline and exact required request IDs, bind the verified feedback, and review scientific meaning. A model-specification path or changed generator hash alone does not prove the intended law was used.

The subsequent additive loader `controller_evidence_use.py` was also inspected. It binds the actual task/candidate/baseline selected by the controller, checks auxiliary artifact paths within the candidate and rejects linked files. Its seven invented-file tests pass using a fresh project-local pytest temporary directory. The first attempted test command encountered the host's inaccessible default pytest temporary directory before any test ran; the bounded retry changed only the test temporary directory. This is seven additional passing integration checks (64 passing checks across the reviewed scopes), with the environment setup failure retained in the review record.
