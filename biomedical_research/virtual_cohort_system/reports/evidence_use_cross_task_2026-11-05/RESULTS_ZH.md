# 两类任务、六次 Agent 构造：本轮完成总结

本轮已经完成 **6次独立构造、18份最终表，每份3,000行**。没有输入患者级数据；Agent 根据外部论文和任务描述选择模型结构及参数，程序按冻结模型采样。全部513个预定分析/诊断值通过独立复算。原始表、生成表、完整第三方论文均保留本地。

我们确实把“证据怎么用”落到了数值生成过程：关联、边际分布、条件波动和未识别假设被分开记录，代码实际使用了这些参数。六次构造通过同一流程完成糖化血红蛋白与TC/HDL两类任务。它们均选择保留初稿，没有强行展示修订收益。

## 有什么结果

六个预定关系在全部模型/种子输出中都与样本参照的点估计同向（54/54个输出）。这不是54项独立临床验证，也不等于效应大小已经正确。TC–BMI真实样本的敏感性区间还跨过0，不能把它称作已经确定的正向总体关系。

下表HbA1c效应的单位是**百分点**：年龄项按每10年报告，并控制性别、BMI和血糖；两项BMI效应按每5 kg/m²报告，调整集分别在表内说明。血脂效应为每5 kg/m²对应的mg/dL变化；相关系数无量纲。

| 分析 | 实际结果 | 能说明什么 |
|---|---|---|
| 年龄与HbA1c | 三份模型平均效应约0.100；样本参照0.075/10年 | 正向关系稳定，幅度偏大 |
| BMI与HbA1c，控制年龄/性别 | 模型均值0.049–0.060；参照0.084/5 BMI单位 | 正向，但关联强度较弱 |
| 再控制血糖后的BMI效应 | H03为0.051，参照0.057；H01/H02为0.030/0.019 | 一份结构较接近，其他结构较弱；不能只挑最好的一份 |
| BMI与HDL | 三份模型约−2.0至−2.2；参照−4.6 mg/dL/5 BMI单位 | 负向关系稳定，幅度有差异 |
| TC与HDL的调整后相关性 | 模型约0.108–0.141；参照0.512 | 联合关系仍明显较弱 |

另外，H03虽然更接近一个BMI效应，HbA1c波动却更窄；L02的TC标准差更接近参照，但TC–HDL联合关系仍弱。因此没有一个模型在所有分析上都最好。

## 现在如何判断

**方向可以继续，当前输出可作为透明、假设依赖的情景数据，用于定性关联探索和分析流程检查；尚不能把它们当成完整真实队列的量化替代。** 这是对本批输出用途的限定，不是缩减整个虚拟数据生成研究的目标。本轮更适合支撑论文中的跨任务构造能力和用途分层，而不是声称所有关系恢复、反馈必然有效或任何场景都高质量。

132条来源检查因权重/口径缺失或算子尚不支持而没有计算数值差异；这不妨碍明确声明假设的生成，但意味着本轮不能证明数值反馈改善。独立复算没有发现当前结果来自已检查的代码或计算错误；证据、迁移和结构假设各自造成多少差异，仍未被控制实验拆开。
