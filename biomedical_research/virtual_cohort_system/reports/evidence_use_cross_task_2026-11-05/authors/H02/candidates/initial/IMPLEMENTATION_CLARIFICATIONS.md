# H02 implementation clarifications

The controller's H02 source-proposal review released implementation without numerical redesign. The proposal and source-review request are preserved unchanged. This document clarifies their provenance and feedback language.

1. Finnish supplement Tables S1/S2 do not explicitly print response-unit headers. Their original numerical coefficients are retained with an unstated-source-scale label. Interpreting S1 as mmol/L and S2 as HbA1c percentage points is an explicit inference from the main paper, measurement discussion and numerical scale. The factor 18 and converted coefficients are separate derived quantities, conditional on that inference. This qualifies the proposal's stronger wording that the numbers “establish” the units.
2. Source weighting and estimator definitions remain as reported or unknown. NHANES and Finnish survey-weighted statistics cannot be reproduced by the unweighted semantic v1 adapter. Finnish binary age adjustment and fasting-time adjustment are not replaced by continuous age or omitted adjustment. Kerman/Taiwan weighting, and inadequately stated missing-value and SD conventions, remain unknown. Unavailable comparisons stay `not_computable` with null operators. The planned approximate checks in the proposal are not authority to bypass this gate.
3. No scientific parameter changed. The residual SD 0.40, beta supports and shape parameters, location anchors, BMI independence, continuous age bridge and cross-source marginal-to-conditional decomposition retain assumption status. Numerical endpoint protection applies only if floating-point arithmetic rounds glucose to 126: use the next representable number toward 55. There is no statistical truncation or fitted correction.
4. `generator.py` reads all scientific settings from `model_spec.json`. The residual is standardized with the beta mean/variance formula, exactly equivalent to the reviewed 0.40*sqrt(7)*(2*Beta(3,3)-1) law. This algebraic implementation does not alter the distribution.
5. This phase permits source reads, deterministic algebra, AST inspection and contract/preflight validation only. No generator import, row generation, sampling, freeze, execution or target inspection is performed. Static success cannot establish generated-table validity; root review and the isolated trial remain necessary.
