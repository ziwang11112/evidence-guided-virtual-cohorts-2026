## Reproduction limits

This is a local Windows/WSL reference integration, not a portable replay package. No fresh replay from this archive was tested, and no byte-identical regenerated output is claimed. Original generated rows remain local and are omitted; their hashes remain in execution and audit receipts. The archive alone cannot satisfy full historical execution verification or recompute row-dependent source statistics.

`run_integration.py` resolves its unit path from its own location and verifies the absolute paths in `ASSEMBLY.json`, including project code, interface documents and the installed skill. Moving the unit from `work/core_v0_2026-10-31` to this `reports/` archive, or placing it in a different clone, does not make that assembly valid. Relocation requires a separately authorized new controller manifest and a documented mapping of the unchanged source/scientific bytes to the new environment. Do not edit the historical assembly, candidate freezes, execution receipts or original source files to make their old checks appear to pass.

Any separately authorized replay needs a fresh working unit with the intended initial scientific inputs and reviewed dependencies, plus the existing isolated WSL/bubblewrap backend. The recorded configuration uses WSL `Ubuntu-24.04`, `/home/zwang/.cache/evidence-cohort-runtime/m2/venv`, and `/home/zwang/.cache/evidence-cohort-runtime/m2/bubblewrap/usr/bin/bwrap`. There is no host-process fallback or runtime substitution. Existing start markers, native execution directories and final lineage refer to this historical two-slot chain and must not be treated as fresh execution state. The export includes no staging helper or automatic replay command.

Any future exercise is a replay of exposed authored inputs, not a new blinded authoring experiment. It must preserve the fixed execution accounting, original evidence/check recipe, authentic feedback linkage, failure closure and retention semantics. Agent restrictions are procedural; native OS isolation covers generator processes only. Exact model identifier, temperature and token cost were unavailable and remain recorded as unavailable.
