# CHNS existing-data information experiment: finite execution policy

This supplements REUSE_AMENDMENT.md before any scientific construction. The user authorized running the existing CHNS benchmark. No acquisition or historical-reference redecoding is needed.

The reserved constructors are E0_A01 through E0_A05 and E1_A01 through E1_A05. Each starts in a fresh Agent context and receives only its assigned task, source packet, fixed compiled evidence, and common interface guidance. No other constructor, target result, historical generator, comparison report or unapproved literature is supplied. The Agent chooses its scientific structure, parameters and assumptions. The coordinator does not insert desired coefficients or relationships. Language-model tool access is instruction-restricted, not an operating-system security boundary; only execution of the submitted generator uses the existing isolated runtime.

Each constructor submits one initial program with its specification, provenance and rationale. Before freeze, at most two correction returns are allowed, only for interface defects: schema, syntax/signature, prohibited input/output, invalid provenance references or inconsistency between declared parameters and their implementation. The original submission and each correction are archived. Feedback cannot supply scientific output statistics, desired signs, parameter values or a preferred scientific structure. A scientifically weak but contract-valid candidate is retained. No generator draw is run for pre-freeze tuning.

Each frozen candidate receives exactly seeds 1701, 1702 and 1703, 3,000 rows each, 180 seconds per attempt, 1,024 MiB process memory, 2,000,000 output bytes and 10,000 log bytes. Execution is through the unchanged WSL/bubblewrap adapter, without host fallback. Failed or unrun slots remain in the 30-slot denominator. There are no post-freeze replacements or retries. Necessary infrastructure checks before this release do not execute a scientific generator.

All ten constructor records and all thirty output slots close before the new reference comparison. Historical researcher exposure is disclosed. Evaluation uses the unchanged CHNS analysis definitions and already independently recomputed measured-reference aggregates; it does not turn the benchmark into untouched confirmation. Per endpoint, average absolute discrepancy over the three seeds within each constructor, then average over five constructors per arm, then subtract E0 from E1. Both source-addressed endpoints must favor E1 for the prespecified complete-arm descriptive improvement statement. Missing constructors/endpoints preclude a survivor-only success claim. Report the third endpoint, all failures, raw units, constructor variation and the fixed reference interval-endpoint sensitivity regardless of favorability.

No source replay or feedback revision occurs in this experiment. Therefore it can test the effect of supplied relationship evidence on this reused benchmark, but cannot establish a benefit of revision, retrieval, multiple Agents, a specific model architecture, or superiority over another generation method. No synthetic table is treated as an independent clinical cohort. The result must be independently recomputed before scientific interpretation is finalized.
