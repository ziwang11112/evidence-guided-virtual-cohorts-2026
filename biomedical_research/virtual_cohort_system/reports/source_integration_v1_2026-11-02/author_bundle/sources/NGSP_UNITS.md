# Official NGSP HbA1c scale relation

Authored reuse of previously audited official guidance, not a newly retrieved study. Original locator: [The IFCC and NGSP, Table 2](https://ngsp.org/ifccngsp.asp). Review-ready unit context only.

The retained relation is:

`NGSP HbA1c (%) = 0.09148 × IFCC HbA1c (mmol/mol) + 2.152`.

This is a deterministic representation relation, not a new empirical cohort constraint. A transformed slope, SD, SE or slope-interval endpoint uses the multiplier only; a transformed level/intercept also uses the offset. Variances use the squared multiplier. These consequences are algebraic derivations, not independent clinical observations. This packet supplies no precomputed converted regression coefficients and does not install a conversion in the strict feedback engine.

Rounded reported summaries on the two scales need not agree exactly after conversion. A scale relation cannot establish common assay performance or source/target population applicability. It is not an estimated-average-glucose or fasting-glucose model, nor a serum/plasma conversion. The glucose normalization convention in older work is not imported as NGSP evidence.
