# M7 custody and methods audit

**Disposition: retain custody and do not release the target for M7.** The controller reports that retrieved source evidence is insufficient for a calibrated generator update. The frozen protocol expressly makes evaluation conditional on usable evidence. This audit supports completing M7 as a documented no-op. It does not authorize generation, target evaluation, a before/after performance claim, or an evidence-improvement claim. The source-applicability judgment itself was supplied by the controller and was outside this audit's scope.

The audit read custody Python source, the protocol, freeze and lock records, amendment and preparation/validation metadata, and official CDC documentation. It computed byte hashes of the hidden table and visible inputs without parsing them. It ran only invented numerical fixtures, with `pandas.read_csv` replaced by a function that raises. No participant rows, raw XPT files, evaluation artifacts, other experiments, or agent inventory were opened. No generator or target analysis was run, and no frozen custody file was changed. CDC documentation retrieval can include public codebook frequency/range text; none was used as target analytical evidence or reproduced here. Thus this review does not claim that absolutely no public descriptive information was ever present in documentation retrieval.

**Integrity evidence.** All 33 checks passed: 14 files anchored by `custodian_lock.json`, 11 files anchored by `protocol_freeze.json`, the hidden-table byte hash, the visible-manifest byte hash, and six files named in that manifest. The hidden-table digest remains `0022eaa4978ec93872ed7387cfd55b052e591a74921e4a0ff74c2e86cab40281`. This establishes agreement with the recorded anchors at audit time; hashes and self-reported receipts do not prove that no unrecorded access occurred. Supporting results are in `CUSTODIAN_AUDIT_CHECKS.json`.

**Eligibility and measurement.** The corrected code implements ages 40–79, examined status, sex codes 1/2, morning `PHDSESN=0`, food-fast duration from 8.5 inclusive to 24 exclusive, positive finite `WTSAF2YR`, complete positive BMI and TG, and finite design fields. One-to-one joins by `SEQN`, input count checks, a nonempty-domain assertion, and the published SI conversion check provide useful preparation safeguards. CDC confirms the morning code and identifies the additional fasting questionnaire items that can affect interpretation. Their omission is disclosed as a limitation rather than silently equated with fully verified fasting. [CDC FASTQX_F documentation](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2009/DataFiles/FASTQX_F.htm)

`LBXTR` is the correct reference-method TG variable. The Roche Modular P assay includes glycerol blanking; the file-specific fasting weight and the specified fasting interval agree with CDC's analytic notes. The inherited `legacy_proxy` token is therefore only a compatibility label, as the protocol states; it cannot establish assay equivalence or resolve transport from nonfasting evidence. [CDC TRIGLY_F documentation](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2009/DataFiles/TRIGLY_F.htm)

The QA receipt records 3,185 positive-weight design rows, 1,575 eligible complete cases, 15 represented strata and 31 represented PSUs, giving nominal domain df 16. These are preparation/design counts, not TG effect estimates. Complete-case eligibility depends on TG validity; consequently the prepared input is a complete-case domain and cannot be described as selected without any machine access to the outcome column. No additional nonresponse weighting is implemented, so population representativeness beyond the disclosed complete-case restriction remains unestablished.

**Survey inference.** The implementation uses a weighted estimating equation with a domain Hessian, zero estimating scores outside the domain, PSU totals nested within strata, and the `m/(m−1)` stratum factor. It retains all positive-weight design PSUs, including those without domain members, rejects singleton full-design strata, and uses occupied-domain PSU minus stratum counts for t intervals. These choices agree with the CDC guidance on domain analysis, masked variance units, with-replacement linearization, and subgroup degrees of freedom. In particular, the reported df should follow the actual represented design rather than be forced to a generic two-year value. [CDC variance-estimation tutorial](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx)

The supplied invented fixtures passed. An additional independent hand-calculated mean-variance fixture passed with a three-PSU stratum, an empty domain PSU, and nonfinite covariate/outcome values outside the domain. The weighted group-difference fixture checks the direct influence-function variance against `c'Vc`. The saturated BMI-group model therefore includes covariance between group estimates; it does not incorrectly add two independent-mean variances. Global weight scaling leaves estimates and variance invariant. Validation remains analytic-fixture validation, not independent replication in a survey package.

**Estimands and reporting.** Adjusted age/BMI coefficients, quadratic second differences, and ordered BMI-group differences provide nontrivial directional comparisons. The four declared primary endpoints have no desired direction. Raw and log-scale curvature, sex effects, subgroup means, and threshold diagnostics should retain their declared roles; the campaign's additional emphasis on ordered BMI contrasts should not silently become a new omnibus confirmatory score. There is no multiplicity-adjusted success criterion or validated equivalence margin.

Arithmetic TG means are positive by construction. Threshold proportions are nonnegative; their signs are not evidence of reproducing a relationship. For geometric cells the stored estimate is mean log(TG), whose sign is a unit-dependent comparison with 1 mg/dL, not a meaningful biological direction. Accordingly, `point_direction_agrees` must never be aggregated across all 67 endpoints as an evidence-fidelity rate. Restrict any directional summary to the prespecified association, curvature and ordered-contrast families. Subgroup means and threshold proportions can support explicitly labeled magnitude comparisons after an authorized future release. The evaluator's interpretation file already warns against positive-mean/proportion direction claims; downstream reporting must honor it.

**Amendment and release gate.** The first preparation used `PHDSESN=1` and reportedly selected zero eligible rows. The recorded correction to code 0 matches the official codebook. The corrected freeze is at 16:06:08 UTC, after the initial preparation receipt at 16:04:11 UTC; it transparently states `before_raw_download_or_parse=false`. The survey-analysis and evaluator hashes are identical in the initial and corrected freeze records. The records attribute the amendment to an eligibility-code error, before any endpoint analysis or generator release. The audit found no basis to characterize that correction as target-effect tuning, but did not independently reconstruct every historical action.

The evaluator checks explicit authorization, declared variants/seeds, candidate and output hashes, visible-input integrity, and a hash-anchored controller guard before its own hidden-table parse. It validates generated schemas and preserved covariates before parsing the hidden table. This is a useful procedural gate. It is not an OS boundary, and the imported controller guard is trusted code. This audit did not inspect or execute controller code outside the allowed custody scope and therefore does not independently certify harness execution or source-admissibility checks delegated to that guard. The no-op closeout should record evaluation authorization as false/withheld because evidence was insufficient; no permissive commitment should be issued.
