# C5 dynamic variable extension implementation pilot

31 October 2026. Authorized by the user's continuation after discussion of natural-language requests, data diversity and evidence-conditioned variable extension. This is a new bounded unit. C4 and all previously revealed real references remain closed.

## Question and scope

Can a fresh scientific Agent interpret a request to add a variable, construct an evidence-compatible conditional extension, and pass that extension through the existing isolated execution harness while preserving the existing synthetic records?

This first check uses one explicitly invented joint Gaussian population. It is an implementation and analysis-consistency pilot, not patient validation, a new statistical identity, or proof of algorithmic superiority. The complete source moments identify the chosen Gaussian model; derived analysis results are not discoveries of otherwise unidentified biology.

The user-facing entry point is a natural-language request paired with the external Agent's structured decision. A deterministic adapter validates that decision; it does not use a keyword parser or pretend to call an LLM. The surrounding session launches the Agent. No browser UI or standalone model service is claimed.

## Scientific and implementation ownership

- Root maintains this protocol, source admission, execution authorization, status and final interpretation.
- A separate fixture custodian chooses the invented source definitions and writes a public analysis plan, sealed analytic reference and evaluator. Root and scientific author do not read sealed results until all final outputs are committed.
- A fresh-context scientific author's task restricts scientific inputs to stage-approved source artifacts, task contracts, interface docs and their own submissions. The author chooses structure, parameters and conditional derivations; root does not supply desired slopes, residual SDs or generator formulas. Incidental historical-summary exposure and early root source intake are explicitly recorded in `EXPOSURE_NOTE.md`; this is a procedural information boundary, not a claim of complete role blindness.
- An implementation Agent writes a generic transition adapter, contract tests and usage documentation. It has no role in choosing scientific coefficients.
- An independent reviewer checks the new code/protocol and final interpretation. Agent roles are procedural; only generator execution has the existing OS-level isolation.

## Sequence and equal final information

1. Admit the custodian's initial packet containing only x1/x2 population moments, their joint Gaussian definition and a whole-cohort request. Create a source-bound harness task with no observed individual records.
2. The scientific author prepares and freezes a parent generator. The initial packet alone is used for that construction. No numerical feedback is supplied for revision.
3. Reveal the final permitted source packet, adding x3 and all necessary joint moments for the same artificial population. It contains no hidden evaluator outputs. The same author constructs a one-shot full-joint generator and a conditional extension generator using the same final evidence.
4. Obtain actual Agent-authored structured decisions for extension, analysis-only reuse, changed-population routing and an underspecified request needing clarification. Additional routing requests create no scientific tables.
5. Independently inspect candidates/contracts and freeze the execution schedule. Execute parent and one-shot full-joint candidates, then materialize each successful parent output as the corresponding child's synthetic observed input. Copy the already frozen extension template scientific bytes into each child, verify equality and freeze before execution.
6. Record a terminal status for all nine scheduled slots: success with output/receipt hashes, failure with the error receipt and no invented table, or blocked/not attempted with the failed dependency. If all nine outputs succeed, commit `final_output_manifest.json` and only then release the analytic evaluator. Otherwise close with a complete `terminal_failure_manifest.json`, preserve every available output and error, and do not reveal analytic truth or add runs to fill the missing slots. Evaluate all scheduled analyses in the all-success path, independently check the arithmetic and close this unit.

One author and two related constructions do not provide independent method replications. Parent construction sees less evidence by design; final joint and extension constructions see identical final evidence. The comparison measures two implementation routes under the stated sequential information order, not pure causal superiority or a formal non-inferiority test. No literal-row-versus-program comparison is performed.

## Transition semantics

The structured decision records the literal request hash, typed variable definitions, population, row identifier/count, reason, evidence references and unresolved information.

- `extend`: existing variable definitions and population remain the same; existing synthetic rows become explicitly labelled synthetic inputs for a new enrichment task. No row or old value may be changed. The new variable's model is authored by the Agent.
- `reuse`: the requested analysis requires no new variables or population change; bind the existing release and do not generate new rows.
- `new_population`: route to a separate version/intake decision; do not silently reinterpret old rows as a different population.
- `revise`: record a proposed scientific-version change, not an in-place edit. No revised population is generated in C5.
- `clarify`: record missing task information and do not fabricate a requested population or variable definition.

Changing the conditioning set can legitimately change a regression coefficient. Preservation applies to the existing data/marginal relationships, not to requiring every newly adjusted coefficient to stay unchanged. Evidence compatibility is a scientific judgement, not certified by schema validation.

Root authorization explicitly binds each parent execution, Agent decision and admitted source registry. Each child is a new task with zero revisions and an explicit one-extension allowance; extension is not a reset of a previous candidate's revision budget. Extra task creation requires a separate authorization, not an implicit counter reset.

## Evaluation fixed before generation

The custodian's public analysis plan gives precise formulas and unit conventions for:

1. Existing x2-on-x1 association and exact preservation of all parent identifiers/values.
2. New x3-on-x1/x2 adjusted association, reporting both slopes.
3. Conditional residual spread, so merely matching a conditional mean cannot masquerade as individual diversity.

Source moments and relevant distribution diagnostics accompany these uses. Report estimates and discrepancies for every seed, not only favorable draws. Reference quantities are exact invented population definitions. Finite generated-table differences are Monte Carlo variation. No clinical tolerance, inferential coverage guarantee, arbitrary percent pass rate or biological effect claim is attached to this fixture.

The hidden numerical reference is mathematically implied by the visible complete Gaussian evidence. Keeping it out of builder feedback checks procedural separation; it does not create a novel predictive-information test.

Nonzero spread alone does not establish its correct scale. No performance win is required or inferred.
