# C5 artificial dynamic variable extension archive

This archive records nine successful fixed generator executions: three two-variable parents, three separate one-shot joint draws, and three parent-preserving conditional extensions. Each table contained 2,000 fictional rows. The invented Gaussian source completely specifies the chosen model. This is an implementation and analysis-consistency pilot, not patient validation, a new statistical identity, or evidence of algorithmic superiority. It does not complete real-case gate F2.

Read [PROTOCOL.md](PROTOCOL.md), the [complete aggregate evaluation](evaluation/report.md), and [EXPOSURE_NOTE.md](EXPOSURE_NOTE.md). The latter preserves root's early final-source intake, the implementation Agent's historical-summary access, the scientific author's incidental Phase 2 historical-summary exposure, and the algebra helper's role within the same construction. Agent boundaries were procedural; OS isolation covered generator processes only. No complete role-blindness or independent method replication is claimed.

The export preserves original protocol, source, scientific-program and native receipt bytes. Original absolute paths and omitted table hashes remain provenance references. This archive cannot independently revalidate historical execution receipts or recompute historical table statistics because row tables and log payloads are deliberately absent. The source `STATE.json` and pre-execution review retain their recorded stage semantics; final interpretation and postrun closure are separate records supplied during root finalization.
