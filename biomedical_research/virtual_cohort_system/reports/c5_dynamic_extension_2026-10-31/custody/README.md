# Custodian boundary

The source is one invented population selected independently of candidates, previous cases, and outputs. No prior patient cases or generators were read. No target rows are stored here or generated by the custodian. The complete visible final moments identify all analytical answers; hiding this file is only a workflow boundary against outcome-file inspection, not an assertion that the answers cannot be derived.

Do not open `analytic_truth.json` or `evaluation/evaluate.py` as the controller or scientific author before the final-output manifest and its bound reveal authorization have been written. `source_commitment.json` is the outcome-free record of exact artifact hashes. Evaluation code checks those commitments and every scheduled table hash before reading the truth or tables. It never imports or executes candidate code.

The source constraints are exact invented population values, with no source-estimation uncertainty. Between-row residual variance and finite-sample Monte Carlo variation remain positive. There are no patient labels, clinical cutoffs, desired p-values, searches, calibration, output rejection, or outcome-based revisions.

Independent evaluator means a separately authored numerical evaluator, not an independent evidence source, Agent-arm implementation, clinical validation team, or proof of correctness under other models.
