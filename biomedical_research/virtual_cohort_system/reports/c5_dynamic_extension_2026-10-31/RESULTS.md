# C5: evidence-conditioned dynamic variable extension

31 October 2026. **The narrow extension prototype ran successfully in one artificial, fully identified Gaussian case.** An Agent authored a parent generator, a complete joint generator and a conditional extension. Nine scheduled executions completed without a replacement run. All three extensions preserved every existing identifier and value. This supports implementation feasibility; it is not a biomedical validation or a demonstrated accuracy advantage.

The project remains evidence-guided generation of reusable virtual biomedical data, including complete cohorts with no individual inputs. Dynamic requests are an optional entry and reuse capability, not a replacement for that scientific objective.

## What was implemented

The session's scientific Agent interpreted natural-language requests and returned a typed decision plus a scientific specification. A deterministic adapter checked the decision, admitted-source bindings, variable definitions, units, population identity and the parent execution. It then prepared the appropriate task. The interface is exercised through files and controller calls; it is not yet a deployed conversational application or autonomous literature-search service.

| Request | Actual Agent decision | Controller behavior |
|---|---|---|
| Add x3, preserving the existing x1/x2 records | Extend | Construct a new enrichment task; copy the fixed parent input; execute the frozen conditional model |
| Analyze variables already present | Reuse | Bind the existing completed release; generate no extra rows |
| Request a new specified population | New population | Record a separate intake route; do not silently change the existing dataset |
| Add an unspecified additional marker | Clarify | Record missing information; invent neither its definition nor a relationship |

The request interpreter was an actual scientific Agent, not a keyword parser. These four decisions were reviewed individually; they do not measure general natural-language understanding accuracy. `revise` is supported by the adapter contract but was not a scientific revision arm in this experiment.

The Agent selected the Gaussian construction supplied by the invented evidence, derived its joint covariance and conditional distribution, wrote the generator and documented assumptions. Root authored admission and execution controls, not the scientific relationship coefficients. A separate algebra helper assisted the same author; this is one construction, not independent author replication. Execution uses the pre-existing WSL/bubblewrap runtime. Generator code was never imported into the host process.

## Experimental information and sequence

The initial packet specifies the x1/x2 Gaussian marginal. The author froze its parent candidate before being authorized to read the final packet. The final packet adds x3 and its joint moments; both complete generation and conditional extension receive this same final information. No actual individuals are supplied to either whole-cohort generator. The extension receives rows from the frozen synthetic parent, explicitly labelled as synthetic inputs.

All moments are invented exact population constraints. These are neither extracted publication estimates nor uncertain real-population measurements. The complete Gaussian packet identifies the analysis answers mathematically. Consequently the withheld analytic file is an implementation check, not evidence of discovering an unreported biological association.

The [protocol](PROTOCOL.md), source commitments, candidate bytes, runtime code and nine-slot schedule were bound before execution. Three independent random draws of each route used 2,000 rows each: three two-variable parent tables, three complete joint tables and three parent-preserving extended tables. There are six final three-variable tables, not nine independent cohorts. There was no calibration, source-feedback revision, parameter search, additional seed or row selection. The zero retrieval budget applies only to this sealed invented fixture.

The final output manifest was committed before analytic release. All scheduled analyses were then computed. [Exposure disclosures](EXPOSURE_NOTE.md) retain early root access to final source evidence and incidental historical-summary access by the implementation Agent and, during Phase 2, the scientific author. No pre-release access to C5 sealed answers or actual generated rows by the author is recorded. Procedural input restrictions are not OS-level isolation of the Agent's general tools.

|---|---:|---:|---:|
| A1: x2-on-x1 slope | 0.7500 | 0.7584 [0.7024, 0.7894] | 0.7525 [0.7257, 0.7771] |
| A2: x3 partial slope for x1 | -1.3626 | -1.3932 [-1.4563, -1.3290] | -1.3149 [-1.3601, -1.2620] |
| A2: x3 partial slope for x2 | 0.9279 | 0.9487 [0.9211, 0.9894] | 0.8913 [0.8630, 0.9265] |
| A3: conditional residual variance | 42.8339 | 42.4420 [41.1794, 43.5282] | 44.0059 [42.7013, 44.9603] |
| A3 companion: conditional residual SD | 6.5448 | 6.5143 [6.4171, 6.5976] | 6.6333 [6.5346, 6.7052] |

All six full tables preserve the negative x1 and positive x2 adjusted directions. Magnitudes vary across seeds and routes. In the extension arm the largest residual-variance deviation is +2.1265; the largest absolute x1 slope deviation is 0.1006. These are retained rather than repaired. No clinical tolerance, post hoc accuracy pass threshold, equivalence or superiority test was introduced.

Every old identifier, x1 and x2 cell is identical in each parent/extension pair, both as parsed values and as written CSV tokens. Across the three pairs this covers 6,000 rows and 18,000 old cells including identifiers. The original x2-on-x1 estimates are exactly unchanged. This does not imply that adding a covariate to a different regression should leave its adjusted coefficient unchanged.

The new values include evidence-derived conditional residual variation. Independent formula review checks its scale, not merely whether it is nonzero. This demonstrates individual variation under the stipulated law; it does not establish diversity of scientific structures, robust subgroup coverage, or uncertainty about real-study transport.

The [complete endpoint report](evaluation/report.md) and [machine-readable evaluation](evaluation/evaluation.json) retain every intercept, slope, residual scale, source moment, covariance, correlation, prespecified quantile and population-conditional residual diagnostic for every seed. There is no endpoint-specific regeneration. The [figure](assets/analysis_routes.png) displays all six full-table draws.

## Verification and cost

Before scientific execution, 37 focused adapter tests and 8 current independent controller/commitment tests passed. An earlier four-test controller receipt is retained but is not counted as four additional distinct tests. The first adapter test invocation failed because its temporary parent directory did not exist; that technical setup failure remains recorded. A separate pre-execution science review passed 68 exact-arithmetic, native-contract, source and routing checks, including the six-file scientific template copy. These checks did not execute the scientific generators.

Nine actual generator executions used the isolated backend and returned success. Native receipts report a summed execution duration of **8.048 seconds**, ranging from 0.625 to 2.844 seconds. This is executor time only, excluding Agent construction, independent reviews, coordination and documentation. Token usage, monetary cost and labor savings were not metered. No training, new paid API, HPC, patient-data download or recurring automation was started.

The [independent postrun audit](review/postrun_audit/POSTRUN_AUDIT.md) passed: all 48 endpoint estimates and 210 diagnostic estimates were recomputed from the actual tables. Across estimates and their derived summaries, 1,213 numeric fields agreed within numerical rounding (maximum absolute difference 4.26e-14). The audit also passed 649 structural/integrity checks and all 10 committed source/custody/evaluator hashes. Eight explicitly bound historical artifacts remained unchanged; this is not a byte audit of the whole project history. No disagreement or scientific rerun occurred. Clinical/raw individual records and generated row tables remain local; the private repository receives only reviewed code, invented source definitions, scalar summaries and provenance records.

## Decision for the method and manuscript

Retain this small adapter as an optional capability: reuse existing data when possible, add a scientifically specified conditional variable when justified, and explicitly route population changes or missing definitions. The same source-consistent Gaussian law can be represented as joint generation or conditional extension; their compatibility is standard probability theory, not a new method contribution. This experiment does not show one route is more accurate.

The useful observation is that extension need not destroy existing analyses, and a new variable need not collapse to a deterministic predicted mean. The study does **not** test whether an Agent can infer an arbitrary missing biological relationship from insufficient publications. A larger generated table does not create additional measured evidence.

The next scientific step is one separately admitted real case with applicable joint or conditional published evidence, a precise target population and approximately three prespecified analyses. First consolidate the compact core method and its source-only feedback/revision replay; then freeze the real-case contract before target outcomes. Reuse the existing generation machinery and this adapter only if the chosen information regime calls for extension. Evaluate source uncertainty and transport assumptions separately from simulation variation. Do not reopen exposed references, broaden this toy matrix, or make a full conversational platform a prerequisite for drafting.

C5 supplies an implementation appendix and a dynamic-use example. It does not by itself complete the whole core-method freeze (F1), real-case admission (F2), manuscript claim lock (R1), or a novelty claim. The [draft checklist](../../docs/DRAFT_READINESS_CHECKLIST_2026-10-31.md) remains the decision framework.
