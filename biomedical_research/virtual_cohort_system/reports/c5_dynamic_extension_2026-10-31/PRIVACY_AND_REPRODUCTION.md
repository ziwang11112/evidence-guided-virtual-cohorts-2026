# C5 export privacy and reproduction record

The source is explicitly invented, fully specified Gaussian population metadata. The JSON source packets and analytic truth contain small means/covariance/correlation/derivation objects. `evaluation/evaluation.json` contains per-run scalar estimates, source-moment discrepancies, quantiles, arm summaries and three preservation/comparison records, not 2,000-row records. Its largest array contains seven interpretation constraints. Native worker reports contain row counts, variable names, runtime versions and isolation probes; they contain no output values per person. Transition provenance records identify synthetic column origins and table hashes, not patient measurements.

The explicit copy allowlist excludes every CSV/TSV, including nine generated scientific tables, three child `observed.csv` tables and three execution-input copies. It also excludes scientific execution log files, duplicated execution-input payloads, Python caches, and all temporary test-fixture trees. No patient table, downloaded source paper, credential or external account token is part of this archive.

Native execution, launch and binding receipts are intentionally byte-identical historical metadata. They retain original local Windows paths and the WSL runtime home path. These paths are machine configuration provenance, not a claim that those paths exist in a recipient's clone. Original generated-table hashes remain in these receipts and in the final-output manifest, although the associated rows are not exported. Omitted files mean native full-execution verification and historical evaluator recomputation cannot pass from the archive alone.

Raw JUnit XML embeds a hostname and, for the initial failed setup, verbose traceback bodies. Instead, `TEST_RECEIPTS_SUMMARY.json` retains each XML source hash, suite timestamp/counts and per-case name/outcome. This is a disclosed metadata transformation, not a new test run. All 35 initial fixture setup errors are retained as an outcome; no test bodies ran in that attempt. The original `method/test_receipt.json` and review bindings remain unchanged, so their raw-XML hashes refer to intentionally omitted local originals.

Every copied source file has an explicit destination and identical SHA-256 in the manifest. The export-created README, privacy record, staging helper and JUnit summary have local source files under `work/c5/export/` and are covered in the same mapping. The manifest itself cannot include its own digest; the separate audit binds it. Any later root-added results/closeout/review files require manifest extension and a refreshed final audit.

The staging helper is a separate allowlist for a new `project/work/c5`, not an archive restoration command. It omits all historical execution state and child inputs while retaining exact original parent/joint candidate input commitments. It defaults to list/check and requires `--stage` to copy files; it cannot launch generation. See the archive README for the unexecuted replay procedure and required existing isolated WSL runtime. Fresh replay is neither tested nor claimed to regenerate byte-identical tables.

The historical disclosure remains complete: root saw final source evidence early; the implementation Agent read historical summaries; the author incidentally received historical summaries in Phase 2; a fresh algebra helper assisted the same construction. The independent structural and postrun checks must not be recast as independent scientific populations or methods. Exact Gaussian truth is implied by the permitted evidence, and this archive does not support clinical validity, algorithm superiority or completion of real-case gate F2.
