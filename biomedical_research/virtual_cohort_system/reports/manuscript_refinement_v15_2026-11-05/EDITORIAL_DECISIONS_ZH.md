# v0.15 的核心故事与图表取舍

2026-11-05。本轮是基于已完成实验的编辑与图形重绘，没有生成新个体、重估真实数据或调节生成器。投稿判断另见本目录的 VENUE_AND_STORY_AUDIT.md；本文不以版式变化代替科学证据。

## 一句话主线

**研究者给出科学问题、人群和可获得的文献证据，Agent 负责把研究条件不同的局部统计转成联合生成模型，交付可以继续做科学分析的虚拟数据。**

完整人群生成是已经运行的主要场景，包括完全没有个体输入的情况。补充未测指标和缺失值仍属于总体方向，但按各自已经获得的证据陈述，不能混为本次全部验证成功的能力。

## 学习近邻论文的论证组织

[G-Sim（ICML 2025）](https://proceedings.mlr.press/v267/holt25b.html) 从模拟器的实际用途提出所需能力，连接结构设计、校准和检查，再展示建成的模拟器能支持什么分析与决策。我们借鉴“问题—实质方法动作—输出用途”的次序。其结构修改/校准能力有自己的实验证据；本项目没有据此新增同样的提升声明。

[LLMSynthor（KDD 2026，v4 全文）](https://arxiv.org/html/2505.14752v4) 把宏观信息、生成决策和评估问题分开，并通过不同显示呈现统计一致性、联合结构及应用用途。我们借鉴这种按问题分面、在原单位呈现结果的组织方法。它也使用 LLM 依赖推断、生成计划和反馈，不能把“用了 Agent”或“没有个体训练数据”单独当作排他的创新。

本轮复核了上述官方论文记录、G-Sim 的问题/方法与主文结果页面，以及 LLMSynthor v4 的方法和实验文字。v4 PDF 的网页读取因 18.8 MB 大小限制失败，因此未声称逐页检查其 v4 PDF 排版，也没有将近邻图稿复制进本文。

## 三项贡献如何写得更具体

1. **明确实际任务。** 文献级局部证据到面向科学分析的虚拟生物医学数据，保留人群、测量、调整集和可用信息条件。它比泛泛的“自动生成数据”更能说明研究问题。
2. **说明 Agent 承担的科学工作。** 选择证据的数值角色，解释边际与条件关系，推导兼容的参数，选择联合分布并记录未测关系假设。随机采样由程序执行，不削弱 Agent 在模型设计中的作用。
3. **用分析用途检验产物。** 关系证据的信息对照、HbA1c/血脂跨需求构造、给定摘要重构，以及纵向与开放检索例子形成不同层次的证据。它们的信息条件不同，保持各自统计口径。

这是方法与实际任务的组合贡献。当前不能只凭流程名称断言算法新颖，也不需要把“优于任意专门设计统计生成器”设为总目标。近邻的具体任务上进行公平比较可以增强证据，但不把尚未做的比较写成结果。

## 主文的阅读顺序

从一个没有完整个体数据的研究需求开始，解释为什么把论文数字直接拼接不能得到所需联合模型。接着给出 Agent 的三个关键动作和一个真实参数推导例子。结果先回答关系证据有没有用，再回答同一流程能否完成不同指标需求，最后说明掌握目标摘要时能够实现怎样的重构。

检索次数、运行尝试、每个生成器家族的细节、所有来源和检查记录保留在补充材料与公开工件中。旧版本继续保留。限制集中在实验解释和讨论中，不让每个段落重复一整套声明；各结果自己的关键反例仍在对应段落明确呈现。

## 四张主图各自完成一项论证

| 主图 | 读者要理解的问题 | 呈现原则 |
|---|---|---|
| 1：实作方法 | 论文证据怎样进入真实生成模型？ | 保留具体数值转换、模型与采样操作；不把日志或文件哈希放成中心机制 |
| 2：关系证据信息对照 | 增加关系证据后，预定分析发生了什么变化？ | 六个分析全部呈现，包含 CHNS BMI 恶化和统计参照；不把不同单位合成分数 |
| 3：HbA1c 与血脂 | 同一流程的不同构造支持哪些科学关系？ | 全部六个构造、全部最终种子；清楚显示效应幅度和 TC–HDL 残差依赖差异 |
| 4：给定摘要重构 | 当相关统计可以提供给 Agent 时，数据能保留什么？ | 五项分析全部保留；标明这是输入摘要的重构用途 |

开放检索、纵向使用、分布波动和解析依赖敏感性四张图转入补充材料；这是证据层次和版面安排，不是删除不利结果。原来两张主数值表也保留完整数值，避免图表重复占据主文。

新结果图采用蓝、紫、赭色和灰色；固定科学含义，减少大标题与重复脚注，依靠面板标题、坐标单位和图注解释。按照最终约 7 英寸的排版宽度设计字体。每次重绘核对同一份汇总数据，既不改变坐标数据，也不删除种子或构造。

## 目前最值得强调的实证内容

关系证据在历史主实验的六个分析中降低了五个的平均偏差，说明信息内容能够影响生成数据的科学用途。新的两类需求显示 Agent 可以独立选择不同生成模型，并保持预定关系的点估计方向；同时，效应大小、波动和联合依赖并没有一并恢复。给定摘要的单独实验展示了更接近参照的联合重构。

这条故事可以围绕“证据如何成为有分析用途的数据”展开。当前结果支持的用途要按具体分析界定；新目标上的定量可靠性仍需另行验证。TC 参照区间跨零、所有构造保留原稿、来源数值检查不可用等事实继续保留，不能将版面精简变成结果升级。
