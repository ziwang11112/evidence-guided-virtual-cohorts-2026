# Independent adaptive-case numerical review protocol

Prepared before opening this unit's generated outputs or reference payloads. The existing case and requested endpoints are fixed by `PROTOCOL.json`; the reviewer does not choose scientific parameters, target signs, favorable versions or extra seeds.

## Preclosure boundaries

Review trusted adapter/evaluator/closure source and pure existing estimator definitions only. No original reference payload or generated-row inspection occurs until the root confirms author completion and `AUTHOR_CLOSED.json` exists. Do not execute author program source on the host, generate additional rows, refit a clinical reference, or change locked design/author-session files. Corrections to postclosure evaluation must preserve the locked original and carry an explicit amendment.

The generated-only adapter invokes the pure existing lipid provider and contains no reference access. Its callback and dependencies are pinned in the session configuration. Postclosure evaluation must verify the completed adaptive session, all closed bundle artifacts and the external adapter/dependency commitments before reference access. Only the existing frozen aggregate reference may supply evaluation values; no target result is returned to the author.

## Coverage and calculations

Retain each submitted stage and all three predetermined seed attempts (9401–9403), including failures. Every run and stage must retain all three primary IDs and 23 diagnostic IDs, with explicit unavailable states and denominators where needed. An uncomputable generated endpoint cannot be an available comparison.

The independent script converts delivered TC/HDL from mmol/L to mg/dL using 38.67, fits the intercept/age10/F-indicator/bmi5 design, computes both BMI coefficients and Pearson correlation of matched residuals, and computes the 23 fixed moments, linear quantiles, conditional RMS values and F fraction. It independently applies the frozen numerical rank/constant-response/residual-variation availability rules. It imports no generator, provider or evaluator. The explicit `--run-postclosure` switch is required and the closure gate precedes all report or generated-data reads. The script never opens original clinical-reference files.

Check closure and receipt/output hashes; compare 26 statistics per successful stage/seed against `EVALUATION.json`; retain failed attempts and unavailable endpoints. Numerical tolerance `1e-9 × max(1, |reported value|)` checks arithmetic consistency only. No clinical agreement threshold follows from it. Verify all comparison arithmetic and stage means/ranges separately, including initial-to-final improvements, worsening or unchanged results without selecting a favorable seed. Direct-row copies repeated across seeds remain one table.

## Reporting limits

Display all primary units and supplied numeric intervals. Existing lipid slope intervals are HC3 normal assumption-conditional sensitivity intervals, not equivalence margins or design-based clinical confidence intervals; residual correlation has no supplied interval. Generated seed ranges describe simulation variation. Only the two existing lipid sample-SD diagnostics have aggregate reference values; preserve the other 21 as generated-only.

The result review concerns numerical/reporting correctness. Source-use and scientific transfer are separately reviewed. One author, one case and previously exposed aggregates cannot establish a causal effect or general superiority of skills, retrieval or revision. Record retention when no scientific revision was selected.

## Initial implementation findings

The locked original evaluator drops all-unavailable endpoints from stage summaries and leaves failed-run endpoint lists empty; its comparison label can say available when the generated value is unavailable. Its gate does not recheck the completed session/external callback commitments, and its Markdown omits numeric intervals and units. These require a versioned evaluator amendment before reference evaluation. Arbitrary failure-message text should remain local rather than enter a public aggregate report. No locked file was edited by this review.
