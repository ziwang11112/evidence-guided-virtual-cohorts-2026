# v0.26 独立批判性审阅：贡献成立在哪里，薄弱点在哪里

审阅对象：2026-11-09 的 v0.26 稿件及其对应实验、协议和部分实现。审阅输入的哈希见 [SCOPE.md](SCOPE.md)。我完整阅读了正文和补充材料，查看了主图及对应 PDF 页面，并分别委派新的上下文审查统计解释、实际方法实现和近邻创新。它们是辅助交叉审查，不是三位外部专家或三家模型的正式同行评审。

本轮没有改论文、改冻结结果、读取患者级表、生成新数据或调参。只有已有汇总数据的事后稳健性算术检查；其性质不升级为新确认实验。

## 1. 总体判断

**这个项目有实际的、可以写清楚的贡献，但当前最充分支持的是有限场景下的科学 Agent 工作流与分析用途研究。它还没有证明一个普遍可靠、能替代未知患者数据的生成方法。**

我不会因为它没有击败“充分设计的所有统计方法”、没有多 Agent、没有新 loss，或反馈后没有提高，就否定它。最终数据的用途才是主线。Agent 确实选择了模型结构、数值关系和补充假设，程序负责抽样，这仍然是 Agent 驱动的数据生成。

但若把它作为较强的 Agent 方法贡献来投稿，审稿人仍会追问：究竟交付了什么可复现的方法？哪些研究用途已经被证据支持？不知道真实答案时，使用者如何理解生成结果的适用范围？当前论文对这些问题还没有给出足够集中的答案。

**上一轮“核对通过”的正确含义是数值、来源归属和成稿一致，不是科学用途充分、创新强度充分或已经可以直接投顶会。** 我仍认为没有理由把全部旧实验重跑；与此同时，也不能把“准确披露限制”误认为“限制已经被验证解决”。

## 2. 值得保留的实质亮点

| 已有亮点 | 证据及正确解释 |
|---|---|
| 从研究请求和外部文献构造完整数据 | Q4 四位构造者选择了不同概率模型，形成十二份最终表。不是只补一列，也不是根任务把目标系数直接写进固定模板。它证明工作流能够执行建模任务。 |
| 同一表能表现多变量分析结构 | ENSANUT Q4 两个模型的所有抽样都保留了加入血糖后 BMI 系数减弱的现象。这个现象比单纯输出正相关更有信息，但不是因果中介发现，也不保证数值适用。 |
| 增加关系证据的实验组中，多项分析误差更小 | Q1 六项对比中，五项 E1 平均绝对差异低于 E0，一项更差。审阅时改用构造者误差中位数，及每臂分别移除一位构造者的敏感性计算，六项方向均保留。详见统计审阅及算术工件。这仍是描述性信息对比，不证明因果效应或所有人群中的普遍优势。 |
| 能追溯科学选择如何改变结果 | Iron 两个生成器的迁移与依赖假设有可检查的代码和解析后果。Agent 的建模决策确实会改变数据，而不是只负责格式化文本。 |
| 有具体失败信息，而非只有成功分数 | 关联方向、效应幅度、残差波动、连续依赖和阈值联合率可以分开失真。这样的完整记录可支撑有价值的经验性方法论文。 |

## 3. 最重要的六个薄弱点

### A. “可分析”“相似”“可用”尚未形成清楚的用途分级

**优先级：高。性质：主要是论证和评价定义不足；不是要求逐行等同真实数据。**

正文 5.1 的 useful associations，以及讨论中 strongest use 的措辞，比实际判断依据更强。能成功拟合回归、保留符号、接近效应量，以及足以做某项研究判断，是不同层次。

Q4 提供了具体例子：

- CHNS 条件年龄参照是 0.008107 pp/年；C01、C02 均值为 0.003109、0.005628，分别低约 62% 和 31%。
- ENSANUT 年龄参照是 0.075132 pp/十年；E01、E02 为 0.103084、0.097724，高约 37% 和 30%。
- Q5 H03 的条件 BMI 系数接近参照，但 HbA1c SD 为 0.3523 对 0.5274，残差 RMS 为 0.3006 对 0.4885。

这些百分比是相对当前样本点估计的描述，不是已知总体偏差，不是新的通过阈值。它们说明：“方向对”不足以宣布研究用途普遍成立，尤其不能顺带认定功效分析、个体差异或尾部研究可用。

**最小修改：**为每项用途增加一行解释：研究者想据此作什么判断；已观察到什么一致性；哪些性质没有验证；目前能否用于探索/方法演示，还是已有足够证据作定量推断。现有结果可保留为连续差异展示，不要看完结果后临时定一个“全部通过”的标准。将个别笼统 useful 改成具体观察，如“保留方向及调整后的衰减，但幅度和残差波动仍有偏差”。

依据：稿件 5.1、5.4、S3、S5；[统计审阅](STATISTICAL_REVIEW.md)。

### B. 实际方法包含必需的来源/代码审查，主图和正文没有完全体现其工作量与角色

**优先级：高。性质：方法规格和贡献归属需要更准确。**

Q4 并非“普通用户给个请求，单个 Agent 自由生成，之后跑一次检查”这么简单。它先提交来源与模型提案，经过来源和科学审查；冻结前允许机械/来源修正；每次冻结和最终选择还要求独立审查绑定。根 Agent/其他审查者参与了具体判断。S3 已承认审查，问题不在于完全没披露，而在于主方法把它压缩得太轻。

Iron 的来源包还预先给出了单位换算、粗 OR 与调整 OR 的区别、另一个来源只能作背景的限定。这些有效工作不能全算成生成 Agent 自己从零发现。与此同时，A 的 2/3 权重和 1/5 重抽样确实是其自行选择的迁移假设。

**最小修改：**增加一张执行职责表，把研究者、宿主 Agent、独立审查、生成 Agent、数值工具分清楚；写明每个核心实验的必需阶段和修改预算。说明“保留初始模型”是保留第一个已经审查并冻结的模型，不一定是未经修正的第一次回答。这不要求新增多 Agent 架构，更不要求证明协作优于单 Agent。

依据：稿件 2.2、S3、S10、S12；Q4 `prepare_batch.py`、`runner.py` 和审查收据；[实现审阅](METHOD_REVIEW.md)。

### C. 程序可以复算，但 Agent 建模过程还没有同等级的可复现性

**优先级：高。性质：核心 Agent 论文的可复现性短板。**

Q1 的关键调度文件直接写着继承宿主模型、精确 backend 未暴露；Q4 记录了新上下文身份，却没有完整模型调用配置。控制器本身明确不是模型启动器。公开代码还保留原来的 Windows/WSL 路径和未公开的审计依赖。

因此应区分三种能力：重画汇总结果图；运行保存的冻结生成器；让另一位研究者重新发起 Agent 完整建模任务。当前前两项的材料更充分，第三项并不等同于 `git clone` 后即可复现。这里没有发现一次新的数值错误，也没有实际执行干净环境复现后报告失败；这是由代码和发布说明直接显示的环境依赖与记录限制。

**最小修改：**给主要实验做模型/宿主/任务/工具/审查/预算版本卡；缺失字段明确写“未记录”，不能追认当前模型为历史模型。给出一条不改旧收据的、可独立理解的冻结生成器重放说明，并区分公开可复算部分和需合法数据访问的部分。若未来要验证“这套 Agent 方法可重复运行”，再对一个固定的新版本完整记录真实调用。

依据：稿件 Limitations、S8、S10；Q1 `FIRST_PAIR_DISPATCH.json`；Q4 `STATE.json`、`PUBLIC_SCOPE.md`；[实现审阅](METHOD_REVIEW.md)。

### D. 主要正面结果与最强验证条件并未落在同一个位置

**优先级：高，但取决于最终主张。性质：外部有效性限制，稿件已有披露。**

Q1/Q4/Q5 的正面结果主要来自已在项目中暴露过的参照；新构造者没有收到目标答案，这支持其建模行为，但不把项目级开发选择变成新的独立确认。Iron 的封存设计更强，然而两个模型的主要 OR 与参照明显不一致，六个估计均低于参照置信区间下限；A 接近联合率，B 接近秩相关。Iron 没有预设可接受差异的通过线，不能将其等同于未通过某项既定门槛。较早前瞻波次则确实没有通过原定整体标准。

这些事实不否定所有数据用途，也不证明后续方法无效。但当前不能把“很多表、很多 seeds、很多独立复算”当成已经有很多成功的新队列验证。

**最小修改：**在主要结果总表中并列输入条件、参照暴露状态、真正构造数、目标人群与主要分析结果，让重建、开发性对照、封存比较各自承担正确证据角色。可以说某表的某个性质接近参照；没有一个事先的选择规则时，不能在不知道目标的应用中保证总能挑到 A 的最佳分析和 B 的最佳分析。

**什么时候才必须补实验：**只有要增强“在新任务/新目标上可靠生成”这一主张时，才需要一个方法、预算、用途和评估均提前固定的独立确认。重复生成已暴露目标不能解决这个问题。若目前没有合法、未暴露参照，就保留有限可行性的定位，不自动扩展数据搜索。

依据：稿件 4、5.3–5.4、S7、S9；[统计审阅](STATISTICAL_REVIEW.md)。

### E. 创新点可成立，但目前是工作流和应用贡献，算法新意有限

**优先级：中高。性质：定位，不能靠加组件修复。**

[G-Sim](https://proceedings.mlr.press/v267/holt25b.html) 已包含 LLM 构造模拟器、校准和结构修订。[LLMSynthor](https://arxiv.org/html/2505.14752v4) 不仅匹配汇总量，也涉及依赖推断和下游用途。[KMGen](https://proceedings.mlr.press/v340/jiang26a.html) 已将 agentic 文献解释与医学个体记录抽样连接起来。不能把“别人不是 Agent”“LLM 加程序生成”“有检查闭环”当作充分区别。

我们的可辩护区别更具体：Agent 在不同人群、测量和调整条件下使用局部医学证据，自行选择连续生物标志物的联合生成结构，交付可追溯的程序，并分析同一表中哪些科学结果被保留、哪些依赖未确定假设。这是有价值的研究问题和工程/实证贡献；既不要求新概率分布，也不自动等于强算法创新。

**最小修改：**在贡献段清楚列出“方法交付”“使用场景”“经验发现”，在近邻表中比较输入、谁确定联合结构、分析用途和验证方式。修补 LLMSynthor/KMGen 的压缩描述，承认真正重叠。不要为了像算法论文而临时加入未经证实的新 loss、rubric 或多 Agent 组件。

依据：[近邻与创新审阅](NOVELTY_REVIEW.md)，其中包含五篇近邻原文和一项更正的逐项比较。此处是对已读文献的定位判断，不是排他性优先权证明。

### F. “生成数据可继续分析”还需要更明确的推断使用说明

**优先级：中高。性质：研究用途界定，不要求本轮解决完整统计理论。**

稿件 3.5 已正确说明，增加虚拟行数不会增加真实证据，种子范围也不代表迁移不确定性。这很好。但交付给使用者的数据仍可被任意扩到几万行并直接做显著性检验。常规模型输出的标准误主要反映在给定生成模型下抽样的变化，不会自动纳入来源估计、模型选择和迁移假设的不确定性。

如果论文把用途写成“开展科学分析”，读者需要知道其允许的解释范围。目前没有独立验证的适用性预测器，也没有普遍有效的合并不确定性机制。不能用 Agent 的来源支持标签替代这一验证。

**最小修改：**随每份数据附一个简短分析用途说明：合成性质、来源支持、关键假设、已检验用途、未检验用途、区间的解释。当前可以支持探索性分析与情景计算，不声称扩大合成样本即可得到新的临床证据。若要支持正式功效、置信区间或假设检验，再针对该用途验证；不必为了当前论文一口气补完所有推断理论。

依据：稿件 3.5、S6、Limitations；[统计审阅](STATISTICAL_REVIEW.md)。

### 另两处值得立即补清楚的细节

**目标参照的完整定义。** ENSANUT 并非笼统的“墨西哥成人”：已有协议限制了既往诊断、记录的空腹时长、血糖低于 126 mg/dL、有效人体测量等条件，并按八个年龄×性别单元等权分析，而不是全国调查权重。主文只突出年龄和样本量，会让使用者误解该比较的科学含义。应从现有 case card 整理一个完整但紧凑的参照定义表，不需要重新拟合患者数据。

**真实—真实比较的尺度并不对称。** 现有比较使用两个互补真实子样本的差，与固定生成估计到两个子样本距离的平均值。举例，若两个真实估计是 m+d、m−d，而生成估计等于 m，那么前者距离是 2|d|，后者是 |d|。这只是说明比较几何不同，不是声称实际回归恰好满足这个等式。其结果可解释差异量级，不能直接成为“生成与真实一样好”的通过线。现稿已声明描述性，应再补这层具体原因。

两项均详见 [统计审阅](STATISTICAL_REVIEW.md)，属于现有材料的说明补全。

## 4. 不是本轮应该重新折腾的事

- 不需要证明每次反馈都有效；多数保留初稿可以是真实结果。
- 不需要强制多 Agent、训练、新 loss 或无限检索。
- 不需要击败一个定义不清、可无限人工优化的统计方法。
- 不需要让每个合成样本或每个统计量与真实样本完全相同。
- 不需要把旧实验全部迁移到最新版重跑；旧版本按真实身份保留。
- 不把未算出的来源检查改称通过；不把已有符号一致换个名字升级为新机制。
- 不把人群差异当成忽略所有偏差的理由，也不把样本点估计当作总体真值。

固定统计对照的信息使用不对称已在稿件披露。它可以保留为一个明确的比较点。若不主张一般性优势，无需为了反驳所有可能统计建模方案扩大实验。本轮中位数/删一构造者检查也没有将其升级为方法排名。

## 5. 故事线和图表的审稿风险

主图和结果图已经能够读懂，未在检查页面发现严重遮挡或裁切。问题主要是叙事负担：

1. 图 1 把反馈闭环放在视觉中心，读者容易以为主要贡献来自修订；实际最强结果大多是保留首个冻结模型。应在图旁说明实际角色，并让“证据到联合模型的科学选择”更突出。
2. Iron 被用来详细解释方法，但主要 OR 与参照明显不一致，六个估计均低于参照置信区间下限。它仍是诚实而有信息的机制例子，应该明确其教学角色：展示迁移假设如何造成不同结果，而不是整个方法的成功广告。
3. 图 3 与图 6 展示的各项方向和幅度容易被概括成一个“可用率”；应避免。图 4 的 5/6 信息对比是更有力的实证问题，建议摘要保留且与完整误差展示绑定。
4. 标注、公式、旧实验编号、执行次数和审计次数较多。它们有审计价值，但主文应优先说明用户问题、Agent 关键选择和科学后果。细节可以集中到一张复现卡和补充材料，避免研究日志感。

## 6. 下一步的最小行动，不自动开新实验

**第一步：只改清楚，不改结果。** 建议 v0.27 完成四项：用途与证据等级表；真实执行职责/审查表；Agent 调用与程序复算分开的版本卡；精确的近邻差异与贡献段。顺手收紧 useful/support 的几处措辞。模型、参照、原协议和旧结果不变。

**第二步：让 biomedical 合作者审查“用途判断”。** 最需要其判断的不是代码能否执行，而是每项实际研究问题对偏差、变异、迁移人群和测量差异的容忍范围。先给全结果和假设，不请他根据已看到的好结果找有利解释。

**第三步：按最后保留的主张决定是否只补一个关键证据单元。** 如果定位为有边界的工作流与用途研究，现有实验可以组成完整稿件，主要做前两步。若要更强的可靠方法论证，先把固定版本、已知模型配置、必要审查、研究用途及评估冻结，再做有合法未暴露参照的确认；若没有该参照，就不要把旧样本重跑包装为确认。无需同时扩展多个疾病、训练和多 Agent。

我的推荐是先完成第一步。现阶段最应避免的是一遇到审稿疑问就增加新组件，最后方法身份和证据条件又发生变化。

## 7. 审阅边界与文件

- [实现与可复现性审阅](METHOD_REVIEW.md)：主程序、任务、审查阶段和公开重放范围。
- [创新与近邻审阅](NOVELTY_REVIEW.md)：既有能力、可辩护差异和叙事。
- [审阅范围](SCOPE.md)：未修改实验、未运行生成器、未查看患者级数据。

没有执行每一行代码或重新复算全部历史结果，也没有进行临床专家评审。因此本报告不作“系统无任何问题”的认证。选定实现路径未发现推翻数值结果的新错误；发现的是用途论证、方法规格、可复现性和外部验证强度上的真实薄弱点。
