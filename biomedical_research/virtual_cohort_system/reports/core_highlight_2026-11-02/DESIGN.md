# Core highlight experiment: evidence to reusable biomedical data

2 November 2026. Design and admission work, **not an execution release**. This responds to the user's decision to finish the important contribution-defining experiments before finalizing the manuscript method. Wave A remains completed and negative under its frozen primary gate; its targets and all earlier revealed targets stay closed.

## Decision and scientific contribution

Prioritize one prospective biomedical experiment: **does adding applicable published joint/conditional evidence improve several scientific analyses of the same Agent-generated cohort?** The output remains a virtual dataset and its generation recipe, including generation with no participant inputs. The question is not whether a new Agent platform beats an ordinary Agent.

The candidate contribution is a practical method that translates partial, study-conditioned evidence into reusable biomedical data. A positive result would demonstrate information-to-data utility on the admitted uses. It would not establish a novel statistical identity, universal transport, restored individual measurements, or algorithmic superiority from an information contrast alone.

Use a new evidence commitment for each arm. **E0/E1 are not initial/final revision stages.** Within each arm, source-only feedback may lead to retention or one revision while its evidence stays unchanged. Do not weaken the existing evidence-equality guard or alter the frozen Wave A controller.

Agent scientific choices remain real: it chooses dependence, distributional structure, parameters and unresolved assumptions from permitted inputs. The coordinator may validate units, interfaces and evidence use, but cannot insert desired target slopes, signs, means or residual SDs. Existing code can execute OLS, correlation and marginal checks; a new framework is not the missing ingredient.

Keep instructions, available tools, feedback opportunities, output requirements and budgets identical between A and B. Common source populations, marginal information and metadata must be in both packets. If E1 also changes these, disclose the compound intervention rather than attributing the result only to conditional evidence.

The evidence difference also governs source diagnostics and review: A receives no E1-derived residual, score, desired sign, model-selection advice or rejection reason. A correctness reviewer may check arithmetic against A's declared model, but may not silently judge A using B's private scientific evidence. Packet, feedback and review channels must all preserve this boundary.

Acquisition occurs before packet freeze. Reviewed extracts prevent E1 facts leaking through complete originals supplied to E0. Construction-time private retrieval is disabled equally for this controlled comparison only; this is not a blanket restriction on the user-facing method. Record actual upstream search-to-source-to-claim review if performed. The contrast does not itself establish an autonomous-retrieval advantage, and procedural withholding cannot establish absence of model pretraining knowledge.

## Three scientific uses, fixed before any target effect access

1. **Evidence-addressed conditional association.** An adjusted continuous association for which E1 supplies a correctly oriented source projection, units and adjustment set.
2. **Distinct joint analytical reuse.** A second scientifically motivated projection from the same rows, such as a different adjusted association or residual dependence. Require relevant E1 information; label whether each quantity is directly reported, algebraically implied, partially constrained or assumption-dependent. Merely withholding an analysis label does not make an implied answer novel.
3. **An additional reuse boundary.** A distribution-sensitive or subgroup use, chosen only if the source and target measurements support its meaning. If tail/joint information is missing, label it assumption-dependent and evaluate it as a limitation rather than quietly declaring it validated. Do not add an OGTT-defined endpoint to a dataset lacking OGTT.

The exact variables, formulas, population, estimands and reference-uncertainty method remain unresolved until source/target admission. No target result will determine this choice. The promising existing glycemia evidence is a lead, not a preselected successful case. If only one meaningful analysis is supported, the planned two-use claim is not admitted; do not pad the endpoint count with redundant re-expressions.

## Proposed execution ceiling, subject to case review

One new case only. No participant-level inputs in the primary whole-cohort setting. Ten Agent constructions (five per A/B arm), plus one prescribed E1 statistical reference. Each complete final table has 5,000 rows, sampled at fixed target seeds 2101, 2102 and 2103. This gives **33 final target slots**, not 33 clinical validations.

Use the existing whole-stage bridge, whose execution plan includes both source and target contexts. Each Agent has an initial frozen model and at most one source-feedback revision; each executed stage includes up to three source contexts at source seed 1101 and three target seeds. The statistical reference has exactly one stage with no extra simulated calibration/revision draws. At three source contexts, the ceiling is therefore 10 x 2 x (3 + 3) + 1 x (3 + 3) = **126 physical table attempts: 63 source and 63 target**. Thirty-three final target slots are primary; initial target slots are additional sealed artifacts or aliases. If every Agent retains, the three-context schedule produces 66 unique tables, including 33 targets. Actual contexts, finite schedules and failure accounting must freeze before first execution.

An initial model freezes before its complete stage executes. Initial target outputs, logs, summaries and scientific diagnostics stay outside constructor feedback. Only admitted source diagnostics can influence the one revision/retain decision. All eleven constructions and their output inventories close before the measured reference is disclosed. The final stage is primary; initial-stage comparisons are secondary after global closure. A retain aliases initial source and target identities without regeneration. A failed construction consumes its slot and stays visible; no best-seed selection, fallback to a favorable invalidated initial, or post-disclosure replacement. No open-ended optimizer or hidden extra calibration draws. The execution release must specify a finite technical-repair policy; extra science attempts cannot be disguised as debugging.

Both arms use explicit semantic_feedback_v1. Unknown source weighting remains unavailable in strict feedback. Although raw OLS arithmetic already exists, the current bridge's supplements do **not** supply general execution-bound approximate OLS feedback. If the admitted case needs that diagnostic, add and independently review one narrow interpretation/collector; never relabel unknown weights as known or silently change the source estimator. Otherwise the evidence may inform construction while that diagnostic stays unavailable. Supplemental approximate diagnostics remain distinct from strict source replay.

Only a thin new arm-aware packet manifest, bounded wrapper and case evaluator are needed, plus an explicitly justified case-specific feedback integration if necessary. Reuse immutable candidate contracts, isolated execution and the unchanged whole-stage source/target bridge. This schedule corrects an initial design assumption that the bridge could pause after source-only execution; it cannot. No such unsupported schedule was run. Keep old frozen code and receipts unchanged.

## Evaluation and decisions

The target reference is a finite sample estimate, not known population truth. Determine its sampling/cluster/survey uncertainty from the admitted design. Compare all declared analyses in natural units, with directions and magnitudes; report necessary distribution/dispersion diagnostics. Simulation seed spread, constructor spread, source uncertainty and reference uncertainty remain separate.

For the two evidence-addressed uses, prespecify the E0/E1 contrast in constructor-level absolute discrepancy from the measured-reference estimate (summarize each constructor's three seed results before the arm summary). Display every constructor and seed. Include null/independence anchors so an apparently tolerant success rule cannot count no relationship as a persuasive recovery. Freeze the exact summary and reference-uncertainty sensitivity before disclosure. Five constructors quantify observed procedure variability, not broad inference across all possible Agents.

The candidate positive claim requires improvement on **both** designated uses, with construction spread and reference uncertainty reported. If reasonable reference-uncertainty sensitivity removes the gain, call it sample-specific or inconclusive. Without an independently justified scientific-use tolerance, claim reduced discrepancy rather than clinical equivalence or quantitative replacement. Do not import Wave A's universal 0.10 resolution as a new success criterion.

| Outcome | Method/claim decision |
|---|---|
| E1 improves both addressed uses and the additional use is adequate under an independently justified criterion | Strongest bounded evidence for reusable evidence-guided data; report the admitted scope. |
| E1 improves addressed uses but the additional use fails or lacks a defensible adequacy criterion | Preserve the useful generation method; restrict supported analyses and document the reuse limit. |
| E1 does not improve both addressed uses | Do not claim that missing conditional evidence explained Wave A, or that this mechanism improved biomedical usefulness. Close the result and simplify the contribution. |
| Agent and capable statistical reference perform similarly | Still compatible with a useful biomedical workflow; no Agent-superiority claim. |
| No admissible source/target pair or genuine execution failure | Retain the explicit failure and stop the unit. Do not invent results or enlarge the experiment to obtain a positive picture. |

Freeze the experimental method/version **before** the new reference is disclosed. Finalize the paper's method description and supported claims **after** complete evaluation and independent recomputation, irrespective of sign. If later changes are necessary, they require a new prospective version; this target cannot be repeatedly used to certify successive repairs.
