# Public snapshot and reproduction boundary

This snapshot contains the CHNS F2 study protocol, authored source summaries, Agent-authored generators and model specifications, independent reviews, source-only aggregate feedback, complete aggregate target results, and independent numerical recomputation. The [case report](CASE_RESULTS.md) is the current outcome entry point. Original pending/prospective wording in immutable artifacts is retained as history; subsequent releases and results document completion.

It excludes all patient-level reference data, generated person-level tables, full third-party papers/codebooks, screenshots, execution logs/environments and host-specific constructor validation receipts. Checksums committed in frozen candidate records are preserved even where the corresponding private artifact is omitted. **This public subset is not a self-contained sealed execution bundle.** Do not edit old commitments or fabricate missing receipts to make the lifecycle gates appear to pass.

Included frozen F2 artifacts are copied byte-for-byte, including CRLF where present. Only the two public test files have a documented `work` to `reports` module-location change. The sync manifest records source and export hashes and transformations. The primary numerical report's original `independent_recomputation: pending` field is historical; the separate [independent report](independent_results/REPORT.json) records completion with zero numerical disagreements.

The public code and invented-fixture tests may be inspected independently of participant access. Run test commands from `biomedical_research/virtual_cohort_system` with that directory available on `PYTHONPATH`; required libraries include NumPy, pandas, SciPy, statsmodels, pyreadstat and pytest. Recorded versions and the exact tests actually run are in the implementation notes. This release does not claim a newly rerun full test suite or a packaged environment. The frozen independent script requires the project root on `PYTHONPATH` when invoked by absolute filename; the actual pre-read launch failure and environment-only correction remain documented.

The authored figure and compact summary can be regenerated with `python render_case_results.py` from its F2 directory, using only the included aggregate primary report and Matplotlib. That command does not access participant records or generate new biomedical data.

Twelve executed slots correspond to six unique generated tables because both feedback-stage decisions retained their initial models and repeated the same seeds. The study demonstrates limited directional analytical feasibility in one selected reference sample; it does not establish revision improvement, equivalence, population uncertainty calibration or data-collection replacement. The CHNS target is revealed and closed to tuning. This bounded scheduled continuation has been paused.
