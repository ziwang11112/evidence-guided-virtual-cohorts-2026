# CHNS measurement contract draft

1 November 2026. **Status: units and stored field identities are substantially supported; field-specific missing-code and categorical-format definitions remain incomplete. This is not a frozen cohort or analysis contract.** The parent selects scientific endpoints later from independently audited external evidence. Whole-cohort generation without participant input remains the central information regime; this draft neither selects a biomarker-only objective nor supplies target relationships or generator parameters.

This unit used `pyreadstat.read_sas7bdat(..., metadataonly=True, user_missing=True, disable_datetime_conversion=True)` on the four acquired files and verified that no data rows were returned. It projected only selected stored-format entries from the existing header audit, reused schema-only codebook crops/audits and the official methods/protocol documents, and read official CHNS documentation in a separate requested Chrome tab. No participant values, eligibility filters, counts, moments or effects were computed; previous linkage/count tests were not repeated. No new file was downloaded and no original-study audit was consumed. Browser traffic was unmetered. No state, generator, source operator or F2 freeze was changed.

## 1. What the actual headers establish

Selected clinical/flag fields are ReadStat `double` values, with numeric storage width 8 except master `GENDER` (6). Numeric storage does not make a category continuous or imply that all codes are valid measurements. Current metadata returns no value-label dictionaries, format-to-label maps, missing ranges or user-missing definitions. Existing raw header entries have **empty stored format strings** for the selected fields. No SAS format catalog or `.sas` format-definition file was located in this unit's local inventory.

Therefore codebook names such as `AGE`, `SEX`, `CLN`, `YESNONO` and `YESNOUNK` identify historical formats but are not available executable decoding maps in the current files. Empty metadata containers do **not** prove that no sentinel-coded missing values exist. They also do not establish field completeness, special-missing frequencies or the reasons for missingness.

The current SAS names take precedence over historical aliases. In particular, survey age is `age`, the biomarker is `HbA1c`, field glucose is `Glu_field`, and the absent `AGE_DAYS` must not be reconstructed silently. Keep an explicit case-sensitive source-name mapping even if the task later adopts canonical names.

## 3. Official missingness and cleaning guidance: general, not field-specific

The official [Missing Values](https://chns.cpc.unc.edu/data/documentation/missing/) page says missingness can use repeated-8/repeated-9 negative codes and, for some variables, large positive codes; it also warns that questionnaires do not document all missingness. This is evidence that sentinel ambiguity is real. It is **not** a field-level mask for 88, 99, 888, 999 or their negative counterparts. Such numbers can be legitimate measurements in some fields, so no universal replacement list is approved.

The already inspected survey codebook marks **`.` as Missing for AGE**. A reader-recognized native missing value should remain missing, with any exposed special-missing reason preserved separately. This does not authorize treating particular numeric values as missing in other columns. If a decoder collapses distinct native missing classes, preserve that limitation rather than claim their reasons were recovered.

The official [Data Cleaning](https://chns.cpc.unc.edu/data/documentation/cleaning/) page describes ID/roster corrections, duplicate/blank-record removal and recoding clearly impossible values to missing. Other extreme values remain for researchers to assess. It neither supplies a `CLN` lookup nor certifies every remaining value as valid. The [Notes](https://chns.cpc.unc.edu/data/documentation/notes/) page adds no `CLN`, `YESNONO` or `YESNOUNK` map. A focused formats search did not yield a verified additional definition; absence from these reviewed pages is not proof that no authoritative catalog exists elsewhere.

**Draft handling guardrails, not an eligibility rule:** retain released height/weight and their cleaning flags; do not repeat historical corrections, winsorize from observed percentiles, or discard every positive cleaning flag. `CLN_HT`/`CLN_WT` labels indicate cleaning when greater than zero, which is not synonymous with invalidity. The exact numeric categories and reasons remain unresolved. A missing flag is not proof of an uncleaned or acceptable record. Before a rule depends on a specific flag category or missing sentinel, obtain its release-compatible definition and independently review the rule. Clinical reference intervals and assay linearity limits are not missing-value definitions.

## 4. Identifier, timing and information boundaries

Official [ID Variables](https://chns.cpc.unc.edu/data/documentation/idvar/) documentation describes a revised numeric person identifier retained across survey years and datasets, with older IDs replaced, and a four-digit `WAVE`. This supports the already specified person-wave linkage concept; it does not replace the completed file-specific key audit or establish clinical completeness. Preserve identifiers; do not reconstruct them from household/line components or alter their values while normalizing column names.

The official [Date Variables](https://chns.cpc.unc.edu/data/documentation/datevar/) page describes older-wave date encodings and does not resolve the current 2009 age reference/rounding or blood-collection date. The protocol separately gives varying fasting intervals, afternoon collection and handling/storage ambiguities. No fasting-compliance field is established in the acquired biomarker schema. Intended fasting procedures cannot be promoted to verified individual compliance or a uniformly fasting analytical population.

The [exposure map](../EXPOSURE_MAP.md), companion crop-failure disclosure and biomarker disclosure remain applicable. This new metadata step adds no participant-value exposure; it does not reset prior exposure. Target marginals must not enter a constructor packet as “population metadata,” and official reference ranges must not become generator targets. Any later source operator must independently bind its variables/roles, population, selection, unit/scale, adjustment, weighting and uncertainty. The semantic identity gate does not perform unit conversion, certify measurement transport or recover an unknown estimator definition.

## 5. Conditions for advancement

The parent can now select candidate questions from external evidence with correctly named fields and supported units. Before F2 or any clinical-value eligibility check, resolve field-specific missing/response semantics for each required variable; otherwise mark the dependent criterion/analysis unavailable, simplify it transparently if scientifically defensible, or stop that proposed use. Optional medication/pregnancy fields create no automatic universal exclusion requirement. Obtain a current authoritative format dictionary or exact questionnaire/coding rule where needed, rather than discover a convenient rule by examining target values.

No target mean, slope, correlation, event rate, effect direction, complete-case count, clinical filtering threshold or imputation parameter is supplied by this draft. No new download payload was incurred; only unmetered official-page browser traffic was added. All original files and prior frozen artifacts remain unchanged.
