What these data can support

The clearest supported use is the positive urban BMI group comparison. Matching sample size and group composition also makes some urban lipid discrepancies comparable in scale to real–real sampling variation. Rural lipid relations and lipid dispersion still need improvement.

The data need not be identical to be useful. Here, usefulness is specific to an analysis: approximate group effects do not establish accurate individual variability, power estimates or weak-effect directions.

How to read the comparison

Each row compares an age/sex-adjusted group contrast with an independently resampled real reference. The gray band shows the differences between two real resamples. Blue and purple rows show all three saved tables from each Agent author.

A small difference is encouraging for that analysis. The gray band provides empirical sampling context; it is not an equivalence margin, independent cohort validation or an estimate of all scientific uncertainty.

Variability must also be checked

A table can reproduce an adjusted contrast while underrepresenting individual variability. Standard deviations are therefore shown separately, in the original measurement units.

What is held constant

Real available-case sizes are BMI 1,189; total cholesterol 400; HDL 405. Each virtual resample uses exactly the corresponding six lifestyle-by-sex cell counts. Age and biomarker outcomes are not forced to match. The original six virtual tables each have 1,226 rows.

Resamples come from the same empirical pools. Household/site clustering is unavailable in the bound adapter. This is a source-rich reconstruction with an already exposed reference, not a prospective population-transfer test.
