# Focused domain review: acceptable differences for an intended use

No expert answers have been collected in this unit. This blank form supports a future review; it does not block documenting the existing observed results.

1. **Intended use:** What would a researcher use this dataset to do? Specify the population and exact analysis (contrast, adjustment variables, units and any decision).
2. **Consequential difference:** What difference in that analysis's result would change the scientific interpretation or decision? State a raw-unit interval or margin, its rationale and any independent source. “Not yet defensible” is a valid answer. Please do not derive it from the largest observed discrepancy.
3. **Essential accompanying information:** Does this use also require reliable residual spread, subgroup effects, joint tail probability, measurement uncertainty or another specific feature?
4. **Evidence boundary:** Is the current result suitable for analytical exploration, approximate quantitative reuse, or neither? Which single additional check would change that judgment?

Record the review date, reviewer role and which results were visible. Judgments made after seeing these results are developmental and should not be presented as prespecified margins. BMI-group pattern, paired-BP dependence and exact lipid magnitudes may legitimately receive different answers.
