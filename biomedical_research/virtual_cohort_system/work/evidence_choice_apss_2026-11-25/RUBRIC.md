# Blinded source-use adjudication for the APSS experiment

This file is evaluator-only. Freeze the rubric before authoring. It scores whether the delivered program used the published **joint** Stage 3 BMI evidence, irrespective of whether the eventual measured underreporting rate agrees with its prediction.

## Materials and independence

A coordinator assigns eight random reviewer IDs and withholds their mapping to policy, block and session. Give two reviewers the same read-only sources, emitted code, model configuration and decision record in randomized order. Omit prompts, arm labels, conversation traces, target workbook, target results, comparator scores and simulation summaries that contain the held-out endpoint. If an author volunteers the policy name or a template discloses it, redact that identifier when possible without altering scientific content; record suspected unblinding. Each reviewer independently freezes a rating with exact code and record locators before seeing the other's rating. Use one row even if no program was delivered. Resolve differences before clinical disclosure, retaining both original ratings, resolution, rationale, and simple raw agreement over the eight assigned sessions. If unresolved, mark disputed and report conservative and permissive counts.

## Code each field separately

| Field | Decision rule |
|---|---|
| Available | A complete runnable artifact was delivered under the registered schema. Report omitted or failed deliveries with reasons. |
| Correct source identification | The author identifies the Stage 3 comparison of online self-reported and objectively measured BMI in the same adults, ≥30 kg/m². Stage 2 compares two self-reports. A generic citation to the paper or the word “kappa” alone is insufficient. |
| Extracted binary joint information | A correct statement of n = 91, the 8/91 vs 12/91 margins and κ ≈ 0.776 (or equivalent joint proportions/counts) with orientation made clear. The case-specific joint vector is (8,0,4,79) ordered both positive, online-only, objective-only, neither. Correct rounding of a derived value is sufficient; exact counts need not be printed by the author if the code uses an equivalent relationship. Record any partial extraction, role swap, use of Stage 2 or unsupported numerator separately. |
| Consequential joint use | Trace an actual parameter, joint distribution, weights, sample allocation, fitting objective, coupling or acceptance/rejection decision to the above relationship. Full credit includes matching the four cell proportions, using margins and kappa in calibration, matching marginal positive rates plus overlap or conditional rates that imply the same table, or an equivalent joint constraint in a rationale-linked fitting step. A numerical penalty or model choice must depend on this joint statistic. A constant can qualify if provenance and use are traceable. An attempt can be consequential even if independently recomputed fit is poor. |
| Continuous paired evidence | Record separately the use of Stage 3 ICC 0.962/RMS 1.3, calculation choice and interpretation. Distinguish exact statistic, assumption-dependent proxy, simple citation or omission. Continuous evidence alone earns this field and does not demonstrate uptake of the binary table. |
| Recomputed compatibility | From generated BMI columns, use ≥30 in both roles and recompute the four cell proportions and kappa per registered seed; record numerical discrepancies against proportions (8,0,4,79)/91. For differently sized tables compare proportions, not the original raw counts. Define an undefined kappa as unavailable. Keep numerical fit separate from consequential evidence use. Any categorical cutoff for numerical fit must be set in the scoring protocol before author dispatch. |
| Qualifying explanation | Record a stated reason for using, softening or declining the joint evidence; distinguish an explained exclusion from silent omission. No credit for correct application merely because text says “checked”. |
| Intended analysis | Confirm online minus objective BMI, strict boundary below −2, common complete-pair denominator, and legitimate finite outputs. This field records software validity, not an outcome-based test of calibration. |

**Primary implementation classification:** count a session as having used the binary joint evidence only if the correct numeric relationship is traceable and it consequentially enters the submitted executable generator or its reproducible calibration/selection routine. Record separate flags for correct extraction and successful execution. For the delivered-use endpoint, require both consequential use and a valid delivered generator. Freeze beforehand which of these columns is the primary endpoint. Missing or unusable artifacts remain in the assigned denominator; report their extraction/implementation status as unavailable when the corresponding record cannot be examined.

### Edge cases

- Citing the correct table, marking it as held out for checking, printing a check after generation, or supplying it in an unused constant is documented recognition with no evidence that its joint information determined the rows. A post-generation check counts as consequential only if it provably changes acceptance or selection of the delivered artifact.
- A generic Gaussian copula that happens to reproduce κ to three decimals does not show uptake. The score for numerical fit can be high despite an absent implementation trail. Conversely, an explicit optimizer using the source table can miss its target and still demonstrate attempted uptake.
- Fitting only the two positive marginal rates permits many cross-tabulations. Treat it as marginal use. State which side each indicator refers to, since a transposed cell vector can preserve overall agreement and κ.
- Enforcing a source probability of zero in a simulated online-only cell is an admissible reconstruction assumption. It is an observed zero in this sample; the study does not establish a population structural zero. A model that appropriately softens this relationship under sampling uncertainty can score consequential use if the data-dependent constraint and rationale are explicit.
- ICC/RMS-based models and other source relationships may be scientifically reasonable. Report which other program features differ between policies. An arm difference in the withheld continuous endpoint is an effect of the policy as a whole; this two-arm test cannot identify a causal benefit of one chosen statistic by itself.

## Suggested blind coding row

Reviewer artifact ID; availability; source identification; binary extraction; cell orientation; consequential use; continuous paired evidence and assumptions; source-fit results per seed; reasons for omitting a statistic; code and evidence locators; reasons for any ambiguous rating. Keep arm, target endpoint and target discrepancy off the coding sheet until both independent ratings and their resolution are frozen.
