## Editorial decisions

1. Keep the virtual-data use central. The evidence-indirectness interpretation remains a limitation and explanatory mechanism, not a replacement failure-benchmark narrative.
2. Main pressure result is the new three-arm comparison (78.6%), not the older exploratory two-arm result (92.89%). Preserve the latter with all endpoints in Figure S1/Table S5.
3. A second case is present, but it is an exposed developmental reference, not a new prospective population. Avoid "independent confirmation".
4. OR discrepancy is measured on the natural-log scale. Report its remaining numerical gap; improvement does not mean matching the measured OR.
5. Whole-cohort generation remains explicit. Column enrichment and partial completion are related information regimes, not automatically validated by these whole-cohort experiments.
6. No composite score, significance threshold, clinical equivalence margin, seed-based sample inflation or selective endpoint deletion was introduced.

## Focused remaining evidence

The core method can now be written consistently. Further work should change a specific claim:

- Domain review: choose one useful analysis and an independently defensible tolerance; do not infer tolerance from these favorable estimates or reference confidence intervals.
- Replication: use the same masks, endpoints and budgets with a second model family if claiming model-general composition capability.
- External validation: one genuinely unused evaluation boundary under a frozen protocol if claiming target transport. An extra indicator in a historically exposed dataset is not automatically a new family-level confirmation.
- Comparative quality: reproduce a close method only on a compatible task/input regime. This edition does not claim that comparison has been completed.

Do not add generic agent count, training or revision components simply to increase novelty. The current tests show that the information provided to the joint model has a specific analytical effect; the remaining limitation is which other uses that model can support.
