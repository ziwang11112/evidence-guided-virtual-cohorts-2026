# Matched replication across additional original publications

The unit of replication is a published source, with 12 matched author blocks per article. The two preceding publications used the same GPT and ordinary-versus-targeted authoring comparison. This implementation carries that scientific contrast across other types of downstream analysis. Each case supplies its own measurement units, independent checks, two estimands, planning margins and original article. Each case is registered publicly before dispatch. Reusing an already studied source applies a new comparison to that source. It does not add a new patient population.

Twelve fresh initial sessions read the full original scientific text and the same research question for that paper. Each submits model parameters, its evidence extraction, executable Python and a scientific decision record. It chooses which measurements belong to the same person within fixed source strata. The runner constructs common marginal columns from the author's extracted inputs. The ordinary follow-up asks for a second defensible model. The targeted follow-up also asks for a different within-person assignment that changes the requested scientific analysis by a meaningful amount without a specified direction or target value. The two follow-ups share exactly the same initial artifact and budget. They never receive the other branch, another block, a supplied solution, clinical microdata, target estimates or performance feedback. Order is shuffled with a registered seed. Every qualified or unqualified result is reported.

Both conditions use the same GPT-6.1 Sol, medium reasoning, default tier, 12,000 maximum output tokens, single attempt, no API retries. There are at most 36 calls and a hard USD 18 cap per article. The maximum byte allowance for a request is 170,000. A conservative worst-case reservation must pass before registration. The account allowance is distinct from this project ceiling. Paid authoring ends and a hash-anchored receipt is written before numerical scoring. Both branches are unissued if the initial cannot be parsed. That block stays in both denominators. Source-incompatible or non-executing artifacts are not replaced. All returned programs run offline in WSL/bubblewrap at three common, registered seeds. An input may specify deterministic assignments. The same evaluator computes both analyses on the same virtual rows.

A program is eligible only with correct extraction, complete within-stratum permutations and all registered source/physiology checks in every draw. A pair is material when both programs qualify, their fixed companion estimand agrees to 1e-7, and the absolute pooled difference in the requested analysis and its minimum shift in the same direction over the three matched seeds strictly exceed the case's margins. Count all 12 assigned blocks in each arm. Report usable programs and pairs, signed differences, matched discordances and the conditional two-sided exact test. Scientific evidence is counted by paper and block. Three seeds and repeated synthetic measurements do not increase the number of tested populations. A second implementation reads the saved rows and source columns to check estimates, eligibility, matched prompts and bills.

At least eight blocks valid in both arms, more material pairs in the targeted arm, and independent recomputation qualify the procedure to enter the next candidate publication. If the gate fails, record the specific reason and stop the remaining paid expansion under this plan. A may-differ result establishes an attainable counterexample under the chosen constraints; accuracy, biological plausibility outside those constraints, and sharp mathematical bounds require other evidence. Full papers, row-level data, raw model transactions and credentials remain local. Public records contain scientific code, original documentation, model decisions, hashes and aggregate results.
