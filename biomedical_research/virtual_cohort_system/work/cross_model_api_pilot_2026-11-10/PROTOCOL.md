# Twenty-construction API pilot

Authorized by the user's 10 November 2026 instruction to connect D:/.env, execute the first twenty constructions and assess scientific analyses. This instruction extends the earlier schema-only planning draft: scientific evaluation is now included, after every construction is closed. Historical targets are exposed at project level, so these are controlled developmental comparisons, not new prospective clinical confirmations.

## Task and comparison

Two unchanged scientific requests, PNS blood pressure and Turkana-context lipids, are each given to five configurations in two fresh independent requests. Four configurations form a provider-balanced comparison: GPT-6 Astra, DeepSeek V4 Pro, Claude Fable 5.2 and Gemini 4 Carbon. GPT-6.1 Sol is the additional within-OpenAI capability/cost comparison. Different requests are construction replicates, not independent model training or patient cohorts. There is no pure provider-effect identification with one model per provider.

Each case has one identical reviewed prompt containing population, columns, requested analyses and fixed published evidence. All models choose their own scientific model, dependencies, covariate distributions and numerical assumptions. No previous generator, target measurement or empirical target estimate enters a request. No web retrieval or external tool is exposed in this controlled comparison; that condition does not restrict the general method. Agent decisions and program are the outputs; statistical tools sample the resulting law. No human edits to scientific parameters are permitted.

## API choices and recording

Authenticated model-catalog GET requests succeeded for all four providers. This confirms key authentication and advertised model availability, not generation quota or account balance. Requested IDs: gpt-6-astra, gpt-6.1-sol, deepseek-v4-pro, claude-fable-5-2, gemini-4-carbon. API-returned model identity/version, request ID, UTC times, full secret-free request body, exact submitted text, response body, extracted text, returned artifact, completion/stop state and usage are saved per call. Unavailable snapshot metadata remains unavailable. Native reasoning effort is high/HIGH; labels do not equate computational work. Temperature is not set. The output budget is 32,768 tokens per request. Provider input limits/settings are captured in RUN_PLAN and catalogs.

Credentials are loaded locally from the supplied file, never copied into prompts, execution environments or public artifacts. Model programs are parsed but never imported on the host. The existing WSL/bubblewrap worker is the sole execution backend, without network, workspace or credential mounts. The authoring API receives no filesystem tool. Full raw API responses, generated rows and host references remain local pending any later selective export review.

One initial call per slot; at most one static formatting/Python ABI repair for an otherwise completed malformed response. Repairs carry the same packet, the original response and only the mechanical diagnostic. They may not use generated scientific metrics, reference discrepancies or desired parameter values. All twenty initial opportunities precede repair spending. Initial and repaired artifacts are retained. Transport/API failures are not silently resent or replaced; interrupted durable reservations prevent duplicate requests on resume. Syntax validity alone does not establish mathematical or scientific adequacy.

## Spending and accounting

Provider ceilings for this bounded authorized run: OpenAI USD20, Anthropic USD15, Gemini USD10, DeepSeek USD5; USD50 maximum planned allocation across providers, not a requirement to spend it. No subscription purchase, top-up or automatic recharge. Each request reserves a conservative input-byte/output-token allowance before sending. Unknown usage or interrupted calls retain the reservation rather than being counted as free. Preflight catalog GETs are not generation calls. The reported monthly OpenAI allowance is USD200, but its remaining balance has not been independently inspected.

Costs are computed from provider-reported usage and the verified 10 November standard text tariffs. They are tariff estimates, not billing-invoice measurements. OpenAI implicit cache writes and reads, Anthropic cache tokens and output/reasoning, and Gemini candidate plus thought tokens are accounted separately as required. DeepSeek uses peak pricing as an explicitly conservative tariff; actual off-peak billing can be lower. No external search/tool charges are incurred by these fixed text-only requests. All rates/settings are in the immutable run plan. Counterbalancing and concurrent execution do not make tokens or compute identical across providers.

## Frozen scientific evaluation

Exactly three seeds (31001, 31003, 31007), 3,000 rows per valid frozen model: at most60 final tables. Failed constructions stay in the20-slot denominator. Models and evaluation code are sealed before worker execution and reference comparison. No failed run is scientifically rewritten or regenerated after viewing analysis results. Requested slopes and adjusted residual dependence, descriptive marginal dispersion and component checks follow EVALUATION_PROTOCOL. All endpoints and seeds are reported; no success cutoff is tuned against these references. Reference estimates have their original sampling limitations and do not represent known population truths.

The first-stage questions are feasibility, traceable evidence/assumption choices, consistency across authors and configurations, and the scientific analyses supported by generated records. A nominal direction match or source-statistic match is insufficient by itself for clinical validity. Structural/parameter convergence is descriptive; different statistical operators are never pooled as one parameter. Repeated seeds describe Monte Carlo variability under one selected law.
