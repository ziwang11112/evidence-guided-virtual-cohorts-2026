What happened in this run

Urban–pastoralist BMI has a similar positive scale. The real reference contrast is 1.882 kg/m²; the six final draws give 1.700 to 2.251 kg/m². This is a descriptive comparison, not an equivalence claim.

Standardized cholesterol agreement hides a raw-scale difference. The urban–pastoralist total-cholesterol contrast is 0.4751 SD in the reference; the means over three seeds are A1 0.4512; A2 0.4955 SD. In raw units, the reference is 20.342 mg/dL, compared with 13.732 to 18.907 mg/dL across the virtual draws.

The rural lipid contrasts are not closely reproduced as point estimates. Total cholesterol: reference 9.493, virtual -0.695 to 1.943 mg/dL; HDL cholesterol: reference 4.446, virtual -1.833 to 0.015 mg/dL. Both reference 95% intervals include zero, so this is a mismatch with uncertain sample estimates, not a claim of established positive population effects.

Virtual lipid variability is smaller. Sample SDs are Total cholesterol: reference 42.811, virtual 31.847 to 34.063 mg/dL; HDL cholesterol: reference 20.228, virtual 14.395 to 15.103 mg/dL. The raw-unit view is therefore essential alongside the standardized view.

The analysis branch can differ. The sex-interaction rule selects sex-specific analysis for A1_s64001 HDL cholesterol (p=0.02457; reference p=0.66618). The affected stratified estimates are retained below; a branch change in one draw does not establish a stable biological interaction.

These results show partial application fidelity under source-rich reconstruction. The positive and discordant patterns are both retained. The published lifestyle findings were allowed inputs, so their reproduction is not independent discovery.

How to read this

Each row is the first named lifestyle minus the second, adjusted for age and sex. Right of zero means a higher biomarker; left means a lower biomarker. Compare direction, effect size, and variation across the two constructions. The raw-unit view prevents standardization from concealing differences in biomarker variability.

What this comparison supports

Agreement indicates that generated data can reproduce this specified analysis under this evidence setting. It does not show exact participant recovery, universal validity, or superiority over another generation method. CI overlap alone is not an equivalence test, and disagreement need not imply that the reference sample is the population truth.

The original paper is allowed construction evidence. Results already described there are reconstruction checks, not unseen discoveries. This application covers three biomarkers and does not reproduce the paper’s full trait family, U.S. comparisons, mediation analyses, or early-life analyses.
