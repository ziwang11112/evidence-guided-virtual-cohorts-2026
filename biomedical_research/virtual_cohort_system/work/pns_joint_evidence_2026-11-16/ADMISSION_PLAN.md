# PNS joint-evidence follow-up: source admission before generation

Selected 2026-11-16 before this unit's literature searches or new target comparisons.

## Case and purpose

Reuse the PNS 2013 blood-pressure analysis context, schema and unchanged three primary estimators. The choice follows the existing scientific gap: external evidence supplies some BMI effects and marginal blood-pressure moments, but not the paired SBP/DBP dependence after identical age/sex/BMI adjustment. The case has a fixed evaluator, an already exposed aggregate reference, and an interpretable distinction between marginal, component and conditional dependence. This is a developmental follow-up, not a new independent clinical validation.

The target remains the original laboratory-weighted complete-case analytical distribution, adults 20–79, not unqualified national representativeness. No new target rows, target mean, slope, correlation or preferred sign are given to the research or construction Agent. The root already has historical exposure and must not use it to pick favorable sources or tune parameters.

## First phase: an actual evidence-search Agent

Use an isolated fresh GPT API context with existing logged Europe PMC search/full-text tools. Supply the original task and existing external evidence packet as context for identifying the missing relation. The Agent chooses search queries and candidate papers, identifies statistical definitions and relevant tables, and produces a structured admission proposal. It does not generate or calibrate data in this phase. No required fixed paper count; stop when useful evidence has been characterized or the bounded search opportunity is exhausted.

One episode, up to 48 calls, 60 tool actions, 20 provider search queries and 16 full-text downloads; $4 tariff-accounted ceiling. Read-only source retrieval only; no account creation, controlled data, patient-level downloads or paid retrieval services. Existing approved GPT/key configuration, current documented tariff, no automatic API retries. Full calls, outputs, tools, usage and costs remain local. A normal inability to find a source is a valid result.

Source preferences are direct adjusted residual covariance/correlation; same-sample joint covariance or correlation matrices with the required covariates; compatible multivariate-regression residual information; or a clearly partial joint constraint. Search for clinical population/measurement compatibility, not numerical closeness to PNS. Exclude PNS-derived evidence and this project's artifacts. Do not conflate raw/Spearman/within-person correlations with the requested Pearson OLS residual correlation. No arithmetic combining unrelated studies can manufacture a same-population covariance without transport assumptions.

Each proposed item must retain population, sample size, measurement/aggregation, transformations and units, adjustment set, statistic and uncertainty, exact article/table locator, cohort overlap status, which analysis it constrains and which assumptions remain. Root checks original admissible source text against the proposal before any source is frozen. An abstract citation alone does not certify a table value. Negative and inapplicable findings remain in the record.

## Second phase, contingent on source admission

If there is usable new relationship evidence, freeze one modest comparison: three fresh constructors with the original external packet and three with original plus the audited Agent-found evidence, same GPT, task, interface and budget. This isolates the evidence increment; it is not an ordinary-Agent-versus-workflow contest. Both arms may choose their own laws, parameters and explicit assumptions. No host-written scientific coefficients, no desired target answer, no target feedback. Same selected laws then produce three prespecified random draws each using the existing WSL/bubblewrap sandbox. All constructors close before final generation and clinical comparison. Keep all three predefined analyses, scales, physical diagnostics and failures, not only the joint endpoint.

The generation protocol will bind exact admitted source objects, runtime, inputs, model, seeds, budget, source checks and estimator/reference files before any author call. Root may correct extraction or interface errors before freezing, but not scientific parameters after seeing target results. If evidence is only partial, label its influence accordingly rather than claim identification.

If no defensible usable constraint is admitted, close source admission with the evidence gap. Do not create another positive-looking generator by replacing an unsupported correlation with a number chosen from the known target. No new dataset family or large model grid is launched automatically.
