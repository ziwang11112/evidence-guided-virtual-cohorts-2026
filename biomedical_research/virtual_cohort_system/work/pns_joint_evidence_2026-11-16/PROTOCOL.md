# PNS: Agent-discovered joint evidence, fixed scientific analyses

## Question and design

Can additional, honestly qualified joint/conditional evidence found by an actual research Agent help new virtual-cohort constructors support the same requested scientific analyses? One existing exposed PNS case; three independent fresh GPT constructions per evidence arm. The source-selection decision is recorded in SOURCE_AUDIT.md. No claim of workflow superiority, new-target validation or a fully identified target distribution is intended.

Arm ORIGINAL receives the unchanged historical external evidence packet. Arm AUGMENTED receives that packet plus the two audited Agent-found records and their applicability limitations. All other instructions, GPT model/configuration, interface and generation budget are identical. Construction order is shuffled once with a fixed schedule seed. Every construction is a new API context. Authors are stochastic constructions from one model, not six independent scientific experts.

The Agent selects structure, all scientific parameters, which evidence to use and transfer assumptions. It can decline a source or use it as a scenario. The host does not replace parameters, prescribe target relationship signs or numerically fit the target. This unit isolates the source increment after a common search phase; it is not a fully autonomous retrieval comparison per author. There are no revision/repair calls or generator selection after results.

## Fixed outputs and endpoint priority

Each constructor writes a program returning 3,000 equally weighted independent virtual people, columns row_id, age, female, bmi, sbp, dbp. Whole-cohort generation requires no individual target inputs. Age 20–79 and sex coding follow the existing task. Exactly three final draws use seeds 16121, 16123 and 16127. All six constructors must close before final draws; all draws must close before target comparison. Maximum 18 final tables. Failed artifacts and runs retain their slots.

The unchanged analysis design is [1,(age-50)/10,female,(bmi-25)/5]. Main question is the Pearson correlation of paired SBP/DBP residuals. Co-report both BMI coefficients in mmHg per 5 kg/m², so dependence improvement cannot hide association damage. Secondary diagnostics are both population-convention SDs, SBP below DBP, nonpositive measurements, marginal distributions, matrix rank and duplicate rows. Do not discard rows or tune the analysis. Three seeds are nested Monte Carlo repetitions, not nine independent authors per arm.

The primary contrast is arm-average absolute reference difference for residual correlation, averaging seeds within construction first, and retaining each construction's results. Report the corresponding contrasts for both slopes and SDs separately in their own units. With three constructions per arm this is descriptive; no clinical-equivalence threshold, p-value claim or general superiority claim. A percentage change is only a descriptive change in distance to this particular exposed reference.

## Source consistency versus target utility

The Burkina Faso Schur complement is checked against its own published same-sample matrix before freeze. Ghana's multilevel components are kept separate. Neither source operator can be replayed by calculating an age/sex/BMI statistic on target-population synthetic rows. No target-output statistic will be mislabeled a passed source-population constraint. After closure inspect each Agent's declared use, code and unresolved assumptions; retain missing source replay as such. Finite sample output alone does not prove finite population moments; inspect each selected law separately.

## Isolation, comparison and uncertainty

Use the existing WSL/bubblewrap execution runtime and reviewed worker, no host import or network for model code, no local fallback. Only generator, specification, task and worker are mounted; no reference/data/source corpus. Final primary values come from the unchanged PNS analysis adapter; independently recompute all six endpoints using the existing QR implementation and compare at absolute tolerance 1e-9 plus relative 1e-10. Validate read-only bindings and runtime fingerprints.

The existing aggregate reference is hashed before construction but parsed only after output closure. PNS is the peso_lab-weighted complete-case laboratory-substudy analytical distribution, not an asserted national population truth. Its existing row-resampling intervals are not survey-design confidence intervals and are not pass/fail boundaries. No new target fits. Source, target and model uncertainty are different; additional rows reduce simulation noise, not evidence uncertainty.
