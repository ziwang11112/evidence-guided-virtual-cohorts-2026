# Two independent applications of a common non-HDL generator

One research use is to estimate how many measured adults cross a laboratory cutoff for study planning. An East African municipal source supplies weighted serum lipid summaries. The two independent reference samples are community residents in Mekelle and employees at Haramaya University, Ethiopia, with different sampling frames and laboratories. The first is closer to the municipal source in recruitment. Both are external to that source. The same frozen pair generator and virtual tables serve both; the estimands refer to eligible measured participants in each sample.

**Inputs.** Kavishe et al., [original Tables 2–3](https://doi.org/10.1371/journal.pone.0223189), first municipal stratum (Mwanza, Tanzania). The source reports nonfasting TC, HDL, non-HDL means, the mean of individual TC/HDL ratios, individual-marker cutoff frequencies and design-based intervals. No source microdata or external target distributions enter either arm. Both arms receive the same selected rows, measurement description, scientific request and fixed marginal order statistics. No participant information, target-specific search or target tuning. The targeted ablation is discretion over pairing given common marginal assumptions; this experiment does not measure autonomous evidence retrieval. The prior project examined this source. The two target studies were selected by prespecified recruitment/availability criteria, project exposure search and schema/units only.

**Design.** Use separate lognormal margins with reported means and single-marker cutoff frequencies. Select the smaller strictly positive log SD when two roots exist; this choice concerns marginal shape and can affect the primary use. Deterministic midpoint quantiles rescaled to the respective means are shared by both arms and seeds. The statistical arm uses a Gaussian rank copula calibrated to the reported paired TC/HDL mean. With marginal means mT,mH and log SDs sT,sH, E(T/H)=(mT/mH) exp(sH²−r sT sH). The Agent receives neither this construction nor its fitted coefficient. One new cost-controlled GPT author writes a permutation program in a clean API context. The evaluator runs it with the project's no-network WSL/bubblewrap adapter. All scientific choices specific to the Agent originate in its response. Budget: one GPT-6.1 Sol call, USD 0.45 conservative tariff cap, 12,000 output tokens, no revisions. Both arms have 16,000 pairs at each of three seeds (40711, 40727, 40739). The three-seed pooled answer is primary, with each seed retained. One law per arm, two reference cohorts.

**Scientific analysis.** Secondary arithmetic control is the unweighted mean of TC−HDL in mg/dL on common complete pairs. Primary scientific result is the percentage with TC−HDL ≥160 mg/dL; equality counts. This is a measured laboratory category including treated and untreated participants, not a disease- or treatment-prevalence estimate. The cutoff has precedent in a [population lipid study](https://stacks.cdc.gov/view/cdc/34088/cdc_34088_DS1.pdf); that paper also used medication information for a different diagnostic definition. Compare each frozen estimate to each reference in its native units. For illustration of a resource-planning use allowing 20 counts per 1,000, specify a ±2 percentage-point tolerance before disclosure. This is a project planning assumption, not a clinical equivalence margin. For each fixed synthetic percentage report signed/absolute difference and interval obtained by subtracting the reference percentile bounds in reverse order. Classify as within only if the full difference interval is inside ±2; outside if disjoint; otherwise unresolved. No winner-selection, powered superiority or replacement of unfavorable sites. Report mean differences without a pass/fail margin. Retain a diagnostic envelope over all pairings consistent with the fixed empirical margins, before imposing source ratio/physiology. It bounds the influence of pairing conditional on these source margins.

**Reference.** Adults ≥20, all treatment statuses, finite positive TC and HDL, one eligible row per ID. Exclude all rows with a missing or repeated ID. No unwritten trimming or removal when HDL exceeds TC. Report those counts for all arms. Both articles sampled independent people; one person per household in Mekelle, payroll recruitment in Haramaya. No nationally representative claim. For both sites independently use 2,000 subject resamples with replacement within the recorded age groups 20–39 and ≥40; seed 404203 for Mekelle and 404207 for Haramaya. This conditions on observed age composition, cases and frozen laws, and omits source uncertainty and unavailable subcity/department sampling details. Site differences in sampling, fasting (fasting at both sites; source nonfasting) and assay can affect transport.

**Sequence.** Bind source, input prompt, task, code, private input identities, reference readers and analysis rules before authoring. Verify eligibility/counts without calculating either target analysis. Record API metadata, program, model, decision, source residuals and physiological checks for all generated draws. An invalid permutation or failed arm is retained as a failure. Seal every output and law before opening both target endpoints together. Do not regenerate after reveal. Publish only original methods/code, bibliographic metadata and group results. Participant-level real and virtual data, original articles and raw API archives stay local.
