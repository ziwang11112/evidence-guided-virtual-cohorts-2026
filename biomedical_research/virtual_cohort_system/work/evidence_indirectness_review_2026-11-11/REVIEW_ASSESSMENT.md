# Assessment of the proposed evidence-indirectness pivot

Date: 2026-11-11. Status: review and design only. No new paid calls, generation, patient-data analysis, target acquisition, manuscript replacement or GitHub publication was performed for this assessment. Existing frozen results remain unchanged.

## Decision

Retain evidence applicability as a focused candidate research question within the virtual-cohort project. Do not yet replace the paper with the proposed universal failure narrative, claim an untouched phenomenon, or launch 384 constructions. The strongest question is narrower:

> When a scientific Agent turns study-qualified statistics into an executable joint generator, does it preserve the distinction between identified quantities, valid transformations and assumption-dependent borrowing, and what consequences follow for the requested analyses?

The biomedical generator remains the experimental platform and practical output. Its value need not be abandoned to investigate this question. A separate application paper is not an automatic fallback; any paper separation would require distinct substantive contributions and transparent overlap.

## What survives the review

- Faithful extraction and executable code do not establish target applicability.
- The existing source-to-parameter traces can reveal where an analysis depends on an unreported bridge.
- Mathematical repair, source consistency and agreement with a real sample are separate achievements.
- Randomized evidence conditions would be more discriminating than retrospective grouping by model or observed error.
- Applicability must be judged before, and independently of, proximity to a target reference.

The strongest retained historical observation is that the 20 delivering initial laws in the two fixed-packet rounds had residual correlations below their respective sample references. It remains a two-context descriptive pattern. Neither all dispersion measures nor every model choice follow one universal shrinkage mechanism.

## What should count as a modeling failure?

Acknowledging a mismatch and then using the evidence is insufficient. A legitimate use can be an exact conversion, weak prior, explicit transport model or disclosed scenario. A point scenario can be scientifically useful without being identified as the true target distribution.

The failure of interest is promoting an indirect quantity into a claimed directly identified target constraint without a valid bridge, or declaring uncertainty that never reaches the generated analyses. These must be distinguished from transparent but inaccurate assumptions and from implementation defects.

Population mismatch and statistical incompatibility should be separate axes. The [GRADE Book on indirectness](https://book.gradepro.org/guideline/indirectness) cautions against automatic downgrading solely because PICO differs; meaningful differences require justification. The proposed population/measurement/statistic/adjustment/scale checklist is a project extension, not GRADE's official five dimensions. Averaging coefficients with different estimands cannot repair their incompatibility.

## Proposed next discriminating unit — not executed

First define a source-to-code annotation ledger on the existing complete roster. Unit: a statistic used for a specified analysis, nested within a constructor. Record the original definition, acknowledged gap, implemented role, valid or missing bridge, and propagated uncertainty. Have source-role judgments made without target errors. Preserve failures and dependent review versions separately.

Then consider a compact controlled pilot: two statistical-operator families, four information conditions and three fresh constructors per cell using one existing economical GPT configuration: **24 initial sessions**. Conditions are common background with no focal relation, directly applicable relation, indirect relation, and both. These deliberately test evidence effects, not an end-to-end workflow comparison. All artificial study records must be labeled simulated and never presented as real publications.

Useful first families are marginal versus adjusted residual correlation, and between-person random-intercept versus single-visit dependence. Freeze valid bridges and hidden laws; include legitimate indirect borrowing and exact conversions so rejecting all evidence cannot win. Where evidence does not identify the hidden law, evaluate honest ambiguity rather than reward guessing one hidden truth. Measure numerical commitments and actual analytical outputs, not only wording.

Only after a reproducible action error should a policy intervention be tested against an equally funded ordinary review. An alternative 24-session design can include 16 initial constructions and eight paired reviews, but it sacrifices construction replication; do not silently run both designs. See [DESIGN_CRITIQUE.md](DESIGN_CRITIQUE.md).

The reviewer-scale proposal is 6 x 4 x 8 x 2 = 384 initial constructions before gate calls. Neither that scale nor the USD50 estimate is presently justified. Cost and power must follow an interpretable pilot and the actual API ledger.

Continue this branch if errors are reproducible and a targeted policy changes unsupported numerical commitments while retaining useful generation. Simplify or stop if most alleged failures are legitimate borrowing, if only prose changes, or if ordinary review performs equally. Do not search for a new favorable patient cohort or claim new biomedical confirmation from controlled data.

## Paper implication

A promising positive framing is evidence applicability in Agent-built biomedical generators: turning incomplete studies into usable data while preserving which analyses are source-supported and which depend on assumptions. The candidate methodological contribution is an actionable treatment of those distinctions, not the word Agent, a caveat checklist, or a guaranteed rejection gate. Its benefit remains untested.
