# v0.33 核心贡献与关键实验审查

日期：2026-11-17。对象：`manuscript/DRAFT_v0_33.md` 及其已完成实验。性质：本项目根任务的独立判断与材料交叉核对，不是外部专家审稿。本轮不修改 v0.33，不启动生成、付费 API、患者分析或新数据收集。

## 1. 结论先行

**主线值得保留：根据科学分析需求，由 Agent 把发表证据转成可执行的联合生成模型，交付可以使用现有统计软件分析的虚拟人群。** 完整人群生成是当前实测场景，不必缩成补一列。

v0.33 已经把“能生成”“会组合证据”“哪些分析接近参照”串起来，比早期以通用反馈环为中心的叙述清楚。但当前证据还不足以把它写成一篇已经证明技术优势的 KDD 方法论文。最薄弱的一环是：**新增正结果证明了联合信息的价值，尚未识别出我们的方法如何比已有生成路线更有效地获得、解释或利用这些信息。** 这不等于没有贡献，也不意味着必须再发明一个 loss 或多 Agent 框架。

建议继续围绕这一问题：

> **When can a scientific Agent turn fragmented published evidence into virtual cohorts that support the requested analyses?**

方法贡献的候选落点是“研究用途驱动的证据解释与联合模型构造”。它目前有可执行实现和部分能力证据；其相对技术增量仍需验证。不要将其改写为“首次文献生成医学数据”，也不把论文转向通用的证据误用或 Agent 失败基准。

## 2. 审查边界与依据

本轮读取稿件的摘要、贡献、方法、实验、讨论和补充结果；核对两轮三组实验的协议、实际提示、结果表与来源/程序审查记录；读取受控组合、生活方式应用、既有 request-only 实验与原定科学用途验证计划。对两轮新增实验的主结论从已保存的 arm 汇总重新计算，另存 `AUDIT_RECEIPT.json`。这不是再次读取患者记录或重新跑统一分析器。

近邻核查限定为 G-Sim、LLMSynthor，以及 KMGen 的官方论文页；KDD 要求来自 2027 官方 Research 与 AI for Sciences CFP。G-Sim 方法使用原先本地全文，LLMSynthor 核查当前 v4 方法部分及官方 README；KMGen 只核查官方摘要，全文链接此次抓取失败，不声称完成其代码复现或全文审读。没有穷尽所有相关研究，也没有重新审查历史约数百个工作目录。

## 3. 现在真正支持什么

| 可以支持的贡献 | 实际证据 | 合适的强度与边界 |
|---|---|---|
| Agent 能从研究需求完成检索、科学建模和数据交付 | 11-11 request-only：两项需求、两种策略、12 个构造、36 张表；331 次模型调用、127 次检索；全部完成 | 证明两个既有场景中的操作可行性。工作流在 6 项汇总分析中仅 2 项更近，不支持整体胜过普通 Agent |
| Agent 不只是填参数，也能完成证据推导和模型选择 | 血压中从矩阵推导年龄/BMI 条件相关；铁状态中自行选 Gaussian copula 并从四格表解潜在相关；人工任务中组合调整与重复测量信息 | 这些是实际 Agent 决定，根任务没有指定目标系数或 copula。数学恒等式及 copula 本身不是新算法 |
| 联合证据能改善特定科学分析 | PNS 残差相关 MAE 0.16328 → 0.03498，下降 78.6%；铁状态绝对 log-OR 差异 1.76200 → 0.93727，下降 46.8% | 是 JOINT 相对 SUMMARY 的描述性改善，不能写成整个表的质量提高 78.6% / 46.8% |
| 生成数据有部分具体分析用途 | 生活方式调整后的城市–牧民 BMI 差为 1.700–2.251 kg/m²，测量样本为 1.882；同一实现也完整报告其余八个对比 | 该例使用原论文结论，属于来源丰富的重建；不证明新发现或独立人群迁移 |
| 生成结果可追溯到科学选择 | 来源值、采用参数、模型隐含量、抽样估计和测量参照分开记录；已有审计发现尾部问题 | 是已实现的可检查性。没有测过审查耗时、错误发现率或置信度校准，不能声称这些已改善 |

主文四块实验共有 44 个构造、132 张表，但其中 24 个构造属于人工受控任务。两轮新真实内容对照是 **18 个构造、54 张表、两个已暴露参照**。表数、种子和虚拟行数不能当作独立研究数量。

### 两个正结果需要怎样讲

**血压的亮点更强。** Agent 没有拿到要生成的目标残差相关，而是从外部相关矩阵做条件化推导，再构造创新项。生成残差相关均值由约 0.554 变为 0.725，测量样本为 0.717。这显示联合信息可以转成更有用的条件结构。但来源只调整年龄/BMI，评价还调整性别，跨人群与调整集的假设依然存在；两项 BMI 斜率的误差没有改善。

**铁状态是第二个有用而不完整的证据。** 生成 OR 均值由约 3.06 变为 6.97，测量参照为 17.79；联合缺乏比例误差由约 0.519 增至 2.594 个百分点，连续 Spearman 误差由 0.0447 增至 0.1736。四格表约束阈值联合关系，却不识别完整连续依赖；来源低铁蛋白比例约 30%，目标样本约 12%。这个案例应说明“改善哪项用途以及付出的代价”，不能称全面复制成功。

这两个结果共同支持的机制是：**边际吻合不足以保证联合分析；增加与分析相关的联合证据，能改善所约束的分析，但没有自动解决人群迁移和未识别结构。** 这是本项目目前最扎实的经验结论。统计学上它并非一个全新定理，论文的技术价值要由 Agent 如何完成这段工作来支撑。

## 4. 对 v0.33 的具体审稿意见

### 高优先级：贡献与实验的连接

1. **贡献 1 和贡献 2 之间还缺一段实测连接。** 摘要与方法从研究请求讲起，但两轮最强新结果使用协调者整理的固定证据包。实际提示禁止工具，只有一次构造，没有检索或反馈。它们很好地回答“信息是否有用”，没有回答“Agent 是否能自行从原文找到并正确组织这份信息”。不能把后者写成尚未发生的流程成果。
2. **通用流程仍不足以说明技术差异。** 现有 `workflow.txt` 已要求识别分析所需信息、追踪缺口、检索并建模；相较普通 Agent 主要增加这一策略指导。既有同模型、同工具试验没有一致质量优势。原样重复这一比较，等待更有利的随机结果，没有研究价值。若声称新方法增量，必须先明确改进的实际操作，并在冻结后检验它。
3. **正文埋掉了最能展示 Agent 的已完成实验。** 建议把 12 个 request-only 构造从 Table S6 的一句话提升为正文一个短结果块：两种策略均完成检索与构造、科学结果有适用范围、没有一致策略优势。它同时给出能力与诚实的对照，不需要新增实验才能呈现。

### 高优先级：科学用途与结论强度

4. **“更接近”与“足够使用”尚未接通。** 铁状态 OR 改善后仍明显不同。应为一个具体用途说明哪些差异会改变研究判断；不要求复制个体记录，也不以真实样本点估计当总体真值。
5. **生物医学可接受差异尚未事先论证。** 原有来源区间不是用途容差，虚拟种子范围不是临床不确定性。既有 matched-size 计划可解释有限样本差异，但不能给出临床等价性。没有领域依据时，使用“分析特定的接近程度/可行性”，不要补一个事后阈值使现有结果通过。
6. **有效重复数小。** 两轮均每条件 3 次新构造、每构造 3 个种子。百分比是描述性效应，不是 9 个独立模型的显著性结论。铁状态两位 SUMMARY 作者有相同主结果轮廓，进一步提醒我们同模型的多次调用并不等于多位独立领域专家。

### 中优先级：材料表达

7. 摘要中两项百分比可以保留，紧接着保留代价；图中同时显示所有预定指标。当前做法基本正确，不必再次增加限定语或大改图的视觉风格。
8. Figure 1 保留“Agent 读条件、推导关系、选模型、写生成器”作为中心；检索和修订按各实验实际执行情况标出。可以用血压与铁状态各一个短例子解释操作，不把单案例公式写成整个系统算法。
9. 论文中的两个 BASE 并不等价：PNS 原来就有关系证据，铁状态 BASE 没有所选定量统计。不能合并成一个通用“无证据”基线。
10. 已有数据家族的盲构造不等于全项目从未揭示的独立确认。无需为所有应用强行找新队列；但若新增“可靠迁移到新人群”的核心主张，就要另有相应评价边界。

## 6. 只补三个直接服务主线的缺口

详见 [NEXT_EXPERIMENTS.md](NEXT_EXPERIMENTS.md)。这是建议顺序，不是已冻结/执行的实验。

**第一项：完成已有的科学用途评价，不花新 API 费。** 对生活方式案例已有六张表做原定 matched-size real–real / virtual–real 诊断，保留全部九项分析和离散度。它回答“差异是否超过同一经验样本下常见的抽样波动”，不承诺独立人群、总体覆盖或临床等价。请实际参与的生物医学合作者判断一个用途及有依据的容差，披露其已知结果。

**第二项：连接原文与生成器，检验关键能力。** 用现有血压、铁状态案例，从研究请求和原文可访问入口开始，Agent 自己定位联合证据、解释统计定义、选择模型；协调者不提供提取好的数值包或目标答案。旧固定包只作为信息充分时的诊断参照，不伪装成同条件因果对照。先少量新会话，记录人工介入、证据遗漏/误读、实际推导及完整下游分析。已有 request-only 实验提供流程背景，这一步专门检验两项新正结果所依赖的关键工作能否由 Agent 完成。

**第三项：一个匹配的已发表生成方法对照。** 优先审查 LLMSynthor 在这些输入上的可复现性。生成阶段双方使用相同获准统计和请求，不给任一方目标个体数据；这只比较生成/组合能力，不替代从研究需求开始的系统比较。采用一项有意义的匹配比较，而不是扩成几十种模型。源码或关键定义不够时如实记录，停止不可信的复现。

第二模型复核是后续增强项：保持两案例 SUMMARY/JOINT 不变，可做 2 案例 × 2 条件 × 3 构造 = 12 次新构造。它检验核心现象的模型依赖性，不是当前应先做的大规模模型排行榜。新目标只为新增迁移主张服务；增加论文数量、Agent 个数、虚拟行数不在本轮计划。

## 7. KDD 的现实判断

[KDD 2027 Research 官方要求](https://kdd2027.kdd.org/research-track-call-for-papers/)列出的评判因素包括技术贡献、原创性、影响、执行、表达与可复现性。没有统一的“必须六个数据集、三个模型”规则。我们最大的缺口是可检验的技术增量与科学用途证据，不是尚未达到某个数量。

[AI for Sciences 官方要求](https://kdd2027.kdd.org/ai4sciences-track-call-for-papers/)强调领域科学价值、严谨验证和领域专家参与，也明确不鼓励单为技术新意堆复杂框架。它不是生物医学题材的自动降门槛通道；官方没有把新增湿实验或新生物机制列为所有论文的必需项。当前以方法发展为中心时，Research 是直接对照；若选择 AI4Sciences，需让具体研究用途与真实领域贡献成为论文中心。

我的审稿判断：**当前是有扎实工程、有限但有解释力正结果的方法研究草稿；还不宜声称已经达到强技术优势型 KDD 投稿状态。** 最值得努力的不是全局“打赢 Agent”，而是把“科学需求如何变成恰当证据与生成模型、最终哪些分析可用”这条证据链做实。比较结果可以质量相当但能力/操作成本不同，前提是相应优势真正测过，且没有隐藏人工工作。

本轮不建议换题，不启动证据误用随机基准，不重新微调已揭示目标。若关键能力与匹配比较均没有增量，应收窄方法主张、保留有用的应用和评价贡献，而不是继续增组件寻找正结果。
