# Exploratory numerical control for lung screening

The previously disclosed Polish full-article experiment asked a GPT model to find a materially different within-person pairing for a declared analysis. This numerical control asks whether an independently specified conventional assignment procedure, given the already extracted numbers and allowed rules, can also produce two such cohorts. The article, earlier agent comparisons, US/Malawi results and the cutoff accumulation audit are already known. This is a post-outcome constructive comparison. Any new witnesses are conditional on the fixed grids and published tests. This exercise supplies no estimate of Polish or target-country prevalence. [Original experiment](../article_lung_pairing_2026-11-22/PROTOCOL.md)

## Inputs and finite search

Use the original sex-specific finite positive measurement grids (8,000 per sex), the numerical source ledger and the archived rounding tests for the means, population standard deviations, Pearson correlation, slope, intercept and R². Preserve FEV1 ≤ FVC on every record. Optimize each sex separately, with equal outcome weights. Search only the missing within-sex assignment of the original FVC indices. Use no patient records, new model calls, agent programs, prior generated pairs or earlier outcomes as calibration targets.

1. Divide each sorted sex grid into 100 interleaved rank blocks of 80. Within one block, every candidate uses precisely the corresponding FVC ranks. For each of two directions, use the Hungarian assignment algorithm to maximize a signed count of screen-positive pairs (FEV1/FVC < 0.70) plus a multiplier times the centered, standardized cross-product. Prohibit physiological violations. Cover both signs of the covariance multiplier: 0 and ±{0.01, 0.05, 0.2, 1, 5, 20, 100, 1000}. Also include the identity permutation. These finite choices, physically feasible because the identity is feasible, give a menu of assignments for each block. Total cap: 3,400 linear assignment solves per sex across the two directions.
2. Combine one menu entry per block to seek a high and a low count, each near the positive square root of the printed R². Use a deterministic greedy fallback that successively moves blocks from a near-comonotone choice towards lower covariance, checks all intermediate candidates against the allowed target covariance band, then accepts improvement by flipping one option at a time. A mixed-integer selector may improve this solution on the same menus, with at most 2,000 nodes or 8 seconds per sex and objective. Use a solver incumbent only when it meets the original checks and is reproducible; if a time-limited choice is not reproducible, retain the deterministic candidate. Keep all four search statuses, their accepted/failure counts, checks, summaries and timings. The entire exploratory run has a 150-second process wall limit.
3. Qualifying witnesses require two valid integer permutations and passing every original registered rounding, positivity, physical and marginal check. The procedure is deterministic; its spread is compared to the original five-percentage-point pooled materiality threshold and two-point single-draw benchmark, with no author blocks, stochastic seeds, significance tests or sources of patient uncertainty attributed to this control. Also tabulate the synthetic fraction in [0.695,0.705) to contextualize any cutoff-seeking behavior. Endpoints found by this restricted search are attainable but need not be globally sharp. The two assignments are kept locally, and only numbers, hashes and original code are public-release eligible.
