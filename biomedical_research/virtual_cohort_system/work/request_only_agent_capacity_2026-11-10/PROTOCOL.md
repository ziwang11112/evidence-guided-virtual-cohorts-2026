## Question and actual treatment

Can a capable general coding Agent and an evidence-guided scientific workflow independently find evidence and construct complete virtual cohorts for specified biomedical analyses? What differs in the delivered data, source use, checks and cost?

The ordinary arm chooses its own plan, searches, scientific model, tests and revisions. The workflow arm receives a generic reusable scientific strategy connecting requested analyses, evidence gaps, study conditions, numerical uses, assumptions and generated-data checks. This initial implementation tests that strategy on a common tool-calling runtime. It does not introduce multiple specialized Agents, a trained model, automatic scientific-parameter optimization or an enforced clinical solver. The ordinary arm may spontaneously use equally good practices. Both have identical underlying tools and output requirements.
