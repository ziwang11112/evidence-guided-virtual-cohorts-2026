# Completed request-to-data execution and scientific analysis

**All four final-budget sessions independently retrieved evidence, authored a generator, passed their first trial and selected that generator. All twelve final tables were delivered and independently recomputed.** The data preserve the displayed reference association directions, with good numerical agreement for blood-pressure residual dependence, but several effect magnitudes and lipid relationships remain different. This supports bounded analytical use and actual autonomous construction, not universal data validity or overall workflow superiority.

This is the last batch of the current continuation. No additional calls, targets, seeds or replacements follow from its results.

## What changed, and what remained an Agent decision

Both ordinary Agent and workflow used the same `gpt-6.1-sol` configuration, target-population descriptions, requested variables/analyses, tool capabilities and within-round ceilings. Sources started empty. The workflow's additional input was a reusable scientific procedure relating analysis needs, evidence gaps, study conditions, reported/derived/assumed quantities, generation and checks. It was not given a source packet, scientific coefficients or target results. The ordinary Agent could independently use equally careful practices.

The shared interface now returns compact searchable source identities with expandable, hash-linked full records and abstracts. Model specifications pass unchanged to the worker. The final diagnostic allowed 48 model calls and 750,000 serialized input bytes per episode, compared with 24 and 250,000 in the earlier rounds. Dollar limits, source/trial/candidate/action quotas, scientific policies, estimators and sampling seeds remained bounded. These engineering/resource changes are not proposed scientific innovations.

The final resource diagnostic was [precommitted](PRECOMMIT.json) from terminal delivery failures before the preceding repair round's reference evaluation. Its independent [preflight](PREFLIGHT_REVIEW.md) verified the two validator-limit changes and the entire earlier expense ledger. No prior generator, source cache or reference estimate entered a new author context. Candidate programs ran only in the existing isolated worker; scientific structures and values came from the Agents.

## Final data: every requested primary analysis

Values below are means over the three predeclared final seeds. Each table has 3,000 rows. The same analysis code was applied to the generated records, followed by comparison with the previously exposed clinical aggregate reference.

| Analysis | Ordinary Agent | Workflow | Existing reference sample |
|---|---:|---:|---:|
| PNS BMI–SBP slope | 5.527 | 5.601 | 3.524 |
| PNS BMI–DBP slope | 3.870 | 3.994 | 2.260 |
| PNS residual SBP–DBP correlation | 0.696 | 0.727 | 0.717 |
| Lipid BMI–HDL slope | −2.612 | −1.189 | −4.623 |
| Lipid BMI–TC slope | 11.195 | 7.656 | 5.683 |
| Lipid residual TC–HDL correlation | 0.407 | 0.323 | 0.512 |

PNS slopes use mmHg per five BMI units; lipid slopes use mg/dL per five BMI units. All slopes adjust for age and sex. Residual correlations additionally remove BMI. Generated lipid units are converted from mmol/L using the same fixed 38.67 factor; this conversion does not harmonize assays.

The association directions agree, but magnitude matters. Both blood-pressure BMI effects are appreciably larger than the reference estimates. Blood-pressure residual dependence is numerically close in these two constructions. For lipids, workflow is closer on the TC slope, while ordinary is closer on the HDL slope and residual correlation. The workflow also spent more calls and estimated API cost in both cases. These observations do not establish a generally better policy.

No equivalence threshold or post hoc composite score was introduced. All per-seed values, ranges and absolute differences remain in [ANALYSIS_RESULTS.csv](ANALYSIS_RESULTS.csv) and [EVALUATION.json](EVALUATION.json). Clinical reference estimates are not known population truths: PNS intervals are conditional row-resampling stability bands, not survey-design intervals; lipid slope intervals are conditional HC3 sensitivity intervals, and its residual-correlation interval is unavailable. Generated seed ranges quantify sampling variation under one fixed law, not source-estimation, model or transport uncertainty.

## What the source audit establishes

**Actual numerical evidence use occurred.** Both PNS Agents independently retrieved China-PEACE BMI coefficients. Ordinary also found an explicitly reported Uganda residual correlation, 0.7307. Workflow found a treatment-corrected longitudinal Kendall tau and derived a Gaussian-copula correlation and residual variance budget. These scientific quantities were chosen and implemented by the API Agents, not supplied as host parameters.

**The statistical operators still differ.** The Ugandan residual model includes a different covariate set, categorical BMI and treatment exclusions. The workflow's dependence source concerns treatment-corrected repeated-exam phenotypes adjusted for age, sex and smoking; Gaussian conversion and further BMI/variance subtraction are assumptions. Neither source directly reports the exact target age/sex/continuous-BMI residual statistic. A numerically close final result is not proof that these transfer assumptions are correct. An Agent-chosen query included a numerical correlation value, so self-directed retrieval must not be described as an exhaustive, unbiased meta-analysis.

**Lipid evidence remains incomplete.** Ordinary's continuous component slopes and log-error dependence are explicit assumptions motivated by external context and categorical association evidence. Workflow accurately extracted Malawian per-SD coefficients but converted them using an assumed transported BMI SD of 4.8; that is not recovery of the unknown Malawian physical-unit coefficient. Workflow assumes conditional HDL/non-HDL independence. Both models can produce a positive TC–HDL correlation through their shared HDL component even without identifying the missing component dependence. More detailed provenance is not itself an accuracy advantage.

**No revision gain is demonstrated.** All four v001 candidates passed their first trial and were selected unchanged. This is evidence of successful autonomous construction/checking, not evidence that a feedback revision improved scientific quality. The Agents retained freedom to revise; none chose to do so in this round.

See the [independent scientific provenance audit](review/SCIENTIFIC_PROVENANCE_AUDIT.md) for source locators, exact reported/derived/assumed quantities, units, selection differences and supported mathematical calculations. It did not inspect clinical reference results.

## Exposure, verification and decision

All clinical reference families were already exposed at project level. Fresh API contexts do not create new clinical confirmation. The bounded current-round audit found no PNS-family ancillary result or Turkana source material in the inspected returned text; that is not proof of perfect provenance screening. The prior repair-round PNS ordinary session's incidental public national-survey prevalence exposure remains explicitly recorded and was not erased or silently repaired.

Independent saved-table recomputation passed **1,157 checks**, with maximum numerical difference **5.51×10⁻¹⁴**. All twelve distinct CSVs, 36,000 retained rows, candidate/receipt hashes, design matrices, unit conversions and cost/count totals agreed. This verifies execution and numerical reporting, not clinical validity. [Recomputation](review/INDEPENDENT_RECOMPUTATION.md) · [Source/tool/cost audit](review/TOOL_SOURCE_COST_AUDIT.md).

**Decision:** freeze this working execution interface for analysis and writing; do not add more framework components or paid batches in this continuation. Center the paper on independently constructed, evidence-informed virtual data and the scientific analyses they can and cannot support. The current results justify an inspectable capability claim and analysis-specific agreements. They do not justify universal transportability, a workflow-superiority claim, patient-measurement replacement or a revision-gain claim. Further scientific improvement should address appropriate conditional/joint evidence and its transfer assumptions, without inserting desired reference coefficients.
