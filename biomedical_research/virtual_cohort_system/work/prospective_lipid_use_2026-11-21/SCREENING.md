# Prospective use decisions on a frozen virtual lipid cohort

Select two previously unscored study frames by methods and file availability. Carry forward the first unused community candidate (Gondar, PLOS ONE 0257710) from the external lipid screen. For a complementary frame, seek an independently recruited adult type 2 diabetes outpatient sample, in which a population-level lipid model faces a stated case-mix difference. Start with open PLOS primary studies in Ethiopia to limit geography as a source of heterogeneity. For each frame, exclude studies used by this project as evidence or target, duplicate study cohorts, children, arms selected on the lipid measurement, and datasets with no verifiable numeric paired TC and HDL or units. If Gondar has no public pair data, screen further independent Ethiopian community studies using the same eligibility rules. If no diabetic sample qualifies, extend that metadata search first to other African and then to other countries' adult outpatient studies. Review release headers, group filters, methods and access statements only. Never select by measured distributions, correlations or threshold proportions.

Require at least 100 eligible adult records per frame before computing any endpoint. A person-level release with a documented one-row-per-person design can qualify even if anonymous IDs are absent. Count missing data, repeats and complete pairs without printing values. Choose the first qualifying release in the public, ordered candidates within each frame; record missing files, incompatible variables, units, eligibility and all attempted alternatives. Stop after two admitted frames, or carry a single frame if only one qualifies after screening ten studies. Preserve any shortfall. Do not use another exposed family as a fresh comparator. No individual data leave the machine. Targets must be selected and the recommendations, common virtual estimates, scoring code and decisions frozen before computing outcomes. This is an endpoint-use study of an existing agent law. Original generators, prior accuracy results and frozen models remain archived.
