# Returning a modeling question to the source

This development exercise starts with the frozen Hong et al. search-to-model run. It tests whether a model can recognize a consequential evidence gap in its own completed draft, choose a published table, read it and decide how to use it. The source, its tables and the weaknesses of the old sampler have already been seen by the project team. This is a paired engineering and scientific-use comparison on a known study. The researcher does not select a table, transcribe a cell, prescribe a model or supply an error on the old generator to the author.

## Fixed inputs and decisions

Reuse the original research request, actual selected source text, original Agent decisions, measurement pair and baseline program. The return agent sees those artifacts and an index of tables from the already selected papers. The index contains labels and captions but no table cells. It may request zero, one or two tables, adapt the second request to the first reading, or keep the baseline with its caveats. Each chosen table must be traceable to the selected article and version. An image table is read as an image by the model and recorded with the image hash; textual tables retain their column structure. No supplemental patient records, plotted individuals, independent evaluator key, public project report, or previously measured discrepancy is sent to the return agent or model author.

Use the same configured GPT with medium effort. Allow three decision calls ($1 maximum total), up to two table readings ($1.50 total), and one revised design/build/review sequence ($1.75 total) if the return agent decides to remodel. When it keeps the draft or finds no useful material, retain that outcome. Unit normalisation, trial feedback, isolated execution, three final seeds and 10,000 virtual eyes per scenario use the existing authoring runtime. Changes to the probability law and assumptions remain with the model. No paid search repeat for this case, no repeated author attempt to obtain better agreement.

## Evaluation

First check whether the actual model request leads back to a genuine article table and the numerical observations reach the scientific author. Independently verify row and column identities, session/visit, units, precision, and roles of the values adopted. Compare the primary scenario of the frozen initial run with the primary scenario of the returned-evidence run at the same seeds; also report every delivered alternate. Recompute both instrument means and sample SDs, signed OCT minus ultrasound mean, dispersion, and the percentage strictly beyond 20 µm from the virtual paired measurements. Report each deviation in original units against applicable printed values. Pay attention to the distinction between the variance of averages of three measurements and agreement limits corrected for the removal of repeat error by averaging.

The paper gives no independently counted proportion over the requested threshold, so a changed synthetic percentage is sensitivity evidence, with no measured error available to rank its accuracy. Repeating numerical seeds does not create additional studies. A better fit of a supplied cell is evidence of successful extraction and use. Any advantage across independent papers or effect uniquely attributable to retrieval requires a different design. Preserve unchanged outcomes and scientific or implementation failures. Corrections to the evaluator cannot change the model, thresholds or inputs.
