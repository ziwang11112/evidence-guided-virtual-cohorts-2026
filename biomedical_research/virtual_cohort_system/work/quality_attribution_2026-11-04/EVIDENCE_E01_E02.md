## 2. 不是所有“缺证据”都是同一种缺口

### 2.1 原始统计真的未报告

E01 需要同一分析情境中的 HbA1c 条件残差尺度，以及 BMI、glucose、HbA1c 在同一调整集下的残差协方差。现有文献分别给分位数、边际 SD、两个嵌套 R² 及另一研究的原始相关，不能直接代替这些量。

E02 需要个体层面 BMI–HbA1c 条件关系和 BMI/age–glucose 依赖，HGI 组均值不足以识别。全协方差公式为：`Cov(B,Y)=Cov(E[B|K],E[Y|K])+E[Cov(B,Y|K)]`。分组摘要最多给第一项，第二项未知；不能因它未报告就默认为零，并认为由文献确定了总关系。

### 2.2 有真实数字，但回答的是不同问题

边际 SD 与条件残差 SD、age-only sex effect 与 age/BMI/glucose-adjusted sex effect、某年龄小组分位数与全人群离散度，都是不同统计对象。当前记录一般已经标注这些移用，但**作者仍可把高影响的移用作为唯一数值情境提交**。这正是方法层面可以改善的地方：让证据充分性决定输出形式或下一次检索，而不只增加一段免责声明。

### 2.3 数字内部不能全部兼容

Marini 样本 1 同时给：`mean(G)=93, SD(G)=11, mean(H)=5.4, SD(H)=.4, r=.55, H=4.0311+.0158G`。若来自同一样本、同权重的普通带截距 OLS，并将报告的 r 解释为 Pearson 相关，必须有：

- 方程在均值处给 `5.5005`，而报告均值为 `5.4`；
- `r×SD(H)/SD(G)=.020`，而报告 slope 为 `.0158`；
- 反过来 slope 与两 SD 蕴含相关 `.4345`，不是 `.55`。

常规按最后一位四舍五入也不足以解释：取 `mean(H)∈[5.35,5.45]`、`mean(G)∈[92.5,93.5]`、截距/斜率相应半单位区间，方程最小预测均值仍为 `5.487925`；取 `r∈[.545,.555], SD(H)∈[.35,.45], SD(G)∈[10.5,11.5]`，蕴含斜率至少约 `.016587`，仍高于 `.01585`。这只是基于通常舍入规则的兼容性算式，不能判断哪项有误，也不能排除未交代的样本/拟合区别。

E02 已明确优先均值、SD、slope，舍弃截距和相关；没有在代码里承诺全部满足。这是有记录的科学取舍，不是新发现的转录 bug。通用求解器可以发现/展示冲突，但不能把不相容数据变成唯一正确目标分布。

Kerman 的 SD 和 `r=.23` 蕴含两个方向的简单回归斜率约 `.01354` 与 `3.90685`，不等于表 2 的 `.13` 与 `.38`。E01 已主动不用这两条斜率，保留原始相关和边际 SD。不能因为斜率有疑点就“校正”原文数值后当作已证实证据。

### 2.4 来源对应的筛选总体不同

E02 的 Italian `.4` 来自 HbA1c<6.5、FPG<126 并有大量排除的来源；任务没有 HbA1c 上限，没有核实药物/贫血排除，且年龄/性别采用等额设计。E01 的 Finnish 来源排除 HbA1c≥6.5，Kerman 低 FBS 组反而保留部分已知糖尿病者。不同选择的矩不宜被当作同一总体事实精确拼接。

这些差异是失配的可能解释和明确的适用性缺口，**并未证明它们各自造成了多少目标误差**。不能拿目标 SD 反填残差，也不能因为人群不同就无条件免除用途评价。

## 3. 方法本身的问题在哪里

| 层次 | 本次判断 | 应采取的有限改进 |
|---|---|---|
| 数字转录、单位、基础公式 | 选用数字与原文核对相符；E02先前两处打印 variance 已有独立更正，未改变最终公式 | 保留原文/表格定位；不要将已更正历史问题算作当前质量主因 |
| 概率生成实现 | 代码实现 E01 固定条件 Gamma 方差和 E02 固定算术条件 lognormal 方差；实际输出残差接近声明值 | 当前不应优先换 sampler 或新增随机种子；这里没有证据证明是主要瓶颈 |
| 证据到条件模型的转译 | 多个高影响量经边际→条件、组间→个体、年龄组→全人群转换后，以一个假设值直接使用 | 将这些转换设为有明确所需联合量的操作；缺条件时交付假设情境或触发针对性检索，不伪装成原文确定值 |
| 来源冲突与可迁移性 | 现有审查能识别并记录，却没有统一的“什么可以共同约束什么”的决策 | 按人群/选择/测量/调整集分开来源算子；兼容性检查只协调同情境可比量，不把所有文献量强塞进一套矩 |
| 研究用途与检索预算 | 四篇来源可能提供很多背景/边际量，但关键条件关系仍为空；源检索在首冻结时结束 | 冻结前先列出本次用途缺的量，优先检索它；可先核已有文章的相关补充材料，不以增加论文数为目标。是否开放新获取由根任务的新协议决定 |
| 数据交付 | 一个最方便的完整联合分布未必足以支持所有分析 | 对关键未确定关系提供有限的、保持既有约束的候选情境或缩窄分析用途；这些不是校准置信区间，不需要默认多 Agent |

这不是否定 Agent 自主构造。Agent 选择结构与补全假设的能力已经存在；要改善的是它**何时可以把一个证据缺口固定成单一关系、何时应主动寻求关键证据、何时应交付有界的情景差异**。若只增加更复杂的结构而没有新的约束，数据可能更灵活，也可能更任意。

## 4. 优先补什么证据；每种证据能改变什么

1. **HbA1c 条件离散度及选择适用性。** 优先寻找报告与目标筛选接近、同一调整集下 residual SD/RMSE 或足够重建它的模型 R²+总方差的研究；若仅有分组 SD，保留分组定义，不直接当全任务残差。它可约束 E01/E02 的条件波动和相关强度，不能单独确定形状/尾部。
2. **同一来源里的多变量关系或共同残差矩。** 对 BMI–HbA1c/glucose，需要同样 age/sex/fasting 调整与编码的系数/相关、预测变量协方差及不确定性。Skogberg 原文确实提到补充 Tables S1–S4 有回归结果，但这些不在本次已审源码包内，不能声称已读到，更不能自动假定补充表给了完全所需的条件关系。它们是有针对性的后续核查候选。
3. **测量/人群适用性，而不是再找同方向论文。** Pani 的 `.010` 与 Huang 的 sex effect 已真实存在；需要的是它们能否在任务的 selection/assay/age 范围迁移，以及相关效应是否随这些因素变化。更多重复方向不会自动给出迁移幅度。

最小下一步不应同时改 family、依赖系数、来源权重和残差尺度。先挑一个证据缺口，固定其他选择，比较“现有补全规则”和“新增合适证据/明确条件转译”对预定用途的影响。保持原冻结结果，用新版本记录。若新资料仍不能约束该量，应保留情景或缩窄用途，不用已知目标的值完成填空。

## 6. 根任务 aggregate-only 诊断的独立静态检查

读了本目录 `aggregate_diagnosis.py` 与已生成的 `AGGREGATE_DIAGNOSIS.json`，没有重新运行。另静态读取 C02 条件均值实现以核 E2/E3 的系数对应。判断：**脚本范围与数学解释可接受，无需阻断修复。**

- 输入限定为已冻结 366 项汇总 CSV、C02/E01/E02 参数规范及 E02 证据 JSON；没有导入/执行候选，没有随机生成或读取参与者/虚拟个体表。输出仅写新诊断目录，运行前后比较输入哈希。
- 六项直接条件均值系数与其单位换算正确；E01 的第七项简化模型投影 `5×(bBMI+bG×gBMI)` 来自两层线性条件均值与残差正交性，不被误称原文直接报告。两个残差量分别是 `sqrt(E01 variance)` 与 E02 设定 SD。
