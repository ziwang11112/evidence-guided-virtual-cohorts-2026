# Can authors produce different answers under all the same lipid summaries?

This is a new source-only sensitivity experiment following the review of KDD v0.40. The Ethiopian outcomes have already been published in the project. No new program will be selected, tuned or scored on either sample. No external records enter this experiment. The result concerns the information in the published Mwanza summaries conditional on the two shared marginal shapes. Four independent author sessions, one GPT configuration and three seeds per scenario provide a descriptive capability check.

## Task and controls

Reuse the original six published source summaries and the two arrays of 16,000 ordered marginal values in mg/dL. The main quantities are the mean of TC minus HDL and the fraction with TC minus HDL at least 160 mg/dL. The article reports the mean of individual TC/HDL ratios as 3.66. Both scientific choices and the computer interface are disclosed in REQUEST.txt. Four fresh GPT-6.1 Sol sessions each author one executable program with two named scenarios. Authors see the common request and source extract. They receive no target results, positions taken by earlier constructors, comparator code or one another's outputs. There is one call per author, medium reasoning, up to 12,000 output tokens each, no source or target feedback, and a total US$0.96 tariff ceiling. Every planned slot stays in the denominator, including outputs rejected by the parser or the execution contract.

The central comparison is between the two scenarios within each fresh author. Each scenario assigns all prescribed HDL values to all prescribed TC values exactly once, with no negative non-HDL values. The same seeds (40937, 40949, 40961) apply to both. A scenario is admissible only when all three seeds complete, both original margins are preserved, every pair satisfies HDL ≤ TC, each mean individual ratio differs from 3.66 by at most 0.02, and the pooled mean ratio is in [3.655, 3.665). These are operational checks against the reported precision of the source point estimate, not estimates of its population uncertainty. Positivity and valid ordering alone do not establish biological realism.

For a material sensitivity finding both scenarios must pass. Their pooled tail fractions must differ by more than 4 percentage points (twice the ±2-point illustrative planning tolerance in v0.40). To exclude a single-seed jump, all three signed within-seed differences must exceed 2 points in the direction of the pooled difference. Report both scenario values, source fit, ordering violations, seed results, failure reasons and costs for all four authors. Three repeats of a deterministic program count as one law. Report a weak/negative result if the thresholds are missed. There is no between-model significance test and the requested two scenarios are illustrative alternatives, not clinical forecasts.

Independently establish numerical feasibility with two deterministic constructed permutations. Split the 16,000 ranks into 125 interleaved blocks of 128. Within each block solve linear assignments penalizing the individual ratio over a fixed multiplier grid in both tail directions, forbidding HDL > TC. Select one admissible permutation per block using an integer linear program subject to the same global ratio rounded to two decimals. Directly recompute on the actual finite arrays. This is a positive control that targets the requested statistic and gives feasible examples, not globally sharp bounds or a clinical superiority benchmark. An inability to find examples is recorded. The previously published Gaussian result is contextual only because it predates the stricter biological ordering check. No new participants, target downloads or target accuracy claims.
