# What did the agent add to the scientific analysis?

Research-track review of the v0.40 working paper, with a frozen source-only lipid experiment and a retrospective lifestyle ablation. The unit of assessment is an **analysis in a specified population**. Estimates obtained from measured samples have sampling uncertainty.

## Reviewer assessment

The best claim is that an agent can turn a paper into an executable model, and show a scientist which conclusions change when the model pairs measurements differently. The CHNS iron comparison goes one step further. For one held-out population, a specific part of six agents' programs brought a continuous analysis closer to measurement. A person with the source counts could already recover its threshold association. The distinction makes the contribution testable. A claim of general improvement in accuracy over statistical generation would receive a weak review. Both approaches chose similar lipid models on the same inputs and made essentially the same external error. Classical work already established that fixed marginals can give widely different distributions of a sum or difference. The computational question here is whether a scientific agent can read the evidence, construct valid alternatives and help a researcher decide which analyses to use. The present evidence is strongest for the first two abilities. ## What four new authors actually produced

Each of four fresh GPT-6.1 Sol sessions received the same source-only request, including the intended analysis and the dimensional and index requirements. Each wrote one program with two assignments of the same 16,000 total cholesterol and HDL values. We sealed the programs, then executed both scenarios with each of three predeclared seeds. The authors did not see either comparator, previous programs, Ethiopian results or each other's responses. Every planned author and execution is present. Two scenarios from one session are paired observations. Three seeds measure numerical repeatability. Four authors on one source and one GPT configuration describe the scope of this experiment.

The fourth decimal for a displayed percentage may be rounded. The pooled numbers for each author come from 48,000 rows per scenario. One request explicitly invited different source-compatible joint structures. Three authors used swaps guided by cutoff crossings. Author 2 used rank cycles in opposite directions calibrated to the ratio. The latter gives an especially legible visual example of how the *same measurements* can yield two scientific answers. Its rank geometry is stylized. These are deliberately different scenarios. Their endpoints have no probability or confidence-level interpretation.

All 24 tables retained both complete marginal arrays, both original single-marker threshold frequencies (14.4% and 15.3%), a mean non-HDL of 128.7711 mg/dL and a mean individual ratio within 0.00020 of 3.66. All passed the ordering requirement. A deterministic blocked assignment solver produced two explicit additional permutations satisfying the same constraints. Their spread covers 98.5% of the width between the unrestricted empirical outer bounds. We make no sharpness or biological-plausibility claim. The four model calls cost an estimated USD 0.2308076 under the logged tariff. An independent implementation reconstructed the arrays and checked all 24 sealed outputs and both numerical controls. The new protocol differs from the earlier single-scenario prompt and has stricter order checks. A cross-run improvement in predictive accuracy cannot be estimated from this comparison. ## The decisive next validation

A prospective scientific-use decision would add more information than further seeds on either Ethiopian sample. The outcome of interest is whether a researcher can identify *before opening a new cohort* which analyses will carry over within a tolerance that matters for the stated use.

- Register untouched target studies by provenance, assay, inclusion criteria and data availability, with two or more independent target frames if available. Register all eligible study-by-analysis combinations before examining effects. Choose simulations per model for numerical precision. The target frames determine the independent evidence for transfer.
- Give a fresh agent and a statistical procedure that allows dependence the same source studies, request, scientific tolerance, computation budget and measurement information. Both submit a point estimate, alternative source-compatible structures, and a pre-reveal use decision for every endpoint. Both receive the same opportunity to abstain. The primary comparison uses the same prespecified coverage; publish the full coverage–error curve and the abstentions.
- Open each target once. An assurance is contradicted when the measured uncertainty interval for the signed discrepancy lies wholly outside the agreed tolerance. Classify an interval crossing the tolerance boundary as unresolved and report its count along with the denominator. Also report point discrepancies and intervals. Keep the evaluator independent and retain failures and all outcomes. Sampling uncertainty and target shift enter this assessment even for an estimand determined at source.
- Primary result: the fraction of assured analyses contradicted at matched coverage, with study-level uncertainty where sample size permits. If the agent only matches the statistical procedure, the supported contribution remains an executable, evidence-traceable sensitivity analysis. A reduction in false assurances at comparable coverage would support a stronger decision-support claim. The new experiment has not been run. The present results do not estimate that reduction.

## Manuscript emphasis

Lead with the lifestyle researcher's two real questions and the iron example where a modeling choice made a measured difference. Use the default lipid tie, the source-compatible counterexamples and the Nigerian result together to show where agreement or assumption checking reaches its limit. Place the four-author rate, all nine lifestyle contrasts and all six iron pairs beside the highlights. The new lipid batch tests counterexample construction on request. A claim that agents independently discover generally correct dependence structures would go beyond the experiments.
