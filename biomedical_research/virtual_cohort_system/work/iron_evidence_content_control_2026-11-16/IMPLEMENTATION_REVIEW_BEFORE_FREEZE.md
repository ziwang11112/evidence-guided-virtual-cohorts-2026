# Pre-freeze implementation and information-boundary review

Root review, 16 November 2026. No second human/model review is claimed. Numerical independence refers to the separately written historical estimator.

The new wrapper reuses the established API client's single-call parser/receipt/accounting, the sealed program-author interface, and the unchanged WSL/bubblewrap worker. It changes task/schema, explicit source masks, schedule and host-only statistical routing. No scientific generator, covariance parameter, conditional probability or preferred relationship is embedded in the wrapper. The four source cells are audited extraction facts rather than host-selected generative parameters.

The previous runtime would classify non-BP tables as lipids. The new wrapper therefore explicitly binds its statistics function to analysis_adapter.statistics before any run and asserts that binding in freeze verification. This avoids silently applying a lipid analyzer to Hb/ferritin. The adapter calls the historical iron analyze_synthetic function; a separate historical weighted_metrics implementation recomputes all outputs. No reference loader, patient decoder or source-feedback call is invoked by the adapter.

Nine preflight checks passed:
- Identical source/target context and requested analyses; exact information increments.
- Original eight-row source collapse agrees with direct univariate margins and the previous independent audit.
- Source-derived OR, target result, full text and omitted conditional tables absent from payloads.
- Strict inequalities, equality at cutoffs and tied ranks checked.
- Zero-cell OR and constant-rank correlation retained as nonestimable without smoothing.
- Re-pairing measurements changes association while preserving margins.
- Negative/nonfinite measurements rejected.
- One artificial 128-row fixture executes in WSL/bubblewrap, with absent host mounts/network routes and correct iron routing; independent statistics agree.
- Previously authorized API credential present, with no secret printed or changed.

The fixture's fixed toy values test software only and are never passed to authors. It is excluded from the planned 27 experimental tables. Source PDF rendering is read-only and carries no target information.

The design is not identical to the historical iron experiment: all new authors receive controlled subsets of one existing source, not the old two-source packet or its feedback. BASE shares source metadata but no selected marker statistics. This difference must remain explicit in cross-case interpretation. Full PDFs and API logs stay local. No public synchronization or new automated schedule is included.
