# Post-construction audit guide

This is an evaluator-side reading guide. It is not an input or feedback channel to any author. Apply it to every scheduled session, including missing/failed deliverables. The original sources and requested analyses were fixed before launch; do not choose a preferred model using the target results.

1. **Actual source access:** Which original parts/pages were returned? Which supplementary abstracts or full texts were returned, rejected or only listed? A citation alone is not evidence that the full paper was read. Record query/target-alias screening incidents without treating a rejected query as a returned target result.
2. **Extraction fidelity:** Check material declared values and locators against original methods, tables and footnotes. Preserve unit-printing conflicts, geometric/arithmetic and CI/SD ambiguities. For the iron paper, distinguish source inconsistencies from transformation errors by using the already inspected page images. An omitted uncertain statistic can be an appropriate decision.
3. **Composition:** Does the Agent correctly distinguish unadjusted, conditional, multilevel and residual quantities? Do any collapsed counts use mutually exclusive groups from the same participants? Check actual derivation arithmetic. A valid source derivation does not establish transfer to the requested population.
4. **Model authorship:** Read the submitted specification and program. Verify which assumptions are actually implemented, including residual dependence, heterogeneity, conditional scales, continuous within-cell relationships and truncation. Record every materially unsupported numerical choice as an assumption rather than silently recategorizing it as evidence.
5. **Mathematical/physiological behavior:** Inspect finite relevant moments and any impossible-order or nonpositive outputs. Bounds, mixtures and transforms can change moments and associations. Report concerns without editing code or selecting a more favorable seed.
6. **Executed behavior:** Relate initial/revised candidates to actual generated-only diagnostics and model selection. Distinguish a mechanical repair, a changed law, a changed narrative and a justified no-op. No target-informed adjustment is permitted.
7. **Scientific-use profile:** Use all prespecified primary analyses and diagnostics after global closure, independently recomputed. The unit is a small feasibility test with three constructors per case; seeds are within-construction repetitions. Old packet conditions are contextual, not equal-input randomized comparators.

Record clear errors, unresolved ambiguities and partial coverage separately. Do not turn this audit into an unvalidated aggregate confidence score or retrofit a success threshold. Root review and separate numerical implementation do not substitute for independent domain-expert assessment.
