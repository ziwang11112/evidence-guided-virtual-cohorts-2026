# P1: original-paper-to-model capability

17 November 2026, America/Chicago. User-authorized execution of the KDD first-paper plan. This unit reuses the existing PNS blood-pressure and NHANES iron-status cases. The scientific aim is final virtual data supporting the requested analyses, with the actual source extraction and modeling work performed by the Agent.

## Design and information

Three independent GPT sessions per case; one final generator per session; three registered final seeds (17121, 17123, 17127), for six constructions and 18 final table slots. Use the existing gpt-6.1-sol configuration, high reasoning, default tier. Model calls, prompts, tool arguments/results, immutable candidates, outputs, usage, reported model IDs, estimated tariff cost and unknown usage reservations remain recorded. No new provider, model training, HPC, patient acquisition or API key is required.

Each author starts from the population/output contract, the exact requested analyses and an original-paper citation with access to the complete original. The blood-pressure source is DOI 10.1136/bmjopen-2024-089374, in original JATS; the iron source is DOI 10.1024/0300-9831/a000014, as complete PDF layout text. Source preparation splits original sections/pages only; no coordinator-selected numerical evidence, derived association, intended sign, joint law or target estimate is provided. Original studies may contain numerical results; these are legitimate inputs. This is a known-entry-point reading and modeling test, not a claim of finding the paper unaided.

Authors may independently search Europe PMC and read approved open PMC articles using the existing screened adapter. Queries are chosen by the Agent, within resource ceilings of 12 queries and 8 downloads per session. Target-cohort and project aliases are excluded by that existing gateway. A later audit records the actual returned source content and any exposure; screening is not an independence guarantee. No general filesystem or target-analysis tool is exposed to authors. References, publications and tool outputs are untrusted data, not instructions.

The Agent decides scientific structure, distributions, parameters, transformations, transfer assumptions and whether further evidence is needed. Source locators, measurements, adjustment/selection context, units and uncertainty should be recorded. Reported statistics, derivations and assumptions remain distinct. Root does not repair scientific parameters or replace a selected model. Whole-cohort generation has no target participant input.

## Construction and execution

Reuse the existing durable GPT tool loop and WSL/bubblewrap generator-only runner. Add an allowlisted original-paper reader and explicit routing to the unchanged PNS/iron scientific estimators. Spec is passed exactly as submitted, not wrapped. No host execution fallback. A failed run consumes a slot.

Per author: at most 40 model turns, 60 tool actions, two immutable candidate submissions (initial plus one revision), two generated-only diagnostic trials at seed 17101, USD4 accounted model spending. Total model ceiling USD24; reservation limits stop dispatch before overspending. Current tariff is a bound, previously verified schedule, not a new invoice quote. Limits are ceilings, not targets. Unknown usage retains its reservation. No automatic retry of uncertain HTTP/tool dispatch and no extra replacement constructor.

Source text is converted losslessly at the original-section/page level as far as the native text permits. Original PDF table pages are visually checked against the extracted layout before launch. Conversion defects are distinguished from source ambiguities and Agent interpretation errors. The original artifacts and converted bytes are hashed and frozen. PDF text does not expose figure pixels; authors must record if a graphical statistic is not available rather than invent it. This is a declared input limitation.

Before launch, check task contracts, source allowlists, pagination, cross-case denial, schema/spec pass-through, both estimator routes, independent numeric agreement and actual sandbox isolation on artificial fixtures. Freeze prompts, input/source bytes, tool definitions, implementation, evaluator and costs. The root's separately performed engineering review is described accurately; it is not an external domain adjudication.

After all six author sessions close, bind every selected candidate and full author history before any final seed or target comparison. All 18 final slots remain in the inventory, including unavailable/failed ones. Read the previously exposed target aggregate references only for the closed batch, never return them to authors. Root may read/review generated programs but may not edit their science. New target-informed generation is not permitted.

## Evaluation and interpretation

Use exactly the existing analyses and measurement definitions:

- PNS: BMI coefficients in SBP and DBP regressions adjusted for age and sex, plus paired residual Pearson correlation; retain both population-SD diagnostics and SBP<DBP frequency.
- Iron: crude anemia/iron-depletion odds ratio, joint-low prevalence and continuous Spearman correlation; retain both low-marker prevalence diagnostics. Hb threshold <12 g/dL; raw ferritin <15 ug/L. Zero-cell odds are not estimable without an added continuity correction.

For each final table, independently recompute the full endpoint inventory from saved rows using the existing separate QR/count/rank implementations. Report all construction means and seed ranges, and reference discrepancies (absolute log-OR difference for iron odds; absolute original-scale differences otherwise). Do not silently drop failed/nonestimable outcomes or count seeds as independent constructors.

Audit whether the author actually read the original, extracted values and conditions correctly, derived joint information correctly, and implemented the declared structure/assumptions in code. Record missing locators, ambiguous source summaries, omitted useful evidence, supplemental search, unsupported extrapolation, mathematical/physiological concerns, no-op revisions and mechanical errors. Root's knowledge of older results must not be supplied as a suggestion to the model. Such auditing explains this batch and is not a calibrated confidence score.

Historical BASE/SUMMARY/JOINT outputs are context only: full-paper access and optional search change the available information/tool setting. This batch is not a randomized estimate of a workflow or retrieval policy effect. Both target families were already exposed to the project; a fresh API session does not make a new clinical holdout. Sample references are not population truth. No acceptance margin is tuned against observed outcomes. If missing identification or source transfer dominates, retain that boundary rather than fill the answer.
