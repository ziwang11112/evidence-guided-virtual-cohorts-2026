# Prelaunch interpretation and analysis plan

Primary unit: starting generator (twelve), with two new review branches; two clinical contexts. Prior generator origin and review treatment are separate factors. This is a development-designed mechanism pilot using all prior laws, not prospective validation of a newly discovered failure mode.

## Report in three separate panels

- **Detection and scientific-law change:** Agent concerns recorded before clinical reveal, source retrieval, contract completeness, actual code/spec changes or retention, and independent postclosure adjudication of mathematical/measurement/dependence claims. Count warnings, unresolved findings, substantiated defects, false alarms, repairs and newly introduced defects separately. AST flags alone are not truth labels.
- **Returned-data coherence and delivery:** every planned slot, runtime/budget failures, nonfinite/invalid outputs and the same common physiological diagnostics as the original evaluation. Show Agent-selected rule checks separately, since choosing weaker rules can make apparent success trivial. No output rows may be dropped after evaluation.
- **Requested scientific analyses:** all six original endpoints and marginal SD diagnostics, displaying initial/generic/structured constructor means and all three seed estimates with the saved reference uncertainty. Within each law report signed change and change in absolute distance to the same sample reference; summarize descriptively within context. A positive reduction in absolute difference means closer to that sample estimate, not proven population improvement. Do not pool endpoints of different units into a single score.

All final outcomes remain in the denominator. If a branch cannot select or deliver a law, its scientific comparison is unavailable; the original is not imputed as its final output. Descriptive paired comparisons among available outputs must state the eligible denominator and show failures alongside them. Retained law is counted as retention even if a different notes file was submitted; bind code/spec and determine actual scientific changes from their content.

Use old initial saved tables at exactly the three prescribed seeds. For a retained byte-identical law, regenerated final hashes/statistics should match under the unchanged worker; unexplained discrepancies require inspection, not choosing the better version. Changed structure may consume RNG draws differently, so equal seeds do not create a clinical paired design. Shared cohort-parameter sampling, when present, remains part of encoded scenario variability and is not a calibrated source/transport confidence interval.

Independent postclosure adjudication should distinguish (i) moments actually undefined under a continuous ideal law, (ii) moments finite only because of implemented numerical caps, (iii) bounded or otherwise justified finite laws, and (iv) insufficient static information. Physiology review distinguishes a stated biological identity from an approximate measurement relation or heuristic bound. Joint review checks whether an assumed dependence was merely renamed as derived/reported. Documentation changes alone cannot be scored as empirical repair.

Record novel evidence and changed scientific assumptions in the same table as each analysis change. This supports attribution of a changed model, not a randomized decomposition of search versus math versus physiology versus dependency review. The ordinary/structured contrast estimates the complete instruction-plus-gate treatment under shared tools, not an isolated check algorithm. There is only one review session per branch per initial law; conclusions about model-level repeatability remain limited.

The root and previous project reviewers have seen the old clinical comparisons. New API review contexts receive none of those values. Old PNS preview exposure stays in lineage, and current retrieved-source exposures are audited. No publication claim of unseen-population performance, valid individual imputation, improved clinical decisions, or universal workflow superiority follows from this unit.

Success for this pilot is informative evidence, not a required favorable result. Continue with the least complex effective procedure; stop adding mechanisms when gains are unsupported. All scientific output is evaluated only after the final global closure.
