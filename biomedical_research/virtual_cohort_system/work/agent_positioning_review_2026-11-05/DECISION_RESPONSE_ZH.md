# 对新一轮 Agent 定位建议的核查与取舍

2026-11-05（America/Chicago）。这是对用户提供评审的回应及下一步建议，不是新实验协议冻结，也不自动启动12次构造、改变历史结果或重写已有方法声明。

## 建议采纳的主线

**研究一个能够从发表证据和研究需求构造可分析虚拟数据的科学 Agent 系统。** Agent 的证据解释、统计推导、模型选择和工具使用是研究对象；完整数据及生成程序是产物；生物医学提供真实任务与评价背景。无个体输入完整生成继续作为重点，指标扩展和缺失补全保留总体用途，但各自按实际验证范围陈述。

这与用户一直坚持的实际数据用途一致，也与当前实现更匹配。不需要先创造新的统计采样算法、训练模型或增加角色。我们仍需用生成数据的分析表现支撑用途，不把日志、字段、测试数或审计数量写成主要科研成果。

两类主张分开：

- 能力/系统主张：Agent 实际完成了哪些 evidence-to-data 工作，在什么信息条件和分析任务上有用途、在哪里失败。
- 方法增益主张：一种明确的决策策略是否改善最终数据、有效交付或实际人工工作。该主张才需要与有能力的通用 Agent 进行可解释的控制比较。

当前并不因为尚未证明第二类主张而失去第一类价值；也不能仅靠换名称或列出应用用途就获得充分的 Agent 研究贡献。

## 如何设置有意义的比较

当前旧流程本来就大量依靠通用科学 Agent。若“专门流程”与“普通Agent”只差内部记录格式，比较不能回答方法增益。因此，先写出实际处理差异，不机械执行评审建议的12次构造。

### 构造能力与取证策略是不同试验

固定共同evidence packet适合比较证据解释与建模；如果双方都不能获取新证据，就不能用这个设计检验“主动补取关键证据”的增益。

若要测试下一版行动策略，建议比较：

| 项目 | 有能力的自由Agent | 分析需求驱动的Agent策略 |
|---|---|---|
| 基础模型、host、初始证据、用户问题 | 相同 | 相同 |
| 可用来源池、计算与获取工具 | 相同 | 相同 |
| 总调用/时间/查询/下载预算、修复和review机会 | 相同且完整记账 | 相同且完整记账 |
| 科学自由度 | 可自主规划、识别缺口、搜索、写代码、检验和修复 | 同样自由；显式将关键缺口、分析影响和下一动作连接起来 |
| 差别 | 自行决定信息获取与建模优先次序 | 使用已实现并冻结的用途/缺口行动策略；影响度分析若尚未实现不能写入处理定义 |
| 输出与评价 | 相同的最低数据/生成器/来源说明契约 | 同一契约；内部额外表单不形成基线失败条件 |

不禁止通用Agent自行采用相同的聪明策略。如果它也这样做，这是实际行为重合，应如实记录，不能故意削弱基线。研究者或外部reviewer的帮助属于预算和干预，不算免费资源。机械格式适配与改变科学建模的帮助分别记账。

两请求×两策略×三独立构造=12次构造、每构造三seed=36最终表，是可考虑的开发pilot规模，不是已冻结或已运行计划。三次构造估计不确定性仍大；seed不增加独立构造数。失败与未交付保留，避免只分析成功者。当前CHNS/ENSANUT已暴露，只能作为明确标注的开发比较。

## 主要终点仍然是数据用途

逐请求报告主要分析的效应幅度、所需联合/条件结构及波动；同时报告可执行且可分析的交付率、来源误用/数学错误、实际成本和人工干预。不同效应单位不随意相加为总分；不能只报方向或输入约束匹配。参照抽样不确定性和real–real variation用于解释，不能事后成为合格线。

检查“关键动作真的改变了什么”是解释机制：例如补充表给出带调整集的有符号系数，Agent于是修正参数映射，而非只写更多说明。最终数据改善但同时额外读更多材料/得到专家帮助，应归因于那个完整条件，不能声称纯策略收益。无增益时保留原简单方法，不强制产生修订或拒绝来制造成功。

## 具体顺序

1. **先明确处理差异并做一个补证据可行性检查。** 已有两个明确附表入口；新版本任务应在同一总预算内预留补取额度，使用既有补充材料工具，绑定来源版本。先确认附表是否提供会改变建模的统计对象，不开展广泛新队列搜索或无界阅读。
2. **有实质差异和可用信息后再冻结小对照。** 固定packet只测构造；允许同预算取证的比较才测取证策略。不能把两者混写。
3. **冻结后测试新请求结构。** 纵向配对任务有辨识力，但须先确认发表证据足够。新任务可以来自已有队列，但要记录人群、变量、关系和历史暴露；已看过其决定性答案就不能称真正未见任务。只有声称未见人群迁移时，才相应要求未暴露人群验证。

新任务评价脚本可由研究者编写；关键生成分布、关系、参数和修订应由Agent自主提出。用既有数据扩展任务比不断获取新队列更贴近当前核心，但不能把定制研究者建模包装成适配。

## 近邻与投稿核查

G-Sim已有LLM结构设计、校准和诊断修订，其框架也讨论稀疏/聚合观测；这不等于已经验证了我们的异质发表证据任务。[ICML正式页面](https://proceedings.mlr.press/v267/holt25b.html)、[原文](https://arxiv.org/html/2506.09272v1)。LLMSynthor v4明确含变量依赖推断、宏观约束扩展及差异引导生成，不能把简单“寻找缺失依赖”本身作为唯一差异。[原文§3](https://arxiv.org/html/2505.14752v4)。

建议聚焦的差异是：按用户分析要求，在不同研究的人群、测量、筛选及调整条件下解释证据，将报告统计、合法推导和未确定关系落实为生成选择及下一步行动。需要过程与最终结果共同证明，这不是当前已经确证独有的能力。

TMLR官方标准重视主张与证据及对研究者的有用认识，不要求新SOTA或新算法，因此系统/实证定位有可讨论的匹配；它是期刊，不是顶会，不能据此预测录用。[官方标准](https://jmlr.org/tmlr/acceptance-criteria.html)。AAMAS的Generative and Agentic AI范围包含工作流、工具、恢复及评价，同时要求明确Agent贡献。[官方范围](https://warwick.ac.uk/fac/sci/dcs/aamas2027/calls/call-for-main-track/)。

截至2026-11-05，AAMAS 2027主会完整论文截止为2026-10-08，ICLR 2027为2026-09-25，均已过去；是路线匹配而不是当前开放入口。[AAMAS日期](https://warwick.ac.uk/fac/sci/dcs/aamas2027/calls/call-for-main-track/)、[ICLR日期](https://iclr.cc/Conferences/2027/CallForPapers)。本轮没有核定下一届或ICML/NeurIPS未来截止，不作猜测。Nature Communications不是凭Agent标签或增加两个案例即可支撑的近期承诺。
