## 2. 三个仍未落地的关键能力

1. **重要性决定预算。** [`evidence_actions_v1.py`](../../cohort_harness/evidence_actions_v1.py) 第 100–136 行按作者提供的卡片顺序分配估计额度，仅对完全相同的 `(tool, request)` 共享估计；没有 estimand 敏感度、信息价值、预期质量收益或成本收益排序。科学 Agent 可以写出优先顺序，但本次没有检验“为何这个排序更好”。66 张卡、120 个维度级缺口不能当作 66 个动作或方法效能。
2. **真正补检索及修订。** 同一代码第 145–155 行明确保留 `gap_status: unresolved`、`executed: false`、`budget_reserved: false`、`retrieval_executed: false`、`candidate_modified: false`。18 个检索提案全部因旧任务关闭而被阻止。本地 E02 补提取是单独完成的动作，不是路由器执行回执。新控制器、真实 gateway 再检查、累计预算、第二证据包、证据再判断及候选绑定仍需实现，见[接口文档](../../docs/EVIDENCE_ACTIONS_V1.md)第 35–43 行。
3. **保持约束的敏感性决策。** `scenario_review` 目前只提出审查，不创建情景、不求解联动参数，也不验证情景仍兑现接纳约束。现有模型的解析值与旧输出相符，是实现/归因检查；个别代数敏感性不等于已建成任务敏感度驱动策略。若未来改变 predictor dependence，必须联动重解相关回归项/残差项并检查可行性，不能固定其余参数后把违反来源约束的变化当作有效情景。若来源约束本身冲突，先说明接纳哪一情境；不能要求精确保持全部不兼容数字。

E02 新提取尤其不可过度解释：复核明确为 sample 2（387 人）中依赖 HbA1c/血糖定义的 HGI 组；不能与 sample 1（2,055 人）的预测方程视作同一分析样本，也不能改名为年龄/性别/BMI/血糖条件残差 SD。

## 3. 公平比较需要先确定可操作差异

评审对强通用 Agent 的要求合理。两组都应得到同一基础模型/版本、请求、初始证据、工具、总预算、执行与修复机会和同等外部 review。通用组允许自行计划、构造模型、诊断和修订，也允许自发做缺口分析；不能禁止它采取“ours”提出的合理动作。以公共可分析产物、科学错误、最终用途、可观察工具行为及外部干预评价；不能因其未输出内部 ledger 格式而判失败。额外研究者解释或代码修复必须对称且记账。

需要明确区分两个问题：

- **相同固定 evidence packet 的比较**只能检验构造/使用证据的差异；它不能证明检索优先级或动态补证据的增益。
- **行动机制比较**应给两组相同初始 packet、相同可访问来源和累计预算，比较通用 Agent 自主处理与显式任务影响度策略。若策略只增加表单，或普通 Agent 本来就是相同流程，就不存在值得包装成方法优势的处理差异。

12 次 construction / 36 张表可作开发性 pilot，但 3 个 seed 只反映一个固定生成器的抽样变化，不能扩充独立 Agent 样本量；每请求每条件 3 次构造也不支持广泛泛化或小效应稳定性结论。先预设有意义的改善与停止规则，避免看完结果再选成功指标。成本必须包含 Agent 推理、工具、失败尝试、检索、review 和人工干预，不能用生成器运行时间替代。冻结任务提示、环境、可观察动作和干预记录即可，无需内部 chain-of-thought。

## 4. 建议的下一个有界实验及停止规则

**先做一次来源动作可行性试点，再做最小对照；这是对评审次序的缩小，而非否定其比较目标。** 当前已知入口和质量瓶颈使这个门槛比立即全量生成更有信息价值。

1. 在新版本任务中只选一个明确请求与关键关系，例如 E01 的 BMI 调整关联；只核查已定位的 Skogberg Additional file 3 的 S1/S2 表。预先写出所需变量角色、单位、调整集、符号、估计值/不确定性与何种信息会改变生成依据。暂不扩展整个来源集或增加新队列。旧四任务保持关闭；新任务采用预先冻结的累计预算和一次补取窗口，不能给旧任务另加免费额度。
2. 通过已存在的补充材料能力完成一次真实取得/抽取/独立语义核对；结果写入新 packet 版本。只根据来源信息判断能否约束请求所需关系，不依据已知目标误差选择数值。不取得有用信息时允许限定用途或保留明确假设。
3. **门槛通过才冻结一个对照 pilot。** 先落实两组真正的操作差异；若先比较构造，向两组提供相同完整新 packet。若检验任务驱动检索，向两组提供相同初始 packet 与获取机会，把来源取得差异视作策略后果。不得把其中一种实验的结论换名为另一种。使用已揭示案例仍是开发实验；需要后续冻结方法的新任务才能检验适配。

预先停止/简化：附表不含所需关系，或含有但上下文不适用且无法作出可信转换；约束保持后请求量几乎不变；两组实际执行策略无区别；增量只有记录长度/格式；更精确兑现输入值却没有新增用途；必须利用目标结果才能选择情景。满足任一对应条件时，停止该机制投入或收缩主张，不为产生修订而更换参数。若公平对照无质量、错误、成本或干预收益，撤回专门策略优势；保留证据支持的能力、失败机制与边界贡献。

## 5. 对评审结论的具体取舍

- **保留：** 无需新统计发明；summary specification 是合法任务输入；真正研究对象可以是 Agent 的证据解释和程序构造；生成器重放与 Agent 构造过程复现须区分；最终数据效果不能被日志数量替代。
- **更新：** “把缺口用于行动”已不再全是设想，已有声明/路由/本地动作原型；但不能因此把评审主张的高价值闭环写成已完成。
- **收窄：** “第一项实际工作就是完成 12 次构造”不是当前唯一合理次序。先确定策略差异并通过一个真实证据动作门槛；若两组无区别，直接写能力与实证贡献，不制造弱 baseline。
- **不据此宣称：** 35 项程序测试证明科学有效；局部补提取已识别关键联合关系；更多案例/生成行自动构成强 Agent 方法；本轮已经能推荐确定投稿结果或当前开放截止时间。

本轮只新增本备忘录；没有复跑已有测试或生成实验。测试和回放结果均明确引用已有独立审查，未冒充此次重新执行。
