# Scientific uses of the final virtual cohorts

Companion to the [v0.13.1 manuscript](DRAFT_v0_13_1.md), 4 November 2026.

We evaluate the table a researcher receives. For each requested analysis, run the specified model on the final virtual tables, report the estimate in its original units, and interpret it against the available scientific reference and its sampling variability. Record which summaries the Agent could see during construction. Agreement with supplied summaries measures reconstruction. Comparisons with other measurements assess how those relationships carry over.

| Scientific question | What the final tables show | Scope of use |
|---|---|---|
| Can they recover an adjustment pattern? | Across all six final ENSANUT draws from two constructions, the BMI coefficient for HbA1c decreased when glucose was added to the age- and sex-adjusted analysis. The selected sample reference showed the same attenuation. | The tables supported the interpretation of this adjustment in this case. The conditional effect sizes varied across constructions. |
| Do they reproduce the spread of HbA1c around the fitted regression? | In the cross-sectional ENSANUT study, residual HbA1c RMS averaged 0.295 and 0.324 across draws for the two authors, against 0.488 in the selected sample. | These tables underestimate residual spread relative to this sample. Power and interval coverage require evaluation for those specific uses. |
| Can they represent relationships together? | In the CHNS summary-assisted experiment, researchers could fit three adjusted regressions and estimate two correlations on each final table. The R constructors had access to 30 target summaries. | This setting measures joint reconstruction from supplied information. The external-evidence experiments address a different information setting. |

**Priority if extending the study.** Freeze the population request, evidence access and intended analyses before comparison with a previously unexposed real reference. Evaluate the final tables for effect direction, magnitude and any dispersion or joint property the intended analyses depend on. Report the reference's sampling uncertainty and every prespecified result. The historical real–real comparison provides descriptive context within CHNS.

**Optional sensitivity analysis.** If a particular use relies on an unreported joint relationship, hold the available evidence fixed and vary that assumption over a prespecified set. Report how the scientific conclusion changes across the full set. The existing BMI–glucose example already illustrates this use.

The method records the model delivered after its quality checks. In the latest experiment, all four constructors retained their initial laws. The empirical endpoints come from the twelve final tables. Scientific author review and venue preparation can proceed using these completed results.
