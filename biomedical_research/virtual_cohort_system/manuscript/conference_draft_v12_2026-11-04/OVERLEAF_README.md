# Overleaf reading draft v0.12

Select LuaLaTeX and compile paper.tex. The archive includes five original vector figures. This is a generic two-column reading layout, not an official submission template. No individual records or third-party papers are included.

Compilation was verified locally. Remote Overleaf compilation has not been tested; fonts and pagination may differ. Fonts fall back to TeX Gyre when Times New Roman, Arial or Courier New are unavailable. The PDF reading edition is available separately in the project repository.
