# Overleaf manuscript

Create a new project from this ZIP, select `paper.tex` as the main document, choose LuaLaTeX, and compile twice. The source uses the standard two-column ACM `acmart` class with `sigconf,review` options. All figure PDFs are included. Author details in the working copy require confirmation before submission. The local verifier compares page text and figure placement against a separate build from the ZIP.
