# Figure 1. System architecture for evidence-guided virtual cohorts

The diagram shows the implemented agent-authored program route. A coordinator dispatches an author with the task, admissible evidence and protocol budget. The author chooses the scientific model, writes the generator, and documents the evidence and assumptions. An isolated worker executes the bound version. Trial summaries and compatible source checks can inform a retain-or-revise decision. The coordinator selects and freezes the final artifact, samples the program at specified seeds, and seals the delivered tables. The evaluator receives the generated tables and a measured reference. The reference may consist of target records or previously computed estimates. The dashed two-way link indicates optional literature queries and returns. It is enabled only under the relevant study protocol.

The architecture describes roles implemented across the studies. Q4 used bounded agent-selected searches. Q5 supplied reviewed sources and optional retrieval. All 132 Q5 source comparisons were unavailable under their declared definitions. The iron study ran a source replay through its case adapter and sealed the virtual tables before target biomarker access. Fresh author sessions in several experiments produced separate models. Numerical execution takes place in the isolated worker. The host orchestrates access, trial versions, review, seeds and artifact closure.
