# Methods working draft v0.29

Upload this ZIP to Overleaf, select paper.tex and LuaLaTeX, and compile twice. This is a complete editable local package, not an already-created online project. The single-column reading edition has no imposed page limit and is not yet a verified conference-format submission.

The revision integrates completed fixed-packet API experiments and three request-only development rounds. It separates Agent scientific authorship, numerical sampling, auditable provenance and independent analytical evaluation. Earlier failures, unfavorable comparisons and exposure status remain visible. Whole-cohort generation is the evaluated main setting.

The current request-only comparison used the same GPT and shared tools in ordinary/workflow arms, without prepared evidence packets or target data. Its four final generators were authored by the model; no host relationship parameters were inserted. Sources and explicit assumptions can be inspected; traceability is not calibrated clinical confidence. Multi-model results belong to earlier, unbalanced fixed-packet pilots.

The package contains manuscript text and aggregate/vector figures only: no real/generated individual records, raw API logs, credentials or full third-party papers. Earlier frozen drafts and experimental artifacts are unchanged. Author/affiliation and submission declarations still require completion.
