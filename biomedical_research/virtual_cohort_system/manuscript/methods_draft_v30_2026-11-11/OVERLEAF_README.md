# Methods working draft v0.30

Upload this ZIP to Overleaf, select paper.tex and LuaLaTeX, and compile twice. This is a complete editable local package, not an already-created online project. The single-column reading edition has no imposed page limit and is not yet a verified conference-format submission.

The revision integrates completed fixed-packet API experiments, the earlier request-only development rounds, twelve fresh request-only constructions, and twenty-four dependent scientific-review sessions. It separates Agent scientific authorship, numerical sampling, auditable provenance and independent analytical evaluation. Earlier failures, unfavorable comparisons and exposure status remain visible. Whole-cohort generation is the evaluated main setting.

The repeated request-only comparison used the same GPT and shared tools in ordinary/workflow arms, without prepared evidence packets or target data. Its twelve final generators were authored by the model; no host relationship parameters were inserted. The later scientific-review study starts from those fixed generators and does not add independent initial constructors. Sources and explicit assumptions can be inspected; traceability is not calibrated clinical confidence. Multi-model results belong to earlier, unbalanced fixed-packet pilots.

All new figures are derived from saved aggregate outputs. No model calls, new virtual cohorts or new patient analyses were made for this editorial revision. The experimental references are previously exposed developmental samples, not newly held-out populations. The new manuscript corrects one old transcription of the DBP SD reference to 11.094; the underlying pinned analyses were already correct.

The package contains manuscript text and aggregate/vector figures only: no real/generated individual records, raw API logs, credentials or full third-party papers. Earlier frozen drafts and experimental artifacts are unchanged. Author/affiliation and submission declarations still require completion.
