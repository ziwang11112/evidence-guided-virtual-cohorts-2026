# ACM anonymous review layout

Set `paper.tex` as the main file, select LuaLaTeX and compile twice. The project uses the standard ACM `acmart` class with the `sigconf`, `anonymous` and `review` options. The archive contains the complete TeX source and nine figure PDFs. The appendix uses two columns, with figures and tables spanning both columns.

This is a locally prepared review draft. Bibliographic and declaration checks remain part of final submission preparation.
