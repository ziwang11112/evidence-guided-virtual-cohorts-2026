# Core story and evidence integration — 16 November 2026

Working integration, not a replacement for frozen manuscript v0.31. This document separates completed generation results from the lipid source-admission closeout. Scientific parameters, old tables and historical manuscript files remain unchanged.

## Main claim

A scientific Agent can turn a biomedical research request and permitted published evidence into a joint data-generating model and complete virtual records. The practical contribution is data that can be passed to familiar scientific analyses, with the evidence and assumptions underlying each use inspectable. Evidence coverage, rather than table size alone, limits which analyses are informative.

The present implementation lets the Agent search for missing evidence, choose structures and parameters, and author executable generation code. The harness supplies interfaces, isolated execution, immutable records and shared analysis. Root source-admission checking is still part of the demonstrated workflow; do not advertise fully automatic scientific verification. Ordinary Agent implementations are valid; universal workflow superiority is not the main claim.

### B. Establish that complementary evidence can be combined correctly

The 24-construction artificial pilot supplies none, one of two complementary records, or both. With both, generated author means for the identified adjusted correlation are 0.2211–0.2230 versus 0.21875, and longitudinal change correlations are −0.6013 to −0.5991 versus −0.6. All 90 identified primary/secondary estimates meet the frozen numerical tolerance. Incomplete-information scenarios are not scored as wrong merely because they differ from one possible completion.

The evidence demonstrates algebraic composition capability, not real-patient validity. Seventy-two table draws are nested within 24 model constructions, including duplicate numeric outputs. Preserve this distinction rather than inflating the experiment count.

Source: `work/evidence_composition_pilot_2026-11-16/RESULTS.md`.

### C. Show a biomedical benefit from filling a joint-evidence gap

In PNS, an actual search Agent found joint-source information from Burkina Faso and Ghana. After original-text and algebra checking, three fresh authors received the original packet and three received the augmented packet. All final tables used the same three scientific analyses. Residual-correlation mean absolute reference difference decreased from 0.17962 to 0.01277; author-mean correlation moved from 0.5376 to 0.7046, compared with the existing sample reference 0.7172. All augmented authors were closer on this endpoint than all original-packet authors.

BMI–DBP and DBP spread discrepancies narrowed, whereas BMI–SBP and SBP spread were less close. The added sources have different populations and adjustment sets, and all augmented target covariance choices remain assumptions. The result supports targeted use, not complete distribution recovery, identified transport or generalized Agent superiority. There were no feedback revisions in this experiment.

Source: `work/pns_joint_evidence_2026-11-16/RESULTS.md`.
