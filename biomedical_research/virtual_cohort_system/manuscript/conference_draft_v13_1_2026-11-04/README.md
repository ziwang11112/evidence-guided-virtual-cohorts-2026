# Evidence-Guided Agents for Analyzable Virtual Biomedical Cohorts

Reading draft v0.13.1, 4 November 2026.

The paper evaluates generated cohorts through prespecified scientific analyses. The appendix provides per-construction estimates and the inventory of source studies.

Upload `overleaf_v13_1.zip` to Overleaf, set `paper.tex` as the main file and select LuaLaTeX. Compile twice. The six figure PDFs are in `figures/`. The archive also includes the compiled reading copy for comparison. The source uses a two-column article layout and switches to one column for the supplementary material.
