completed two evidence structures. Engine snapshots, request hashes and all
selected committed artifacts were verified. This is implementation validation,
not a target accuracy experiment or a claim of scientific novelty.

## Revision checks execute actual models

FIT/Han's historical revision retains target baseline/weight rows and both
original native-source outputs under common seeds. Perturbing the supplied Han
slope by .01 changes target waist outputs, confirming that this input reaches
the actual target path. It does not establish correct transport or a new result.

The exercise Agent chose normal marginal response distributions with independent
within-arm residuals, nominal arm transfer and identity waist-change transfer.
These are declared Agent assumptions, not framework constants or identified
population laws. Source and target call the same response-sampling function.
Individual source SDs are not converted to standard errors. Baseline strata use
bounded beta marginals and a numerically calibrated Gaussian copula, chosen by
the Agent rather than prescribed by the common runner.

After additional DREW evidence, the Agent declined to equate a pooled,
incompletely specified association with target within-arm dependence. It left
the generator byte-identical. The engine verified all shared output columns
under common seeds, and numerical probes confirmed that the deferred input did
not enter sampling. Independence remains an unvalidated reference assumption;
the no-op does not prove it correct or establish generation benefit.

## Framework defects found and repaired

The first staging attempt filtered later checks but leaked a later coefficient
through global free-form notes. That attempt was interrupted before engine
execution and retained as aborted. A generic allowlist now stages only active
evidence, contexts/checks and explicitly stage-scoped notes. The fresh initial
builder used a new context. This is a documented implementation defect and
repair, not evidence that the first attempt was clean.

Input-use probes now compare categorical as well as numeric columns. A
`no_op` automatically checks every shared output column rather than trusting
optional declarations. Executed versions include local engine snapshots so
later software changes do not silently alter their provenance.

All 21 meaningful regression tests pass: numerical estimands, transforms,
undefined observations, evidence staging, immutable artifacts, failed runs,
invariants, no-op claims, input use and categorical behavior. These verify
software behavior; their number is not a measure of scientific quality.

## Remaining boundaries and next optimization

The controller is reusable, but the new build/update sample size is one task.
The other task replays historical programs. The same process must still be
tested on more evidence structures and later real analyses. No ordinary
statistics or capable no-record Agent comparator was run in this demonstration.

Current checks cover selected source quantities and global baseline moments.
They do not verify complete covariance, subgroup distributions or unprovided
relations. The exercise model represents empirical baseline covariance, while
adapter SD gates reference sample moments; the small declared convention
difference falls within the Monte Carlo tolerance and should become an explicit
estimand field in the next contract version. Input-use probes do not establish
correct effect magnitude, direction, specificity or scientific transport.

Optimize the shared scientific decision process next: how evidence changes
the proposed model components, how candidate structures are compared using
allowed diagnostics, and how unsupported relationships remain represented as
assumptions or scenarios. Compare that procedure with ordinary iteration using
the same information and computational budget across tasks. A strategy that
only keeps its initial model is not automatically useful; the no-op observed
here is a behavior to investigate, not a favorable performance endpoint.

Do not resume case-specific coefficient rescue or make one fixed model family
mandatory. Keep later real-target evaluation separate from the revision loop.
The framework remains an externally dispatched collaboration workflow, with
curator-assisted extraction and no standalone unattended model API service.
