Read this document, your assigned policy file, the three descriptive JSON/Markdown files and observed.csv in `shared/`, `runner_contract.json`, your own run folder, and approved artifacts in your own literature session only. Preserve each observed `row_id,bmi,age,sex` and generate an entirely unmeasured `hdl` column in mg/dL for the described target population. Produce useful virtual data for biomedical association analyses, including questions not answered explicitly by your input evidence. No expected sign, coefficient, correlation, shape, subgroup pattern or residual variance is supplied by the coordinator.

Choose the scientific structure and all parameters yourself. You may use applicable primary research, explicit transformations and clearly documented assumptions. The gateway screens before displaying content, including article references; record access limitations and never bypass a rejection.

Both workflows can identify problems, search for additional evidence, consider competing structures, revise and retain a justified no-op. Use your best scientific judgment. This is not a competition to produce a desired known effect.

# Consequential evidence-gap/action workflow

Follow the common construction contract, using the same tools, model freedom, total budget and initial/revision schedule as the ordinary workflow. Make the following decision process explicit and operational.

1. Map the evidence needed for intended analyses: conditional location/dependence, relationship shape, relevant modifiers, conditional variability, tails, source selection, measurement and target applicability. Mark irrelevant dimensions as such. Do not require a particular interaction, nonlinear term, sign or distribution merely because it is available.
2. Identify consequential gaps. Separate a usable reported constraint, an assumption-dependent bridge, contextual evidence and missing information. “Not reported” does not by itself establish zero, independence or a constant effect.
3. Rank follow-up actions by the analysis they could change and a concrete obtainable lead. Search for distinguishing evidence or supplements rather than merely adding articles. Where enough source context exists, check the candidate against the statistic under that source's population/measurement/adjustment conditions. If the operator cannot be computed, record that instead of fitting invented data as known.
4. Consider a focused scientific challenge: could another plausible model satisfy the current evidence while changing an intended interpretation? State what information would discriminate it. Do not adopt a more complex alternative merely because it exists; a finite sensitivity set is not a calibrated uncertainty interval.
5. Let evidence and review trigger a concrete action: retrieve, re-extract, check, revise, assess sensitivity, retain or stop with reasons. Distinguish individual residual variability from source population/measurement differences. Reassess previously supported components after a revision.

Required in both `initial/` and `final/`:

`gaps.json`: a nonempty list; each record has `id`, `component`, `affected_analysis`, `evidence_status`, `consequence`, `next_action`, `status`, `resolution`.

Allowed status values: `open`, `acted`, `resolved`, `unresolved`, `not_applicable`. Initial records may be open. Final records must have a non-open status and an explicit nonempty resolution. A resolution can state that evidence remains insufficient; it must not invent certainty.

`actions.json`: a nonempty list; each record has `gap_id`, `action`, `evidence_artifacts`, `model_change`, `reason`.

Allowed actions: `retrieve`, `reextract`, `source_check`, `revise`, `sensitivity`, `retain`, `stop`. `evidence_artifacts` uses run-relative path/hash objects from the actual gateway; a retrieval claim requires at least one real registered artifact. Link actions to gaps. State whether an action changed a parameter, structure, measurement assumption, analysis qualification, or nothing.

Use the review turn for the most consequential attainable correction within remaining budget. Limit countermodel exploration to a focused challenge and explain search saturation. Do not fill the records with decorative steps while leaving their implications unconsidered.

Primary performance concerns the generated data on every reserved analysis, regardless of your support labels. Better qualifications are a separate result; declining every analysis is not success. No source or target relationship is prescribed by this policy.

"""Versioned evidence -> initial generator -> review -> revision control.

Owns schemas, provenance, state transitions and numerical output contracts only.
No biological dependence or parameters are implemented here. Static source
checks are defense in depth, NOT an execution sandbox.
"""
from __future__ import annotations
import argparse
import ast
import copy
from datetime import datetime, timezone
import hashlib
import importlib.util
import json
from pathlib import Path
import time
import numpy as np
import pandas as pd


def sha(path):
    return hashlib.sha256(Path(path).read_bytes()).hexdigest()


def read(path):
    return json.loads(Path(path).read_text(encoding='utf-8-sig'))


def write_new(path, value):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open('x', encoding='utf-8') as stream:
        json.dump(value, stream, indent=2, ensure_ascii=True, allow_nan=False)
        stream.write('\n')


def now():
    return datetime.now(timezone.utc).isoformat()


def require(condition, message):
    if not condition:
        raise ValueError(message)


def checked_relative(root, relative):
    root = Path(root).resolve()
    path = (root / relative).resolve()
    require(path.is_relative_to(root), 'Path outside assigned run')
    return path


def validate_ledger(ledger):
    require(isinstance(ledger, dict) and isinstance(ledger.get('sources'), list) and ledger['sources'], 'Ledger needs nonempty sources list')
    require(isinstance(ledger.get('evidence'), list) and ledger['evidence'], 'Ledger needs nonempty evidence list')
    ids = [s.get('id') for s in ledger['sources']]
    require(all(isinstance(x, str) and x for x in ids) and len(ids) == len(set(ids)), 'Source IDs invalid')
    for source in ledger['sources']:
        for key in ['id', 'identifier', 'population', 'measurement', 'cohort_overlap', 'approved_artifacts']:
            require(key in source, 'Source field missing: ' + key)
        require(isinstance(source['approved_artifacts'], list) and source['approved_artifacts'], 'Approved source artifacts required')
    evidence_ids = []
    for item in ledger['evidence']:
        for key in ['id', 'source_id', 'locator', 'estimand', 'variables', 'adjustment', 'reported', 'uncertainty', 'applicability', 'model_use', 'bridge_assumptions']:
            require(key in item, 'Evidence field missing: ' + key)
        require(item['source_id'] in ids, 'Unknown source ID')
        require(isinstance(item['id'], str) and item['id'], 'Invalid evidence ID')
        evidence_ids.append(item['id'])
    require(len(evidence_ids) == len(set(evidence_ids)), 'Duplicate evidence ID')
    return set(ids), set(evidence_ids)


def validate_spec(spec, evidence_ids):
    parameters, provenance = spec.get('parameters'), spec.get('parameter_provenance')
    require(isinstance(parameters, dict) and parameters, 'Nonempty parameters dict required')
    require(isinstance(provenance, dict) and set(provenance) == set(parameters), 'Provenance keys must match parameter keys')
    assumptions = spec.get('assumptions')
    require(isinstance(assumptions, list), 'Assumptions list required')
    ids = []
    for assumption in assumptions:
        require(isinstance(assumption, dict) and isinstance(assumption.get('id'), str) and assumption['id'], 'Typed assumption ID required')
        require(isinstance(assumption.get('description'), str) and assumption['description'].strip(), 'Assumption description required')
        ids.append(assumption['id'])
    require(len(ids) == len(set(ids)), 'Duplicate assumption ID')
    for item in provenance.values():
        require(isinstance(item, dict), 'Typed parameter provenance required')
        for key in ['evidence_ids', 'assumption_ids']:
            require(isinstance(item.get(key), list), 'Provenance reference list required')
        require(item['evidence_ids'] or item['assumption_ids'], 'Parameter has no evidence or assumption link')
        require(set(item['evidence_ids']) <= evidence_ids, 'Unknown evidence reference')
        require(set(item['assumption_ids']) <= set(ids), 'Unknown assumption reference')
        require(isinstance(item.get('derivation'), str) and item['derivation'].strip(), 'Parameter derivation missing')


def gateway_registry(cfg):
    session = Path(cfg['literature_session'])
    state = read(session/'state.json')
    require(state['session_path'] == str(session.resolve()), 'Wrong literature session')
    require(state['config_sha256'] == sha(cfg['gateway_config']), 'Gateway config changed')
    data = (session/'audit.jsonl').read_bytes()
    registry = set()
    for line in data.splitlines():
        event = json.loads(line)
        if event.get('type') == 'artifact_approved' and event.get('status') == 'accepted':
            require(event.get('config_sha256') == state['config_sha256'], 'Wrong approved artifact config')
            artifact = event['artifact']
            p = checked_relative(session, artifact['session_relative_path'])
            registry.add((str(p), artifact['sha256']))
    return registry, {'session': str(session), 'config_sha256': state['config_sha256'],
        'audit_bytes': len(data), 'audit_prefix_sha256': hashlib.sha256(data).hexdigest(), 'usage': state['usage']}


def verify_gateway_snapshot(path):
    snapshot = read(path)
    data = (Path(snapshot['session'])/'audit.jsonl').read_bytes()
    require(len(data) >= snapshot['audit_bytes'] and hashlib.sha256(data[:snapshot['audit_bytes']]).hexdigest() == snapshot['audit_prefix_sha256'], 'Gateway audit history changed')


def validate_gaps(gaps, final=False):
    require(isinstance(gaps, list) and gaps, 'Gap policy requires nonempty gap records')
    ids = []
    for gap in gaps:
        for key in ['id', 'component', 'affected_analysis', 'evidence_status', 'consequence', 'next_action', 'status', 'resolution']:
            require(key in gap, 'Gap field missing: ' + key)
        require(gap['status'] in ['open', 'acted', 'resolved', 'unresolved', 'not_applicable'], 'Invalid gap status')
        require(isinstance(gap['id'], str) and gap['id'], 'Invalid gap ID')
        ids.append(gap['id'])
        if final:
            require(gap['status'] != 'open', 'Final gap requires explicit disposition')
            require(isinstance(gap['resolution'], str) and gap['resolution'].strip(), 'Final gap resolution required')
    require(len(ids) == len(set(ids)), 'Duplicate gap ID')


def validate_actions(actions, gaps, final=False):
    require(isinstance(actions, list) and actions, 'Gap policy requires action history')
    ids = {g['id'] for g in gaps}
    for action in actions:
        for key in ['gap_id', 'action', 'evidence_artifacts', 'model_change', 'reason']:
            require(key in action, 'Action field missing: ' + key)
        require(action['gap_id'] in ids, 'Action uses unknown gap')
        require(action['action'] in ['retrieve', 'reextract', 'source_check', 'revise', 'sensitivity', 'retain', 'stop'], 'Unsupported action')
        require(isinstance(action['reason'], str) and action['reason'].strip(), 'Action reason missing')
        require(isinstance(action['evidence_artifacts'], list), 'Evidence artifact list required')
        if action['action'] == 'retrieve':
            require(action['evidence_artifacts'], 'Retrieval claim requires actual artifact')
    if final:
        acted = {a['gap_id'] for a in actions}
        require(all(g['id'] in acted for g in gaps if g['status'] != 'not_applicable'), 'Final gap has no linked action or justified stop')


def source_check(path):
    """Conservative static check, followed by independent human/Agent review."""
    tree = ast.parse(Path(path).read_text(encoding='utf-8-sig'))
    allowed_imports = {'numpy', 'pandas', 'scipy', 'math', 'statistics', 'typing', '__future__'}
    blocked_names = {'open', 'exec', 'eval', 'compile', '__import__', 'input', 'breakpoint', 'getattr', 'setattr', 'globals', 'locals', 'vars'}
    blocked_attrs = {'read_csv', 'read_table', 'read_pickle', 'read_json', 'read_excel', 'read_parquet', 'to_csv', 'to_pickle', 'to_json', 'load', 'save', 'fromfile', 'tofile', 'memmap', 'read_text', 'read_bytes', 'write_text', 'write_bytes'}
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            require(all(x.name.split('.')[0] in allowed_imports for x in node.names), 'Unapproved import')
        if isinstance(node, ast.ImportFrom):
            require(node.level == 0 and (node.module or '').split('.')[0] in allowed_imports, 'Unapproved import-from')
        if isinstance(node, ast.Name):
            require(node.id not in blocked_names, 'Blocked dynamic/file function')
        if isinstance(node, ast.Attribute):
            require(not node.attr.startswith('__') and node.attr not in blocked_attrs, 'Blocked attribute/file access')
    require(any(isinstance(n, ast.FunctionDef) and n.name == 'generate' for n in tree.body), 'generate function missing')
    return {'static_check': 'pass', 'scope': 'Conservative AST checks; not a sandbox or proof of no side effects'}


def file_commitment(paths):
    return {str(Path(p).resolve()): sha(p) for p in paths}


def verify_commitment(manifest):
    for path, value in manifest.items():
        require(Path(path).is_file() and sha(path) == value, 'Committed file changed: ' + path)


def init(run, policy, observed, contract, protocol):
    run = Path(run).resolve()
    require(policy in ['ordinary', 'gap_policy'], 'Invalid policy')
    require(not (run/'run.json').exists(), 'Run already initialized')
    tool_dir = Path(__file__).resolve().parent/'tools'
    study = tool_dir.parent
    prompt_paths = [study/'BUILDER_GUIDE.md', study/'policies'/f'{policy}.md', run/'REQUEST.md', study/'shared/schema.json', study/'shared/target_description.md']
    write_new(run/'run.json', {'created_utc': now(), 'policy': policy, 'observed': str(Path(observed).resolve()),
        'contract': str(Path(contract).resolve()), 'protocol': str(Path(protocol).resolve()),
        'literature_session': str(run/'literature'), 'gateway_config': str(tool_dir/'gateway_config.json'),
        'commitment': file_commitment([observed, contract, protocol, __file__, tool_dir/'literature_gateway.py', tool_dir/'gateway_config.json'] + prompt_paths)})


def freeze_candidate(run, version):
    run = Path(run).resolve()
    require(version in ['initial', 'final'], 'Invalid version')
    cfg = read(run/'run.json')
    verify_commitment(cfg['commitment'])
    if version == 'final':
        require((run/'review_receipt.json').exists(), 'Final submission requires prior review')
        verify_commitment(read(run/'initial/freeze.json')['commitment'])
        verify_commitment(read(run/'review_receipt.json')['commitment'])
        verify_gateway_snapshot(run/'initial/gateway_snapshot.json')
    folder = run/version
    files = [folder/x for x in ['generator.py', 'model_spec.json', 'evidence.json', 'decision.md']]
    require(all(p.is_file() for p in files), 'Missing candidate artifact')
    ledger = read(folder/'evidence.json')
    _, evidence_ids = validate_ledger(ledger)
    source_check(folder/'generator.py')
    spec = read(folder/'model_spec.json')
    validate_spec(spec, evidence_ids)
    registry, snapshot = gateway_registry(cfg)
    linked = []
    for source in ledger['sources']:
        for artifact in source['approved_artifacts']:
            p = checked_relative(run, artifact['path'])
            require('approved' in p.parts and p.is_file() and sha(p) == artifact['sha256'], 'Invalid approved evidence commitment')
            require((str(p), artifact['sha256']) in registry, 'Evidence artifact not registered by gateway')
            linked.append(p)
    if cfg['policy'] == 'gap_policy':
        gaps = read(folder/'gaps.json')
        validate_gaps(gaps, final=version == 'final')
        files.append(folder/'gaps.json')
        actions = read(folder/'actions.json')
        validate_actions(actions, gaps, final=version == 'final')
        files.append(folder/'actions.json')
        for action in actions:
            for artifact in action['evidence_artifacts']:
                p = checked_relative(run, artifact['path'])
                require('approved' in p.parts and p.is_file() and sha(p) == artifact['sha256'], 'Action evidence artifact invalid')
                require((str(p), artifact['sha256']) in registry, 'Action artifact not registered by gateway')
                linked.append(p)
    if version == 'final':
        revision = read(folder/'revision.json')
        require(isinstance(revision.get('reason'), str) and revision['reason'].strip(), 'Revision/no-op reason required')

"""External aggregate-evidence HDL generator; no target outcome fitting."""

import numpy as np
import pandas as pd


def generate(observed: pd.DataFrame, evidence: dict, seed: int) -> pd.DataFrame:
    """Return observed fields unchanged and a locally seeded positive HDL draw.

    The evidence argument is model_spec.json, containing a parameters mapping.
    The function does not read files, fit to the supplied cohort, or mutate input.
    """
    p = evidence["parameters"]
    required = ["row_id", "bmi", "age", "sex"]
    if not all(column in observed.columns for column in required):
        raise ValueError("Missing required observed column")
    result = observed.loc[:, required].copy(deep=True)
    bmi = observed["bmi"].to_numpy(dtype=float)
    age = observed["age"].to_numpy(dtype=float)
    sex = observed["sex"].to_numpy()
    if not (np.isfinite(bmi).all() and np.isfinite(age).all()):
        raise ValueError("Observed BMI and age must be finite")
    if not ((bmi > 0).all() and np.isin(sex, [1, 2]).all()):
        raise ValueError("BMI must be positive and sex must be 1 or 2")

    bmi_knots = np.asarray(p["bmi_knots"], dtype=float)
    age_knots = np.asarray(p["age_knots"], dtype=float)
    age_effects = np.asarray(p["age_contrasts"], dtype=float)
    age_counts = np.asarray(p["source_age_counts_by_bmi"], dtype=float)
    age_center = (age_counts @ age_effects) / age_counts.sum(axis=1)
    age_effect = np.interp(age, age_knots, age_effects)
    mean = np.empty(len(result), dtype=float)
    log_variance = np.empty(len(result), dtype=float)
    for code, label in ((1, "male"), (2, "female")):
        selected = sex == code
        source_mean = np.asarray(p["source_hdl_means"][label], dtype=float)
        source_n = np.asarray(p["source_cell_counts"][label], dtype=float)
        source_se = np.asarray(p["source_mean_standard_errors"][label], dtype=float)
        source_sd = source_se * np.sqrt(source_n)
        # Convert arithmetic mean and SD to the exact lognormal variance.
        anchor_log_variance = np.log1p((source_sd / source_mean) ** 2)
        centered_means = source_mean - age_center
        mean[selected] = np.interp(bmi[selected], bmi_knots, centered_means)
        mean[selected] += age_effect[selected]
        # Cross-sectional obesity slope supplies the local additive tail derivative.
        excess = np.maximum(bmi[selected] - bmi_knots[-1], 0)
        mean[selected] *= np.exp(
            p["tail_additive_slope"] * excess / mean[selected]
        )
        log_variance[selected] = np.interp(
            bmi[selected], bmi_knots, anchor_log_variance
        )
    if not (np.isfinite(mean).all() and (mean > 0).all()):
        raise ValueError("Model conditional mean is not finite and positive")
    rng = np.random.default_rng(seed)
    standard_normal = rng.standard_normal(len(result))
    result["hdl"] = np.exp(
        np.log(mean) - log_variance / 2
        + np.sqrt(log_variance) * standard_normal
    )
    return result

# Final model decision: ordinary_1

The conditional lognormal generator retains the initial Taiwan Biobank sex-by-BMI mean anchors, age-centering construction and source-derived variability proxy. The numerical revision replaces its longitudinal percentage tail with a cross-sectional additive obesity slope. No target outcome or generated target cohort was inspected to select this change.

## Review F1: directly relevant cross-sectional tail evidence

Two additional gateway searches identified L2020 (PMC7644056), a study of 1,214 Italian overweight/obesity clinic patients. Its main Table 2 gives an HDL-on-BMI coefficient of -0.42 mg/dL per BMI unit (95% CI -0.53 to -0.32), adjusted for age and sex. More specifically, the published author response embedded in the approved JATS contains Table rev2 for patients with BMI>30: coefficient -0.33 (95% CI -0.47 to -0.20), with the same adjustment. This is a separate subgroup analysis in the publication correspondence, not a main-text coefficient, a downloaded DOCX table, or an independent second cohort. All numbers were read from the gateway-approved complete article text/XML; no external supplement or individual data was accessed.

The final model uses -0.33 as the right derivative of the conditional arithmetic HDL mean at BMI30.5, common to men and women. Let m0 be the sex- and age-specific mean at that anchor. Beyond it, m=m0*exp(-0.33*(BMI-30.5)/m0). This retains a positive mean and preserves the source slope locally. It does NOT reproduce a fitted source linear model across the entire range: exponential curvature is assumed. The initial sex-specific longitudinal percentage slopes remain only a comparator, not final parameters. This removes the change-from-within-person-to-between-person bridge while leaving transport and curve-shape bridges unresolved.

L2020 is selected and not target matched. It excludes medications, diabetes and several diseases, is from Italy, and includes ages as young as14. Table1 reports BMI25-64.60; target predictor support extends beyond that. Several Table1/prose age, sex-count and BMI-range entries differ slightly. No numerical correction is invented; no model parameter uses those discrepant summaries. The subgroup n is unavailable. Its slope confidence interval is sampling uncertainty within the source, not a bound on target transport. Flat-tail, original longitudinal-tail, source-CI slope and linear-tail alternatives are evaluated on invented inputs only.

## Review F2: retained anchor and age assumptions

The original G2019 (PMC6627528) Table2 sex-by-BMI means are category averages, not exact-BMI conditional means. Knots17,21.25,25.5,30.5 are assumed representatives; only the two closed-bin knots are midpoints of published boundaries. The source has no registered supplements (gateway list-supplements returned an empty list), and no retrieved evidence identifies within-bin BMI distributions or joint sex-by-age-by-BMI cells. Its Table3 age effects also adjust for lifestyle, WHR and body fat, unlike the generated model.

The current means and modest common age pattern are retained because no available replacement identifies the missing joint information more directly. Final checks vary representative BMI values and remove age effects; these reveal sensitivity, not identify a preferred alternative. The source-age centering identity is an algebraic identity at assumed representatives only. It does not demonstrate reproduction of actual source within-bin distributions. No conditional age/sex interaction is inferred from pooled margins, and a printed overlap in source age-bin boundaries remains disclosed.

G2019 SEM*sqrt(n) correctly recovers approximate individual SD under the usual independent-mean formula. The resulting SD remains a broad-cell marginal SD, not a residual SD conditional on exact BMI, age and sex. The final model retains it as an explicit variability proxy; lognormal shape, source-derived CV with age and the extreme BMI tail, and independent participant residuals remain assumptions. Repeated random draws quantify Monte Carlo variation under the fixed scenario, not source or transport uncertainty.

L2020's overall HDL48.35+/-12.47 mg/dL is a mixed-sex, mixed-predictor mean and SD. It is not substituted for conditional spread. That study used overnight-fasting plasma lipids measured by automated colorimetry (Hitachi/Boehringer Mannheim); this does not establish calibration to the target direct-serum Roche method. G2019's exact HDL assay remains unspecified in its retrieved maintext. Final checks include SD multipliers0.75/1.25 and a matched-mean/matched-variance gamma alternative. These are deliberately illustrative model choices with no evidence-based uncertainty coverage.

"""Literature-anchored stochastic HDL model; no target HDL information is used."""
import numpy as np
import pandas as pd


def conditional_moments(observed: pd.DataFrame, evidence: dict):
    p = evidence["parameters"]
    bmi = observed["bmi"].to_numpy(dtype=float)
    age = observed["age"].to_numpy(dtype=float)
    sex = observed["sex"].to_numpy()
    knots = np.asarray(p["bmi_anchor_kg_m2"], dtype=float)
    age_effect = np.interp(age, p["age_knots_years"], p["age_effect_mg_dl"])
    age_effect = age_effect - p["age_center_mg_dl"]
    means = np.empty(len(observed), dtype=float)
    sds = np.empty(len(observed), dtype=float)
    for code in (1, 2):
        selected = sex == code
        key = str(code)
        m = np.asarray(p["mean_hdl_by_sex"][key], dtype=float)
        s = np.asarray(p["sd_hdl_by_sex"][key], dtype=float)
        b = bmi[selected]
        location = np.interp(b, knots, m)
        upper = b > knots[-1]
        floor = p["tail_asymptote_by_sex"][key]
        location[upper] = floor + (m[-1] - floor) * np.exp(
            -p["tail_decay_per_bmi"] * (b[upper] - knots[-1])
        )
        means[selected] = location + age_effect[selected]
        sds[selected] = np.interp(b, knots, s)
    return means, sds


def generate(observed: pd.DataFrame, evidence: dict, seed: int) -> pd.DataFrame:
    """Return one positive HDL draw, preserving observed values and row order."""
    required = ["row_id", "bmi", "age", "sex"]
    if not all(c in observed.columns for c in required):
        raise ValueError("Missing required observed column")
    if not observed["sex"].isin([1, 2]).all():
        raise ValueError("Sex must use codes 1 and 2")
    values = observed[["bmi", "age"]].to_numpy(dtype=float)
    if not np.isfinite(values).all() or (values <= 0).any():
        raise ValueError("BMI and age must be finite and positive")
    mean, sd = conditional_moments(observed, evidence)
    if (mean <= 0).any() or (sd <= 0).any():
        raise ValueError("Specification implies invalid conditional moments")
    log_variance = np.log1p((sd / mean) ** 2)
    log_location = np.log(mean) - log_variance / 2
    rng = np.random.default_rng(seed)
    out = observed.loc[:, required].copy(deep=True)
    out["hdl"] = rng.lognormal(log_location, np.sqrt(log_variance))
    return out

def taylor_fit(X, y, domain, spine):
    """WLS and stratified-PSU Taylor sandwich with zero scores outside domain."""
    X, y = np.asarray(X, float), np.asarray(y, float)
    require(X.ndim == 2 and y.shape == (len(X),), "Bad fit dimensions")
    require(np.isfinite(X).all() and np.isfinite(y).all(), "Nonfinite fit inputs")
    rank = np.linalg.matrix_rank(X)
    require(rank == X.shape[1], "Rank-deficient frozen model")
    w = number(domain, "weight")
    require((w > 0).all(), "Nonpositive domain weight")
    w = w/w.mean()
    pairs = spine[["stratum", "psu"]].drop_duplicates()
    counts = pairs.groupby("stratum").size()
    require((counts >= 2).all(), "Singleton full-spine stratum")
    bread = X.T @ (w[:, None]*X)
    inverse = np.linalg.inv(bread)
    beta = np.linalg.solve(bread, X.T @ (w*y))
    scores = (w*(y-X@beta))[:, None]*X
    names = [f"score_{i}" for i in range(X.shape[1])]
    tagged = domain[["stratum", "psu"]].reset_index(drop=True).copy()
    tagged[names] = scores
    totals = tagged.groupby(["stratum", "psu"])[names].sum().reindex(pd.MultiIndex.from_frame(pairs), fill_value=0)
    meat = np.zeros_like(bread)
    for _, group in totals.groupby(level="stratum"):
        values = group.to_numpy()
        centered = values-values.mean(axis=0)
        meat += len(values)/(len(values)-1)*(centered.T@centered)
    covariance = inverse@meat@inverse
    covariance = (covariance+covariance.T)/2
    domain_pairs = domain[["stratum", "psu"]].drop_duplicates()
    design_df = len(domain_pairs)-domain_pairs.stratum.nunique()
    residual_df = design_df-(rank-1)
    diagnostics = {"full_spine_n": len(spine), "domain_n": len(domain),
                   "full_strata": int(pairs.stratum.nunique()), "full_psus": len(pairs),
                   "domain_strata": int(domain_pairs.stratum.nunique()), "domain_psus": len(domain_pairs),
                   "design_df": int(design_df), "residual_df": int(residual_df), "rank": int(rank)}
    return beta, covariance, diagnostics

def contrast(beta, covariance, c, df):
    c = np.array(c, float)
    estimate = float(c@beta)
    variance = float(c@covariance@c)
    require(variance >= -1e-9, "Negative contrast variance")
    se = float(np.sqrt(max(0, variance)))
    margin = float(t.ppf(.975, df))*se if df > 0 else None
    return {"estimate": estimate, "standard_error": se,
            "ci95_low": estimate-margin if margin is not None else None,
            "ci95_high": estimate+margin if margin is not None else None,
            "df": int(df)}

def analyze(observed, y, domain, spine, spec):
    y = np.asarray(y, float)
    require(y.shape == (len(observed),) and np.isfinite(y).all() and (y > 0).all(), "Bad HDL vector")
    fits, endpoints = {}, []
    for name, X in matrices(observed).items():
        beta, covariance, diag = taylor_fit(X, y, domain, spine)
        fits[name] = {"coefficients": beta.tolist(), "covariance": covariance.tolist(), "diagnostics": diag}
        for endpoint in spec["endpoints"]:
            if endpoint["model"] == name:
                endpoints.append({"endpoint": endpoint["name"], "model": name, "role": endpoint["role"],
                                  **contrast(beta, covariance, endpoint["contrast"], diag["residual_df"])})
    w = number(domain, "weight")
    w = w/w.sum()
    mean = float(w@y)
    sd = float(np.sqrt(w@((y-mean)**2)))
    order = np.argsort(y, kind="stable")
    cumulative = np.cumsum(w[order])
    quantiles = {str(q): float(y[order][min(np.searchsorted(cumulative, q, side="left"), len(y)-1)]) for q in [.1, .5, .9]}
    b = number(observed, "bmi")
    bc, yc = b-w@b, y-mean
    denominator = float(np.sqrt((w@(bc*bc))*(w@(yc*yc))))
    corr = float((w@(bc*yc))/denominator) if denominator > 0 else None
    return {"endpoints": endpoints, "fits": fits,
            "distribution": {"weighted_mean": mean, "weighted_sd_population": sd,
                             "weighted_quantiles_inverse_cdf": quantiles, "weighted_bmi_correlation": corr}}

def validate_release(release):
    require(release.get("all_four_constructions_frozen") is True, "Missing all-four freeze assertion")
    require(release.get("root_authorized_evaluation") is True, "Root has not authorized evaluation")
    require(release.get("no_builder_access_to_target") is True, "Missing blinding assertion")
    require(release.get("analysis_spec_sha256") == sha(BASE/"analysis_spec.json"), "Analysis spec mismatch")
    require(release.get("evaluator_sha256") == sha(__file__), "Evaluator mismatch")
    entries = release.get("outputs", [])
    require(len(entries) == 40, "Expected 4 constructions x 2 stages x 5 draws")
    keys = [(e["construction"], e["stage"], e["draw"]) for e in entries]
    require(len(set(keys)) == 40, "Duplicate output slot")
    constructions = sorted(set(e["construction"] for e in entries))
    require(len(constructions) == 4, "Expected four constructions")
    arms = {}
    for construction in constructions:
        group = [e for e in entries if e["construction"] == construction]
        require({e["stage"] for e in group} == {"initial", "final"}, "Missing stage")
        require(len({e["arm"] for e in group}) == 1, "Conflicting arm")
        arms[construction] = group[0]["arm"]
        for stage in ["initial", "final"]:
            require({e["draw"] for e in group if e["stage"] == stage} == {1, 2, 3, 4, 5}, "Missing draw")
    require(list(arms.values()).count("ordinary") == 2 and list(arms.values()).count("gap_policy") == 2, "Require two constructions per arm")
    for entry in entries:
        require(sha(safe_path(entry["file"])) == entry["sha256"], "Generated output hash mismatch")
    validate_provenance(release, entries)
    return entries

def run(release_path):
    release = json.loads(Path(release_path).read_text(encoding="utf-8"))
    entries = validate_release(release)
    frozen = json.loads((BASE/"locked/freeze_manifest.json").read_text())
    for item in frozen["files"]:
        require(sha(safe_path(item["path"])) == item["sha256"], "Frozen custodian packet changed")
    observed = read_csv(PILOT/"shared/observed.csv")
    valid_observed(observed)
    generated = [(entry, match_generated(observed, read_csv(safe_path(entry["file"])))) for entry in entries]
    # Reference and design are read only after the release and every output pass.
    reference = read_csv(BASE/"locked/reference.csv")
    truth = match_generated(observed, reference)
    spine = read_csv(BASE/"locked/design_spine.csv")
    require(spine.design_id.is_unique, "Duplicate design ID")
    require((number(spine, "weight") > 0).all(), "Nonpositive full-spine weight")
    target_spine = spine[spine.in_target_domain == "1"].copy()
    require(target_spine.row_id.is_unique and set(target_spine.row_id) == set(observed.row_id), "Domain/spine mismatch")
    require((spine.loc[spine.in_target_domain == "0", "row_id"] == "").all(), "Unexpected out-of-domain row key")
    require(spine[["stratum", "psu"]].ne("").all().all(), "Missing design code")
    domain = target_spine.set_index("row_id").loc[observed.row_id].reset_index()
    spec = json.loads((BASE/"analysis_spec.json").read_text())
    reference_results = analyze(observed, truth, domain, spine, spec)
    by_endpoint = {x["endpoint"]: x for x in reference_results["endpoints"]}
    draw_results, differences = [], []
    for entry, values in generated:
        result = analyze(observed, values, domain, spine, spec)
        metadata = {key: entry[key] for key in ["construction", "arm", "stage", "draw"]}
        draw_results.append({**metadata, **result})
        for endpoint in result["endpoints"]:
            ref = by_endpoint[endpoint["endpoint"]]
            difference = endpoint["estimate"]-ref["estimate"]
            differences.append({**metadata, **endpoint, "true_estimate": ref["estimate"],
                                "true_ci95_low": ref["ci95_low"], "true_ci95_high": ref["ci95_high"],
                                "difference": difference, "absolute_difference": abs(difference)})
    table = pd.DataFrame(differences)
    summary = table.groupby(["construction", "arm", "stage", "endpoint"], sort=True).agg(
        generated_median=("estimate", "median"), generated_min=("estimate", "min"), generated_max=("estimate", "max"),
        median_difference=("difference", "median"), median_absolute_difference=("absolute_difference", "median"),
        true_estimate=("true_estimate", "first")).reset_index()
    initial = summary[summary.stage == "initial"].drop(columns="stage")
    final = summary[summary.stage == "final"].drop(columns="stage")
    paired = initial.merge(final, on=["construction", "arm", "endpoint"], suffixes=("_initial", "_final"), validate="one_to_one")
    paired["final_minus_initial_median_absolute_difference"] = paired.median_absolute_difference_final-paired.median_absolute_difference_initial
    results = BASE/"results"
    require(not results.exists(), "Evaluation results already exist; never silently overwrite")
    results.mkdir()
    table.to_csv(results/"all_endpoint_draws.csv", index=False)
    summary.to_csv(results/"endpoint_summary.csv", index=False)
    paired.to_csv(results/"initial_final_changes.csv", index=False)
    save(results/"analysis_results.json", {"reference": reference_results, "generated": draw_results,
        "release_manifest_sha256": sha(release_path), "spec_sha256": sha(BASE/"analysis_spec.json"),
        "limitations": [spec["claims"], spec["uncertainty"], "No inferential arm-superiority test or overall pass/fail is calculated.",
                        "All eight endpoints are reported, including disagreement and unsupported endpoints."]})
    print(json.dumps({"outputs_evaluated": len(entries), "endpoint_rows": len(table), "results_directory": str(results)}))

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--release", required=True)
    args = parser.parse_args()
    run(args.release)
