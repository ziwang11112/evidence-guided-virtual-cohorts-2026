1. WHAT WE WANT TO BUILD

Working question: Can an Agent combine available observations and applicable published evidence from different studies to generate richer virtual datasets that support useful biomedical analyses, including analyses whose results were not supplied during construction?

Three use cases remain in scope, although a first paper may reasonably prioritize one:
A. Whole-cohort generation: target population description and study-level evidence -> new virtual participants.
B. Variable enrichment: observed records with a limited variable set plus external evidence -> preserve observed cells and add variables never measured in that cohort.
C. Missing-cell completion: partially observed data plus evidence -> fill designated missing cells while preserving observations.

Example B: a cohort contains BMI, age and sex but no insulin. The Agent retrieves external research, interprets population, assay and adjustment differences, and constructs p(insulin | BMI, age, sex, target population, measurement conditions). It samples plausible insulin values and outputs analysable enriched datasets, generator code and evidence/assumption records. The objective is not to recover each person's actual insulin. If age or sex is absent it cannot silently treat invented values as observed.

The motivating benefit is reusable research material: analysis prototyping, hypotheses, study preparation or extending questions possible from limited data. Actual recruitment or measurement savings have not been demonstrated. Generating many synthetic rows adds no new empirical evidence. An unmeasured-variable deployment may have no complete target reference; this makes validation boundaries important rather than requiring exact reconstruction everywhere.

The user emphasizes scientific conclusions and relationships, not exact matching of means, SDs, individual cells or decimal coefficients. We agree that direction alone is insufficient when curvature, adjustment or subgroup patterns change interpretation. Distribution checks are diagnostics. Reproducing an input relationship is evidence consistency; recovering reserved target implications is a different, stronger test; an unsupported new relationship remains exploration.

Crucial correction to our recent framing: the capable “ordinary Agent” is itself a potentially useful method. That label only means it lacked the latest mandatory gap/action records. A viable paper need not prove that an extra multi-agent arrangement, new loss or elaborate checklist beats it. We must assess the whole evidence-to-data approach, the simplest defensible implementation, and its incremental usefulness. Added policy failure is not failure of the broad idea; broad feasibility is not sufficient novelty either.

2. WHAT THE AGENT ACTUALLY DOES

The current executed route is Agent-authored executable generators, followed by reproducible Python sampling. Direct LLM record generation remains an eligible future comparison; it was not the latest experiment. No LLM weights were trained. A new deep-learning generator, HPC or a large agent swarm was unnecessary for the pilots.

The LLM chooses sources, transformations, dependence structure, scientific parameters and revision decisions. The controller enforces interfaces, provenance, observed-cell preservation, budgets, candidate freezing and evaluation separation. It does not supply biological signs, slopes, interactions or case-specific coefficients. All four latest builders independently chose conditional lognormal programs; this family was not prescribed.

The implemented evidence schema records source identifier, exact locator, population, measurement, cohort overlap, estimand, variables, adjustment, reported value, uncertainty, applicability, model use and bridge assumptions. Parameter provenance must resolve to evidence or explicit assumptions. A source file requires a genuine gateway approval record. Unknown details remain unknown. LLM confidence is not a statistical precision weight.

The retrieval gateway searches primary literature, screens prohibited sources before displaying text, retrieves main text, lists source-linked supplements and handles supported text/XML/CSV/TSV/HTML/XLSX formats. PDF and several other supplement formats are not supported; this limitation affected access. Live metadata/maintext/listing checks passed; supported supplement parsing was tested with artificial fixtures, not a universal live fulltext claim.

In the latest pilot, both workflows could search, identify gaps, compare candidate structures and revise after the same independent source/code/scientific review. Each builder had 12 total queries and 12 document-download attempts across initial and revision turns. One scientific feedback round and a final implementation review were provided. The explicit gap policy additionally required a consequential-gap map, linked actions, source-context checks where computable, a focused alternative-model challenge and a final disposition for each gap. It permitted justified no-ops.

The evaluator was separate, opening protected target outcomes only after every output was frozen. Actual source usage and no-ops were recorded. Fresh contexts and file scopes provided procedural isolation on a shared filesystem, not OS-enforced security or proof against pretrained knowledge. Exact provider revision, token totals, latency and costs were unavailable; equal budget caps do not mean exactly matched compute.

3. COMPLETED HISTORY: WHAT HAS AND HAS NOT WORKED

3.1 Earlier retrospective completion and synthesis

One already examined 75-person, five-visit cohort was replayed through 144 tables: original reference, three overlapping masks, 60 Agent completions, 60 MICE–PMM completions and 20 draws from an existing whole-cohort generator. These are not 144 studies. The batch produced 5,040 analysis records. Most completion outputs used unchanged cells and were preservation controls.

Among 18 affected mask-by-analysis comparisons, Agent completion retained the reference evidence state in 18/18, missing-only also in 18/18, and MICE–PMM in 17/18. Agent effect discrepancy was smaller than this particular MICE implementation in 16/18, but covariates/specifications differed and the comparisons were retrospective. This does not isolate an Agent advantage. Whole-cohort synthesis retained some supplied trends and related-measure associations but missed other cross-variable and longitudinal relationships. Exact reconstruction was not required; the failures changed analysis interpretations.

3.2 Frozen Stage 1: extra dependence scenarios

Three previously exposed development cases (Ross n=75 with five visits; Travers n=12 endpoint pairs; He n=44, 43 for glucose/TG pairs) were reconstructed from limited summary packets. Nine initial lineages yielded eighteen paired Agent revision arms and three fixed statistical arms, producing 420 cohorts and 7,700 retained analytical term records. Repeated draws and terms are not independent studies.

The proposed policy retained three dependence scenarios rather than one ordinary revision. It did not consistently improve reserved analyses. Some shared-response scenarios produced confident synthetic relationships when the small real-data reference remained unresolved. An unresolved reference interval is not proof of a true null. Scenario enumeration showed sensitivity but did not provide calibrated uncertainty or a reliable accuracy improvement. The policy was not advanced unchanged. This experiment did not implement the full autonomous evidence-acquisition task, and its negative result cannot establish that enrichment or retrieval is useless.

3.3 Entire-column insulin enrichment

Fresh local benchmark: NHANES 2017–2018, 1,700 eligible adults aged 20–79, with documented fasting-sample weights and exclusions. The entire insulin column, outcome summaries, original identifiers and reserved results were hidden. The clean Agent saw only randomly keyed BMI/age/sex and population metadata. No target-trained model or insulin microdata were supplied.

The Agent independently retrieved six screened non-NHANES primary papers; three supplied numerical inputs. It derived a log-BMI slope from group contrasts, age anchors from published summaries and spread from SE/sample-size information. It assumed common log-linear BMI slope and no extra sex interaction. These were Agent decisions and assumption-dependent ecological-to-individual bridges, not identified conditional effects. One earlier search context encountered prohibited snippets and was retired; its information was not transferred to the clean builder. No-op review and the incident are recorded.

One generator produced 20 draws. Broad positive BMI–insulin association was retained: adjusted geometric-mean ratio per 5 BMI units was 1.346 in reference data (95% interval 1.304–1.390), versus generated median 1.230. However, reserved curvature (reference log-slope contrast -0.123; generated median 0.003) and sex-slope difference (reference -0.109; generated median 0.006) were not recovered. Both sexes' positive slopes survived. No statistical comparator was run for this feasibility case. Independent audit checked 84 fits and 168 endpoints. Source/code correctness did not resolve transport or structural uncertainty.

3.4 Latest fresh HDL case: ordinary versus explicit gap policy

NHANES 2013–2014, 4,885 eligible adults aged 20–79. The entire HDL column and original IDs were hidden; builders saw BMI, age and sex. The official direct-assay outcome is mg/dL. Reference analyses used survey-weighted regression with full-spine Taylor covariance (15 strata, 30 PSUs). All NHANES-derived outcome evidence from all cycles was excluded by the gateway; the conservative filter can also exclude independent papers mentioning NHANES.

Two independently initialized ordinary builders and two gap-policy builders each submitted initial and final versions, five seeds each: 40 scheduled files but 25 distinct contents, because three revisions were exact no-ops. These are four Agent constructions, not forty independent Agents. Same model configuration, tools, budget caps, review opportunities and no target feedback applied to both workflows.

All target estimates were reserved, but broad BMI/sex/age relationships and some shape evidence were source-informed. Holding out target coefficients does not make these newly discovered biological relationships.

4. OPEN DESIGN ISSUES, NOT ALREADY SOLVED CONTRIBUTIONS

Study-level summaries do not usually identify a complete joint distribution. Marginal group means are not conditional regression coefficients; marginal SD includes covariate variation; adjusted correlations do not become slopes without additional assumptions. Population selection, assay differences and adjustment sets matter. Multiple publications can reuse one cohort. More random draws cannot fix missing structure.

One prospective direction is an Agent that converts source evidence into study-specific observation operators: simulate under that study's population/measurement conditions, apply its original analysis, then compare with its reported statistics. Only afterward generate for the target. This connection resembles indirect inference/simulated moments and aggregate-to-individual evidence synthesis; it is not automatically a new statistical idea. Our implementation has source-specific checks but not a universal fitted hierarchy of source populations, measurement processes and target transport. Please do not credit us with a fully implemented general operator compiler.

Other possible improvements, all currently hypotheses: better evidence acquisition rather than more agents; explicit coherent multivariable generators; source/effect uncertainty propagation; analysis-specific support labels; restricted or partial identification; adaptive source selection; held-out source checks; conservative but useful uncertainty; direct row generation versus executable simulation; measurement acquisition or study-planning utility. Do not assume any is necessary. A simpler evidence-informed Agent may be preferable if it is effective and reproducible.

We want public-data-first work. Local Python supports current pilots; HPC can be provided if justified. Wet-lab collaboration is uncertain, so propose both no-wet-lab and targeted partial-wet-lab routes. Do not require collecting a large new cohort as the only feasible plan. Adult/child transport is an optional demanding case, not a completed result or compulsory theme.
