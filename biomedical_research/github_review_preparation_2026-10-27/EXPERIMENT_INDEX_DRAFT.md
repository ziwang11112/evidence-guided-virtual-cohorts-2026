Prepared 27 October 2026 from local protocols, result reports, audits and directory inventories. This is a draft navigation document, not a new scientific analysis. No raw participant records were inspected for this inventory, and no experiment was rerun or changed.

## Scope and counting rule

The inventory covers all **77 pre-existing top-level directories in `biomedical_research/`**: 17 dated October dossiers, `population_framework`, 58 September dossiers, and the historical `manuscript` directory. The new review-preparation directory is excluded. There are **98 uniquely identified review units**: two framework units, 17 October dossiers, the exercise umbrella plus 20 nested units, 56 other September dossiers, one literature-review dossier and one manuscript dossier. Dossiers include experiments, technical diagnostics, preparation-only tasks, literature reviews and manuscript material; **neither 77 nor 98 is a count of independent experiments or studies**. A dossier can reuse the same participants, study, source packet or Agent output many times. Stable IDs below identify review units and must not be recycled if a claim is later withdrawn. A path check confirmed coverage of all 77 dossiers and existence of every explicit local must-read file listed as an exact path; wildcard and narrative references require run-level selection.

The current mainline is cross-study evidence -> executable target-population model -> qualified revision -> later queries. The latest comparative policy result is negative. October reconstruction, prediction and workflow experiments are methodological precursors. September skin and exercise discovery branches are historical context and do not validate the current population framework. The older computer-science permission/claim-licensing research elsewhere in this workspace is a separate project.

Paths in the tables are relative to `biomedical_research/`; filenames in the last column are relative to that row's directory unless a path is explicitly given. Readers should open the listed result, protocol and audit before relying on a result. The index summarizes reported results; it does not replace checking scripts, locks and all metric tables.

## Review questions that the record can support

- Is the proposed scientific contribution more than conventional joint-distribution modeling, transport, constraint fitting and workflow engineering? Which concrete unresolved problem would justify a paper?
- Does a reusable population representation add measurable utility over a capable no-record Agent or equally informed statistical estimator? OCT-08 currently gives no primary accuracy advantage for cohort generation.
- Which evidence identifies dependence, heterogeneity, measurement mapping and transport, and which components are assumptions? Passing supplied-moment checks is insufficient.
- Does PF-02's negative result require abandoning this policy, changing the mechanism, or changing the claimed contribution? Do not rescue it with only favorable secondary endpoints or source-fit checks.
- What evaluation would add new evidence after the target exposure history, rather than reuse the same cohorts under new splits or prompts? Synthetic rows, bootstrap resamples and software test counts are not independent biological observations.
- Can the proposed manuscript clearly distinguish direct LLM numeric authorship, Agent-authored executable generators, deterministic review tests, retrospective development and genuinely reserved study-level evaluation?
