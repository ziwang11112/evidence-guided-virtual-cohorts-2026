**Scientific-use development, 9 November 2026.** The [completed coherence experiment](biomedical_research/virtual_cohort_system/reports/analysis_use_rubric_v2_2026-11-09/RESULTS.md) evaluated an unchanged baseline and an Agent-selected repair across six tables. Violations fell from 16/9,000 to zero, while the repair introduced 16 equality-boundary values. All 156 scientific and diagnostic calculations were independently reproduced; conditional evidence gaps remain. This is a controlled development result, not new clinical validation or an overall quality claim.

## From Published Evidence to Analyzable Biomedical Cohorts with Scientific Agents

The scientific agent turns published evidence and a study request into a probability model and sampling program. The host coordinates the evidence and review budget, a numerical worker generates the records, and a separate evaluator compares the requested analyses with a measured reference.

**Executed adaptive loop, 9 November 2026.** The new [controller](biomedical_research/virtual_cohort_system/docs/ADAPTIVE_SESSION_V1.md) dispatches Agent-selected retrieval, construction, isolated execution, checks and revision. In one [existing-case run](biomedical_research/virtual_cohort_system/reports/adaptive_case_loop_2026-11-09/RESULTS.md), a fresh Agent completed 28 actions and six generated tables across a primary and a dependence-sensitivity model. All requested analyses were computed and independently reproduced. The author retained its primary model before reference evaluation; source-transfer uncertainty remains, and this run does not demonstrate an overall quality gain from revision. Full-text sources and individual tables stay local.
