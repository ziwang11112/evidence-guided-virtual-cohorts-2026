## Follow an agent's modeling decision

Start with an iron-status paper whose tables give counts by clinical thresholds. Examine what one constructor extracted, which dependence assumptions it made, and how its executable program pairs continuous hemoglobin and ferritin. Then inspect the estimates obtained when the same scientific analysis is applied to generated and measured records. ## Reproduce the public checks

Run from the repository root with Python 3.12, NumPy, pandas and SciPy. The first check compares 178 populated numerical cells and the main figure with archived aggregates. The next command reproduces the new statistical draws, paired errors and decision. All commands below use public inputs and make zero model calls.

```sh
cd biomedical_research/virtual_cohort_system
python -B reproducibility/check_v39.py
python -B work/prospective_iron_dependence_2026-11-20/replay_public.py
python -B work/chns_statistical_comparator_2026-11-19/run.py replay
python -B work/chns_iron_conditional_holdout_2026-11-19/public_replay.py
python -B work/original_paper_iron_sensitivity_2026-11-19/public_replay.py
python -B work/prospective_bp_freetown_2026-11-18/replay_public.py
```

The seven tables and the public external comparison were checked in the release checkout. Independent scoring of both official data formats is recorded in the result folder, including a minute tie difference between formats. ## Data access and scope

The release includes code, authored laws, protocols, source provenance, aggregate estimates and verification receipts for the eight study directories cited above. For CHNS, the public replay checks the 18 call records and 54 draw receipts against saved summaries. The statistical comparator can recreate its own draws from public A aggregates. Re-estimation of the measured B reference from individual records requires the underlying cohort files and applicable access terms. Patient-level measured and generated tables, third-party full texts, private API transcripts, credentials and local working files are kept outside the public release.
