# External review guide for the KDD v0.42 manuscript

Read Figures 3–5 together. For the CHNS iron split, re-pairing fixed biomarker values identifies what the six agents contributed to the continuous correlation. For lipid screening, four agents generated different source-compatible pairings. Eight new advisers then ranked six uses before disclosure of an independent Virginia study. Alternative pairings informed the ranking of the largest error. The two highest-ranked uses remained contradicted or unresolved. The statistical rule ranked all six the same way as the fully informed advisers. Appendix Figure 14 shows which discrepancies can be explained by pairing the same marginal values. ## Reproduce the public checks

Run from the repository root with Python 3.12, NumPy, pandas and SciPy. The first check covers 178 inherited numerical cells, all three main figures’ reported comparisons and the two lipid planning decisions. The next command reproduces the earlier Nigerian statistical comparison. All commands below use public inputs and make zero model calls.

```sh
cd biomedical_research/virtual_cohort_system
python -B reproducibility/check_v40.py
python -B work/prospective_iron_dependence_2026-11-20/replay_public.py
python -B work/chns_statistical_comparator_2026-11-19/run.py replay
python -B work/chns_iron_conditional_holdout_2026-11-19/public_replay.py
python -B work/original_paper_iron_sensitivity_2026-11-19/public_replay.py
python -B work/prospective_bp_freetown_2026-11-18/replay_public.py
```

The seven tables and the three main comparisons were checked in the release checkout. The Ethiopian reference data were independently read in their native SPSS and Stata formats, and all six sealed virtual outputs were recomputed. The earlier Nigerian verification documents a small tie difference between its two release formats. ## Data access and scope

The release includes code, authored laws, protocols, source provenance, aggregate estimates and verification receipts for the studies and checks linked above. For CHNS, the public replay checks the 18 call records and 54 draw receipts against saved summaries. The statistical comparator can recreate its own draws from public A aggregates. Re-estimation of the measured B reference from individual records requires the underlying cohort files and applicable access terms. Patient-level measured and generated tables, third-party full texts, private API transcripts, credentials and local working files are kept outside the public release.
