 摘要

 结论：项目已建成一套可审计、如实保留失败的工程与研究流程，并在两个真实参考人群上得到
 “方向可迁移、量级与离散度不可靠”的开发期证据；它尚未证明 Agent 生成的数据比“直接引用
 文献估计”或“同信息的常规统计合成”更有分析价值，也未证明源反馈修订有效。 最可信的论文
 方向是“已发表证据究竟能识别什么”的前瞻评估与信息极限论文，而不是方法优势论文。下文用
 【已核实】【解读】【建议】区分事实、判断与提议。

 【已核实】实现层面：固定提交上的测试套件在 Linux 原生运行为 553 通过、40 失败；40 项失
 败全部源于执行适配器只接受 Windows 盘符路径，加一个只翻译路径的测试垫片后 593 项全部
 通过。这些测试使用模拟后端，证明契约与完整性，不证明沙箱隔离或科学有效性。最近四个含
 修订机会的单元（core v0、M17-B、ENSANUT、C4）全部选择“保留”，修订环节在近期从未
 产生数值改动。

 【解读】关键新发现来自我对 ENSANUT 已发布聚合结果的重算：三个有直接来源统计量的端
 点，生成数据三个种子估计的中点与“照搬来源系数”相差不超过 0.005；目标误差（年龄
 +33%、BMI −29%）几乎全部来自来源人群到墨西哥目标人群的迁移差异。唯一必须依赖生成
 联合结构的分析（Q3，调整血糖后的 BMI 效应）只达到参考值的 39–43%，其对数误差中约
 60% 可归因于假定的 BMI–血糖残差相关。也就是说，在被直接报告的分析上虚拟行没有提供文
 献之外的信息；在它可能增值的“隐含/联合”分析上，恰恰是证据最薄弱处。

 【解读】新颖性边界：通用的“LLM 提议—执行—校验—修订”循环已有 G-Sim、LLMSynthor
 （KDD 2026）和 2026 年的无样本人口合成；无个体输入、基于公开统计与指南的合成人群已
 有 Synthea 与 QSP 虚拟人群传统；从已发表汇总量重建个体数据已有 SynthIPD 等统计方法；
 “部分证据无法识别联合关系”是统计匹配（条件独立假设）的经典问题；按研究人群条件整合汇
 总证据并迁移到目标人群，ML-NMR 已有成熟统计框架。本项目仍可占据的空白是：在明确信
 息层级、同信息对照和逐分析识别标签下，前瞻评估 Agent 构建的零个体输入虚拟队列能否支
 持目标人群中的下游分析。

 【建议】主线采用故事 1（信息极限与分析效用的前瞻评估）；“研究条件化证据算子 + 显式迁移”
 （故事 2）作为有条件的方法扩展；Agent 统计语义翻译保真度（故事 3）作为可测量的组成部
 分。最小判别实验是一个前瞻真实病例上的多臂设计：直接引用（不生成）、同信息确定性统计
 合成、两次独立 Agent 构建、无证据的 LLM 先验，并以目标数据对半分割给出噪声下限；端点
 预先分为“直接 / 代数隐含 / 假设依赖”，主要结局是隐含端点上的误差差异。

 对“有用可复用数据”这一主张而言的致命缺口（对有界可行性或信息极限论文不致命）：

  1. 没有反事实对照，无法把效用归因于生成数据或 Agent。
  2. 生成数据唯一可能增值的隐含/联合分析，要么失败（Q3），要么分辨率不足（M17-B）。
  3. 冻结核心缺少异质来源所需的源情境执行；当前全队列反馈只是“目标人群生成数据 vs 他人
  人群统计量”的恒等比较。

 可修复缺口： 记录模型身份与训练截止日期；证据模式增加样本量、估计量与加权字段；反馈
 报告蒙特卡罗尺度并使用与分析不同的种子；对未识别依赖给出多结构情景；留出部分来源统计
 量做源内交叉验证；系统审计 Agent 的统计语义翻译；执行环境可移植；构建者工作区与网络
 隔离。

 B4 零个体输入下，“可复用数据”算不算有意义的科学能力？

 【解读】释放的数据所含信息不会多于“证据 + 假设 + LLM 先验 + 蒙特卡罗噪声”。因此它的能
 力不是发现，而是三件事：把异质证据编译成一个自洽联合分布并暴露冲突（例如 C3 中 Pani
 年龄曲线与线性年龄项的冲突）；为研究者提供接口，在拿到数据前用常规代码做分析原型与样
 本量规划；对每个分析做假设记账。

 【解读】在线性高斯构造下，虚拟行只是闭式隐含值的蒙特卡罗近似，增加的是噪声而不是信
 息；当分析涉及非线性变换、截断选择（如 FPG < 126 的拒绝抽样）、复杂加权或多步流程时，
 数据接口的价值才明显。

 【建议】把核心对象重新表述为“带数据接口的可执行证据综合模型”。每次发布必须同时给出：
 逐分析识别标签（直接 / 代数隐含 / 假设依赖 / 未识别）、生成器的无限样本隐含值，以及与更简
 单路线（直接引用、闭式计算）的对比。

 (C) 论文故事排序

 排名第一的是“已发表证据能识别什么”的前瞻评估与信息极限论文：它最贴合现有的混合与负面
 结果，且新颖性来自评估设计而非虚构优势。 故事 2 方法新颖性最高但目前零证据；故事 3 最
 易测量，适合作为故事 1 的组成部分。
