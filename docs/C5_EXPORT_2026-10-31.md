# C5 artificial dynamic extension export

The [C5 archive](../biomedical_research/virtual_cohort_system/reports/c5_dynamic_extension_2026-10-31/README.md) preserves the completed nine-slot artificial Gaussian implementation pilot. It records three parents, three independent one-shot joint draws, and three conditional extensions, with all original parent identifiers and values preserved in the extensions. The source and analytic answers are invented exact definitions. These results do not establish biomedical validation, novelty, superiority or completion of real-case draft gate F2.

The export uses an explicit per-file allowlist and [source/destination SHA-256 manifest](../biomedical_research/virtual_cohort_system/reports/c5_dynamic_extension_2026-10-31/EXPORT_MANIFEST.json). Frozen scientific bytes include all six template files. Included receipts are historical native execution/provenance metadata and aggregate preservation/analysis records. Every generated/input row table, execution log, temporary test-fixture tree, Python cache, patient record, downloaded paper and credential is excluded. Raw hostname-bearing JUnit files are represented by a disclosed hash-bound outcome summary, including initial failed fixture setup.

The source [exposure clarification](../biomedical_research/virtual_cohort_system/reports/c5_dynamic_extension_2026-10-31/EXPOSURE_NOTE.md) and author decisions remain intact. Root's early final-source intake, incidental historical-summary access and algebra-helper assistance are retained. Generator isolation does not imply Agent knowledge isolation.

This archive is under `reports/`; its controller imports `work.c5`. The README and read-only-by-default helper specify staging only frozen replay inputs at `project/work/c5` in a fresh clean clone. Old output/transition/run-state/reveal receipts stay in the archive. Re-execution requires the existing isolated fixed WSL/bubblewrap backend and separate controller authorization; there is no host fallback. No fresh replay or byte-identical output reproduction was tested during export.

The export preparation changes only this new report subtree and this new export note. It does not edit frozen source bytes, old exports or old receipts, and does not commit, push or publish. Final results and independent postrun closure are added and audited by the root coordinator before any synchronization.
